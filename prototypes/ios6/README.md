# Hastings · 老 iOS 风格网页端原型

打开 [index.html](index.html) 可在 7 个**桌面网页页面**间切换；[overview.png](overview.png) 是总览图，`01.png`–`07.png` 是 1440 × 900 的逐页截图。

## 产品思路

这套原型把 iOS 6 的蓝色高光、金属工具栏、分组面板、凸起按钮和轻微织物纹理用作**视觉风格**。信息结构采用桌面网页的宽屏工作台：全局导航、项目选择、多栏编辑、证据侧栏和大面积正文区域。

主流程是：**项目概览 → 创作台 → 故事账本 → 变更影响 → 修订审阅**。悬疑审计和作者模型提供两种持续反馈：前者说明故事中的事实与披露是否一致，后者让作者知道系统从哪些真实编辑中形成了偏好。

| 图 | 网页页面 | 设计重点 |
|---|---|---|
| 01 | 项目概览 | 当前任务、作品进度与待审工作 |
| 02 | 创作台 | 主编对话、正文、场景事实三栏并列 |
| 03 | 故事账本 | 真相、角色认知、读者披露分层查看 |
| 04 | 变更影响 | 事实变化的下游路径与局部修订范围 |
| 05 | 修订审阅 | 逐项查看差异、依据与授权边界 |
| 06 | 悬疑审计 | 三层事实的一致性发现与证据链 |
| 07 | 作者模型 | 偏好的证据、置信度、适用范围和撤销 |

原型依据 [V2 目标设计](../../dev-notes/v2/DESIGN.md) 绘制，是概念界面；当前运行的 V1 前端尚未具备全部 V2 能力。
