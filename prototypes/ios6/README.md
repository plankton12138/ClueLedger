## 视觉参考与历史演示

这套原型展示 iOS 6 的蓝色高光、金属工具栏、分组面板、凸起按钮等**视觉语言**。
成品如何取用这些表达，以[当前视觉与交互原则](../../product-design/v0.3/writers-desk-design.md)为准；原型中的纹理、页面结构和控件摆放不要求照搬。

下面七页是历史概念演示，用来在不同内容场景下观察视觉效果，不是成品的主流程或功能清单。
其中变更影响、修订审阅、作者模型等独立页面的处理，以[当前产品设计](../../product-design/README.md)为准。

| 图 | 历史演示页面 | 示例内容（非功能要求） |
|---|---|---|
| 01 | 项目概览 | 当前任务、作品进度与待审工作 |
| 02 | 创作台 | 主编对话、正文、场景事实三栏并列 |
| 03 | 故事账本 | 真相、角色认知、读者披露分层查看 |
| 04 | 变更影响 | 事实变化的下游路径与局部修订范围 |
| 05 | 修订审阅 | 逐项查看差异、依据与授权边界 |
| 06 | 悬疑审计 | 三层事实的一致性发现与证据链 |
| 07 | 作者模型 | 偏好的证据、置信度、适用范围和撤销 |

原型最初依据 0.2（原 V2）设计绘制，截图中的按钮、示例数据和状态不构成交付证据；
不得据此恢复已取消的模块，或推定未展示的功能（如执行日志）应被移除。

在仓库根目录运行 `node prototypes/ios6/capture.mjs`。脚本使用前端已安装的浏览器测试依赖，不需要启动后端。
