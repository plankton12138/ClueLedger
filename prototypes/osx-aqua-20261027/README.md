## 设计取舍

- 银灰渐变、细边框和轻微高光集中在窗口与控件，正文使用平整暖白底，减少阅读干扰。
- 蓝色主要表示选中项与主操作；侧栏、表格和正文通过分隔线与缩进组织，减少重复标签。
- 三张图共用窗口结构、分段导航、列表选择和按钮质感，方便比较不同内容密度。
- 取用经典 OS X 的视觉语言，并为中文正文保留较大字号。图中的列宽、控件尺寸和导航位置仍需结合实际窗口验证。

作为桌面布局原则参考，[Apple 的 macOS 设计说明](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos/)强调利用大屏幕呈现内容、减少嵌套层级并保持适当信息密度；这里的经典 Aqua 材质是本次探索方向，不代表采用当前系统外观。
