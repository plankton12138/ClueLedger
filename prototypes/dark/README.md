# dark 模块化布局参考

本目录图片仅供设计语言参考，不代表成品功能、最终布局或交付状态；图中的页面、按钮和数据均为演示内容。
这组图片属于历史视觉探索，不表示成品采用深色主题。当前已确认的视觉方向为老 iOS 风格。

2026-10-17 已确认参考本组原型的以下特点：

- 模块按职责清晰分区，主内容与辅助内容各有空间，相关信息在模块内成组组织。
- 字号较大、层级清楚，正文、列表与操作容易阅读，不靠缩字容纳内容。
- 布局充分使用页面宽高，外围空白适量；模块间距、内部边距和行高让内容充实而不拥挤。
- 模块大小随内容调整，例如主体列表配辅助区域；具体分栏和模块数量由当前任务决定。

这些布局原则与老 iOS 的控件质感结合，成品应用方式见[模块化布局与空间利用](../../product-design/v0.3/writers-desk-design.md#模块化布局与空间利用)。
图中的页面、统计、评分、过滤项与导出按钮仍只是演示内容，不因采用布局参考而成为功能要求。

使用边界见[原型目录说明](../README.md)，成品功能与交互以[当前产品设计](../../product-design/README.md)为准。
