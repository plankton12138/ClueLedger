## 设计取舍

- 木料只出现在框架层：顶栏、工具条、侧栏栏位与面板边框用实木，正文与列表仍用纸面。整屏木质会压低正文对比度，长时间阅读更费力。
- 木纹用竖向条纹叠加顶部高光，不使用贴图；深浅两档木色区分层级（顶栏最深、工具条次之、侧栏偏浅）。
- 选中项与主操作走黄铜，与木头在色相和明度上都拉开，避免和背景混在一起。
- 蜡封红只承担「我的发言」这一种含义，助手回复用亚麻白，保证对话双方一眼可分。
- 正文用衬线字体、横线稿纸和首行缩进两字，沿用古典排版；界面文字仍用无衬线，保证小字号可读。
