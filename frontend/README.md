# 线簿 / ClueLedger 前端

当前版本为 **1.2.0**，面向浏览器前端与本地服务。v1.3 章节线索登记及前端提案已标记为保留、暂不上线；实现位于 `codex/reserved-v1.3-clue-registry`，见[保留记录](../dev-notes/v1.3/README.md)。

当前视觉为[经典 OS X Aqua](../product-design/visual-language.md)：银灰工具栏、暖白稿纸，绿色作者气泡与银灰模型回复气泡。页面随窗口宽度切换分栏，保留阅读字号。

## 当前可用流程

- **作品管理**：打开或新建作品文件夹，切换最近作品、重命名、重新读取文件；不提供正文上传导入或作者直接新建章节的界面入口。
- **写作台**：左侧定位全书结构、章节与作品模块，中部阅读，右侧对话。空作品先在对话里建立结构，再开始正文；作品模块内容调整从对话发起。
- **手动修订**：对话区「修改正文」进入稿纸修订模式；编辑后「看差异」，确认修改才入稿，取消保留原文。
- **修订与约定**：「本章修订」回看改稿差异，按需启动模型分析；「写作约定」可直接编辑保存，并在正文生成前读取。
- **灵感**：悬浮按钮与面板支持拖动，Alt + I 开关；记录、搜索、历史和最近删除恢复。加入对话只准备草稿，不自动发送。
- **模块库**：独立页面可新建、编辑、浏览版本、添加到作品。模型也可在创作中建议创建或装入模块，作者选择后继续原任务。
- **会话与记录**：逐轮流式回复，思考与工具过程按需展开；支持任务暂停、按服务端能力继续及插话，活动记录用于回看操作与文件变化。
- **模型设置**：在设置中管理连接与默认模型，在对话区切换当前选择；草稿不因尚未连接模型而清除。
- **无模型使用**：本地阅读、灵感记录、手动正文修订与模块库整理可用；生成与分析需要模型连接。
- **账号与登录（v1.4 P1/P2）**：server 模式先登录再进入工作区，支持注册、邮箱验证、找回与重置密码；local 模式不显示登录页。作品由服务器分配目录，模型设置、凭据与私有模块库按账号隔离；见 [P1 记录](../dev-notes/v1.4/notes/P1-email-accounts.md) 与 [P2 记录](../dev-notes/v1.4/notes/P2-isolation.md)。
- **订阅与额度（v1.4 P3/P4）**：server 模式顶栏显示「订阅」，可查看套餐、当前权益、用量进度、最近订单状态并申请退款；额度接近用完或耗尽时给出等待恢复或切换自带连接的下一步。支付结果以支付宝通知或服务端查单为准。见 [P3 记录](../dev-notes/v1.4/notes/P3-billing.md) 与 [P4 记录](../dev-notes/v1.4/notes/P4-metering.md)。

写作台不再提供历史构思时间轴或全书线索页面。历史文档中的入口与截图不能作为当前功能说明。

## 开发运行

在仓库根目录启动后端：

```powershell
uv sync
uv run python -m hastings.server
```

另一个终端在本目录执行：

```powershell
npm ci
npm run dev
```

开发服务器将 `/api` 转发到本地 8000 端口，`/api/billing` 转发到支付服务 8300；生产由反向代理映射同一路径。生产构建执行 `npm run build`，产物位于 `frontend/dist`，可由后端托管。

需要邮箱登录时，后端以 server 模式启动并显式给出账号数据库：

```powershell
uv run python -m hastings.server --mode server --database .\data\clueledger.sqlite3
```

未配置 SMTP 时，验证码邮件写入应用状态目录下的 `mail-outbox/`；注册和找回密码都在页面内输入 6 位验证码。

## 状态与数据边界

作品目录用于正文、结构、写作约定和作品资料；应用状态记录会话与运行过程，模块库用于跨作品复用。

切换会话先保留当前草稿，再恢复目标会话状态。切换作品或页面不自动重跑任务，不自动发送未提交草稿。运行中的任务归属于原会话。

模型密钥由后端凭据机制保存，不写浏览器存储。保存连接与切换当前选择分别处理，模型切换影响后续请求。

## 代码位置

| 位置 | 职责 |
| --- | --- |
| `src/components/workspace/` | 应用壳层、稿纸、对话、作品与模型入口 |
| `src/components/writing/` | 章节目录、结构阅读、正文修订与修订记录 |
| `src/components/library/` | 模块库列表、预览、编辑与版本 |
| `src/components/ideas/` | 灵感记录与浮动面板 |
| `src/components/models/` | 模型设置与连接管理 |
| `src/components/auth/` | 登录、注册、邮箱验证与密码重置 |
| `src/state/` | 作品、写作、会话、草稿、登录会话和显示状态 |
| `src/api/` | 与本地服务的接口契约；`http.ts` 统一 Cookie、CSRF 与 401 处理 |

## 验证

```powershell
npm test -- --no-file-parallelism
npm run build
npm run test:e2e:local -- writing-workbench.spec.ts
```

浏览器测试使用隔离作品与真实本地服务；`writing-workbench.spec.ts` 不调用模型，其中分析结果展示采用受控夹具。真实模型验收使用在线模型，不能把这些确定性用例视为在线验收。

最新的 v1.2 验证与历史豁免见[开发入口](../dev-notes/v1.2/README.md)；本次功能暂缓后的定向回归见[v1.3 保留记录](../dev-notes/v1.3/README.md)。
