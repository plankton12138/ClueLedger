# Hastings 工作台

当前默认入口为 **0.3 写作台**：正文居中，对话和输入在主区，章节目录与账本按需展开。产品目标见[产品设计](../product-design/README.md)，界面当前契约见[写作台模块](../dev-notes/v0.3/modules/desk-surface.md)。

## 运行

仓库根目录启动后端：

```powershell
uv run python -m hastings.server
```

在本目录运行：

```powershell
npm install
npm run dev
npm run build
```

开发服务器将 `/api` 与 `/ws` 转发到本地 8000 端口。生产文件位于 `frontend/dist`，由后端托管。默认数据库查找、指定作品库及备份方法见[运行说明](../dev-notes/v0.3/release.md)。

开发模式的聊天默认使用模拟器；`?chatMock=0` 切到真实 API。模拟器可用于展示，不能作为真实链路验证证据。

## 当前可用流程

- 无模型时保存想法或导入正文；输入框草稿刷新后恢复。点击“接着讨论”才发送已保存想法，不因连接模型而自动发送。
- “手工修改”开启工作副本，可跨章暂存，完成后统一记录版本。冲突时保留草稿，让作者选择；可回看历史和撤销。
- “试写”生成候选，完整预览后采用；采用检查预览指纹。空作品可试写首章，无需预先填写大纲或节拍。
- 右栏维护故事账本，待确认设定成组采用；假设不直接入账。章摘要与账本更新建议由作者分别启动。
- 图谱提供人物、线索、手法结构和时间线，支持文字目录与来源定位；拖动只保存本地布局。

写作台输入框使用 Ctrl+Enter 保存想法，组合输入期间不提交。兼容对话栏的快捷键与写作台不同，具体以所在输入框为准。

## 模型接入

顶栏模型按钮和设置均可打开模型接入。选择服务、填写对应 Key、保存连接后选择模型；当前选择由服务端保存，正在运行的任务保留原连接快照。本地模型提供检测、下载、加载和测试状态；其他服务可通过自定义地址接入。套餐 Key 接入不等于网页登录授权。

凭据不进入作品备份。远程服务的真实 Key 链路尚无当前验收证据，运行条件见[验收状态](../dev-notes/v0.3/release.md#5-剩余缺口与未验项)。

## 代码导航与限制

| 位置 | 职责 |
|---|---|
| `src/App.tsx` | 默认写作台、导航、模型设置与旧对话栏显隐 |
| `src/components/desk/` | 正文、输入框、账本、图谱、导入与修改工作区 |
| `src/state/desk*.ts` | 主区导航、阅读位置与写作台状态 |
| `src/state/v2.ts`、`src/state/v2socket.ts` | 项目隔离、正文缓冲、版本回读与事件同步 |
| `src/api/` | 业务接口与对话服务契约 |
| `src/components/chat/` | 兼容对话栏与任务候选展示 |
| `src/pages/` | 概览、创作台、账本及历史兼容页面 |

整体修订的后端执行接口 `POST /revision-tasks/{id}/run` 尚无前端按钮；执行日志后端接口可用，前端面板尚未接通。旧变更影响、修订审阅只读回看，旧审计页面不提供启动按钮，作者模型页面与路由不提供当前入口。不得根据保留的源码或旧页面文档推断这些功能仍可用。后端对应限制见[API 说明](../dev-notes/v0.3/modules/api-matrix-and-retirement.md)。

## 验证

```powershell
npm test
npm run build
npm run test:e2e
```

浏览器测试使用隔离的真实 API 与数据库，模型可用确定性替身；它不能证明真实模型质量。默认匹配规则见 `playwright.config.ts`，独立走查脚本需显式执行。真实模型走查方法见[评测导航](../eval/README.md)。旧页面的历史测试不作为当前写作台全部能力已验收的依据。
