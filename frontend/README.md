# Hastings 工作台

当前默认入口为 **0.3 写作台**，桌面只保留三件：正文稿纸（只读）、模型对话（增删改在此发生）、设定集（只读查）。产品目标见[产品设计](../product-design/README.md)，界面当前契约见[写作台模块](../dev-notes/v0.3/modules/desk-surface.md)。

[0.4 修改计划](../dev-notes/v0.4/development-plan.md)将保留布局，改接 Markdown 文件、三类设定、直接写入与 Git 历史。该链路尚未实现，下面的运行方式和候选采用说明仍对应 0.3。

## 运行

仓库根目录启动后端：

```powershell
uv run python -m hastings.server
```

在本目录运行：

```powershell
npm install
npm run dev
npm run build
```

开发服务器将 `/api` 与 `/ws` 转发到本地 8000 端口。生产文件位于 `frontend/dist`，由后端托管。默认数据库查找、指定作品库及备份方法见[运行说明](../dev-notes/v0.3/release.md)。

开发模式的聊天默认使用模拟器；`?chatMock=0` 切到真实 API。模拟器可用于展示，不能作为真实链路验证证据。

## 当前可用流程

- 桌面只保留三件：正文稿纸（只读）、模型对话（增删改在此发生）、设定集（只读查）。左栏为章节目录与对话历史；右侧为固定对话栏；右缘只剩「设定集」一枚标记。
- 无模型时导入正文或先在对话里记录；对话输入框草稿按会话保存、刷新后恢复。回车发送一轮，Shift+Enter 换行，组合输入期间不提交，不因连接模型而自动发送。
- 正文只读：只能由模型经对话生成候选、作者采用后落盘，或从外部导入；前端不提供手工编辑入口。导入仍保留。
- 设定集只读：按人物 / 线索 / 时间线 / 谜底 4 类分组展示；增删改在对话里由模型提议、经对话内「采用」落盘。
- 候选采用在对话内闭环：对话区渲染「待审阅候选」卡，点「接受候选并提交」落盘，成功后出现「已接受 · 正式版本」结果卡。

## 模型接入

顶栏模型按钮和设置均可打开模型接入。选择服务、填写对应 Key、保存连接后选择模型；当前选择由服务端保存，正在运行的任务保留原连接快照。本地模型提供检测、下载、加载和测试状态；其他服务可通过自定义地址接入。套餐 Key 接入不等于网页登录授权。

凭据不进入作品备份。远程服务的真实 Key 链路尚无当前验收证据，运行条件见[验收状态](../dev-notes/v0.3/release.md#5-剩余缺口与未验项)。

## 代码导航与限制

| 位置 | 职责 |
|---|---|
| `src/App.tsx` | 顶栏（作品选择、模型、设置）与写作台挂载 |
| `src/components/desk/` | 写作台壳、只读稿纸、设定集、导入 |
| `src/state/desk*.ts` | 主区选择与阅读位置 |
| `src/state/v2.ts`、`src/state/v2socket.ts` | 项目隔离、正文缓冲、版本回读与事件同步 |
| `src/api/` | 业务接口与对话服务契约 |
| `src/components/chat/` | 对话消息、任务与候选卡 |

整体修订的后端执行接口 `POST /revision-tasks/{id}/run` 尚无前端按钮；执行日志后端接口可用、前端面板尚未接通；图谱、整体调整、后续状态、操作结果、证据核对、版本历史等高级入口自 V03-10 起从前端撤下，后端接口与数据保留。不得根据保留的源码或旧页面文档推断这些功能仍可从界面使用。后端对应限制见[API 说明](../dev-notes/v0.3/modules/api-matrix-and-retirement.md)。

## 验证

```powershell
npm test
npm run build
npm run test:e2e
```

浏览器测试使用隔离的真实 API 与数据库，模型可用确定性替身；它不能证明真实模型质量。默认匹配规则见 `playwright.config.ts`，独立走查脚本需显式执行。真实模型走查方法见[评测导航](../eval/README.md)。旧页面的历史测试不作为当前写作台全部能力已验收的依据。
