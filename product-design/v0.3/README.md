## 范围与放弃项

主工作区无正文时承接对话，有正文后以文章为中心；账本、图谱与执行日志按需查看。
首版正文由模型生成候选后采用，或导入已有正文，不提供空白首章的直接写作入口。
人工修改在独立工作副本中跨章进行，完成后统一记录版本，再按需启动摘要更新与账本更新建议整理。
模型功能一律由作者明确启动，不运行默认或隐含的后台任务；确定性保存、版本记录与证据核对可随操作自动完成。

作者模型、模型一致性审计、参考材料与 RAG 为后续保留项，本版不实现，也不展示可用占位入口。
0.4 起取消候选采用、段落内容数据库与工作副本流程，本目录只保留当时的设计依据，不代表当前能力。
