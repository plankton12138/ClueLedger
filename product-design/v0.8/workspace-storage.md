# 作品目录与真实删除

日期：2026-10-26。状态：已实施。保持版本 `0.8.0`。
开发记录见[作品目录与删除](../../dev-notes/v0.8/notes/workspace-storage-and-deletion.md)。

## 内容统一存放

作品和可复用模块都是作者内容，默认归入系统文档目录下的 `ClueLedger`，方便定位和备份。
两者分别存放，正文按作品隔离，共享设定通过装卸引用。

```text
文档/ClueLedger/
├─ ModuleLibrary/
└─ 作品/
   └─ 作品名/
      ├─ 正文/
      ├─ 灵感本/                 # 首次保存时创建
      ├─ .clueledger/            # 装配等作品资料按需创建
      └─ .git/
```

系统文档目录遵循 Windows 的目录重定向；不可用时使用主目录下的 `ClueLedger`。
普通新建和基于当前模块组合新建都使用上述默认作品父目录。
普通新建保留更改位置，显示完整目标路径；同名目录拒绝创建，不补写或覆盖原目录。
新作品只建立正文目录和版本历史，不建立空设定集，也不强制装入模块。

本轮不迁移之前的测试作品，不移动、复制或自动清理旧目录。

## 删除范围与确认

作品菜单和作品位置对话框的最近列表均提供删除入口。列表中的旧作品可以直接删除，无需先切换。
确认框展示名称、完整路径、删除范围与不可恢复提示，操作为「取消」和「删除作品及文件」。
取消不修改目录或登记，打开确认框本身不发起删除请求。

确认后永久删除该作品文件夹及其中全部文件，包括正文、灵感、装配和版本历史；
同时清理该作品的会话、活动、索引和其他应用记录。共享模块库保留，不删除模块版本。
删除当前作品后切换到仍存在的其他作品；没有其他作品时清空写作页面。
删除列表中的其他作品不改变当前作品。

删除必须确认当前完整路径。正在运行任务、目录被替换成链接、路径包含模块库、应用状态或其他登记作品时拒绝删除。
删除未完成时保留登记，展示具体原因并允许重试；部分已删除的文件无法由应用恢复。
不增加回收站、恢复流程或批量删除功能。
