# 当前视觉与布局：经典 OS X Aqua

日期：2026-10-28。作者已确认采用经典 OS X 原型的布局、较大字号与按钮位置；**对话继续使用绿色作者气泡与银灰模型回复气泡**。本文件取代旧方案中与之冲突的视觉规定；功能范围、数据和模型操作仍由各模块方案决定。

作者本轮取消故事资料并要求线索与模型操作重新设计，见[体验反馈](v1.0/interaction-redesign.md)。分支时间线与构思区现以[1.0.1 想法占位](v1.0.1/README.md)记录，具体页面与开发计划后续确定；视觉原型不能恢复已取消板块。

## 设计目的与取舍

线簿需要支持长时间阅读、创作讨论和资料核对。主要空间用于正文与当前材料，窗口材质集中在工具栏、按钮和选中项。通过稳定的分栏、阅读字号和操作位置，让作者更容易找到正在阅读、正在讨论和准备执行的内容。

视觉参考见 [经典 OS X Aqua 原型](../prototypes/osx-aqua-20261027/README.md)。原型提供视觉方向，其中的演示数据、导航细节和按钮不自动成为功能规格。

## 页面组织

- 顶栏左侧选择作品，中间保留「写作 / 模块库」，右侧放设置。故事资料板块取消。
- 写作页在宽屏并列目录、正文和辅助区。默认目录宽 240px，辅助区宽 420px，仍可拖动调整。压缩外侧边距，以细分隔线区分区域。
- 正文上方放上一章、下一章和字号调整，文件路径与大小收进文件信息。阅读区使用平整暖白底；正文仍为只读，选段引用继续可用。
- 对话输入区保持稳定可见。模型流式输出、暂停、继续和插话是待统一的交互要求，具体实现以后续计划为准。
- 收起的灵感入口避开对话输入与引用操作区，仍可拖动；展开后的灵感面板按完整窗口空间显示。
- 构思／正文切换、分支时间线与备选方案属于 1.0.1 想法占位，后续再明确布局，不作为当前已交付页面。
- 模块库在宽屏保留列表和内容预览；编辑入口靠近文档标题，保存、取消或添加操作在文档底部。模块仍是自由内容，作品内修改与全局复用边界沿用现有规则。

## 字号与控件

| 区域 | 默认字号 | 表现 |
|---|---|---|
| 正文 | 桌面 21px，窄屏 19px | 宋体阅读字形，约 1.95 倍行距 |
| 对话正文、输入与主要控件 | 16px | 保留气泡的高光、描边和投影 |
| 目录行 | 16px | 缩进与蓝色选中行说明当前位置 |
| 模块正文预览 | 19px | 主要内容连续阅读 |
| 次要提示 | 通常 13–15px | 弱于正文，保留清楚的文字对比 |

以上是 100% 显示偏好下的尺寸；已有 80%–150% 字号偏好继续作用于正文、对话、资料和弹层，字号快捷按钮也修改同一份偏好。

普通控件使用银灰渐变与轻微内高光；主操作使用 Aqua 蓝色，选中项使用深蓝渐变。错误、警告与成功继续有独立文字语义。气泡颜色、材质与左右归属保持原有风格。

## 窄窗口与放大字号

分栏按可用宽度与字号预算收起，不缩小文字来容纳三列。目录按需展开；正文、对话和线索使用现有切换入口。模块库在窄窗口逐页查看列表和详情，缩放或改窗口大小保留当前模块与编辑草稿。主要按钮允许换行，阅读区和输入区分别滚动。

实施与验证记录见 [前端 Aqua 改造](../dev-notes/v1.0/notes/aqua-ui.md)。
