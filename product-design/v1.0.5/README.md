# 1.0.5 三模式工作区与构思/正文双向联动

本版把工作区收成三个顶层模式：**正文 / 构思 / 模块库**。每个模式有自己的默认三栏，但左右栏职责固定：左栏是资料与检查器，中栏是工作台，右栏只在写作类模式里显示对话。

## 全局骨架

| 模式 | 左栏 | 中栏 | 右栏 |
|---|---|---|---|
| 正文 | 目录 / 本章线索 / 全书线索 | 正文、来源或模块正文 | 对话 |
| 构思 | 目录 / 全书线索 | 悬疑视图 | 对话 |

> 2026-11-01 后续调整：构思页删除结构视图、阶段筛选与节点详情，只保留悬疑时间轴。实现记录见 [删除结构视图与阶段筛选](../../dev-notes/v1.0.5/notes/2026-11-01-remove-structure-view.md)。
| 模块库 | 作品目录 | 模块列表 / 详情 | 不显示对话 |

- 顶栏只保留作品选择、三模式切换、全局活动记录、设置与作品菜单。
- 原二级栏的“目录、构思、对话、全书线索、专注构思”撤掉；目录和线索成为左栏标签，对话成为右栏。
- 时间轴上的线索 chip 只做使用点与选择入口；线索详情只出现在左栏，底部线索区删除。
- 悬疑视图、右侧线索面板、底部线索区三者不再同时存在。

## 使用场景

- 写正文时查线索：左栏切到本章线索或全书线索，中栏保持正文/来源，右栏保持对话。
- 改构思时对照线索：左栏默认全书线索，中栏时间轴，右栏对话。
- 点击时间轴线索：左栏自动切到全书线索并展开该条详情。
- 从构思点“写这一段”：切到正文模式，中栏显示正文，右栏显示候选写作进度。
- 点击原文依据：切到正文模式的来源子状态，左栏保留线索，右栏保留对话；来源提示可返回构思。
- 模块库：左栏目录、中栏模块；不常驻对话，离开时回到进入前的模式。
- 灵感仍为浮层；活动记录为全屏对话框；设置、作品位置、创建构思等仍为对话框。它们关闭后回到原模式。

## 状态与切换

- 三模式写进 URL；`?mode=story` 表示构思。正文、构思、模块库可前进后退，深链接可直接打开。
- 每个作品记住最近一次正文/构思位置；模块库“返回写作”回到进入前的模式。
- 构思里打开的原文依据仍标记“返回构思”；正文里打开的来源返回原处。
- 正文和构思共用同一段对话与运行任务；切换模式不重置对话。顶栏在任务运行时显示“生成中”，可回到有对话的模式。
- 左栏在线索模式下临时加宽到 320px；目录模式沿用用户保存的栏宽。宽屏三栏、中屏左栏抽屉、窄屏单栏切换。

## 线索状态与正文联动

- **仅构思**：账本有计划和使用点，正文没有观察。
- **正文未登记 / 待复核**：章节存在，但线索还没有可引用观察，或来源已变化。
- **已入正文**：候选提交后自动登记线索呈现与原文依据。
- 候选正文提交成功后，按节点线索呈现把正文中确实出现的原句登记为账本观察；后续章出现登记为提及。
- 从正文校准仍复用现有构思任务与撤销记录；逐项证据差异预览留待后续。
