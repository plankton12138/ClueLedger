# 1.0 产品方案：修订学习与写作偏好

日期：2026-10-26。状态：**方案与开发计划，尚未实施**。目标发布版本：**1.0.0**。

本版让作者在正文中直接改稿，再把有依据的修改整理成可确认、可纠正的写作偏好。
完整安排见 [1.0 开发入口](../../dev-notes/v1.0/README.md)。
前置思路见[修订学习草案](../future/revision-learning-design.md)；差异以本版明确契约为准。

## 1. 已确认方向

- 作者直接修改正文，版本系统记录修改前后内容。
- 自动分析改稿，**作者确认后**才用于后续写作。
- 默认限定当前作品；个人通用偏好只能主动推广，本版先完成作品内流程。
- 目标版本由作者定为 **1.0**；偏好通过规则与示例参与写作，首版不训练模型参数。

交互预览用于比较边栏伴随与专注写作，不代表业务代码已经交付。
不把预览中的示例分析、续写内容、版本号带入生产。

## 2. 作者旅程

```mermaid
flowchart LR
    A[编辑正文] --> B[保存与记录版本]
    B --> C[自动分析改稿]
    C --> D[待确认偏好]
    D --> E[确认或调整]
    E --> F[相关写作中使用]
    F --> G[继续修改与纠正]
```

点击「编辑」后直接修改已有章节。草稿自动保存到作品应用记录，刷新或桌面重启后恢复最近
已持久化草稿；界面区分「草稿已保存」和「正文已保存」。外部版本变化时保留基础版本、
草稿和最新正文供对照，不自动覆盖。

保存先完成正文与版本，分析随后运行。分析失败不影响已保存正文。
候选通过轻量入口提示，不抢焦点、不逐次弹窗；没有值得复用的理解时允许没有候选。
已保存的人工正文无需再次接受。

## 3. 偏好内容

把「林岚很紧张，她害怕许砚继续追问」改成「林岚把杯沿转了半圈。『你刚才说到哪儿了？』」，
可提出：

> 人物回避追问时，优先用小动作和转移话题表现紧张，减少直接解释心理。

同时显示条件、范围、前后原文与证据。作者可确认、编辑、收窄范围或选择「仅本次，不学习」。
不能直接归纳成「以后不写心理描写」。

对白表达、场景描写、情绪呈现、叙述措辞与局部节奏进入 1.0。
节奏需连续段落或场景，上下文不足时不推断整部长篇的结构风格。
纠错、人物事实与知情变化、剧情调整、格式整理分别识别，不直接当作文风。

## 4. 页面安排

| 位置 | 本版行为 |
|---|---|
| 稿纸 | 阅读、编辑、草稿恢复、保存与冲突对照 |
| 改动与历史 | 来源、段落与句内差异、完整段落、关联偏好和最新提交撤销 |
| 写作台右侧 | 对话与写作偏好共用区域；切换不丢内容，不新增第四列 |
| 窄屏 | 按需展开、关闭并返回正文，恢复原焦点 |
| 偏好详情 | 规则、条件、范围、例外、证据；确认、编辑、停用、恢复和忘记 |
| 任务详情 | 真实请求使用的规则版本、示例及排除原因 |

默认按需打开偏好面板，宽屏可伴随阅读，关闭恢复原对话布局。
不增加「作者模型」主导航和没有后端能力的推广按钮。
删除和新增同时使用符号与文字，不能仅靠红绿颜色区分。

## 5. 学习和使用边界

1. 自动学习来源仅为应用内人工编辑已有正文的实际差异。
2. 模型修改、建议采用、外部未知来源、导入和恢复分别记录，不伪装人工原创。
3. 同处反复保存只贡献一组证据；新增证据不自动改写已确认规则或扩大范围。
4. 待确认不进入生成，当前明确要求优先，事实与披露边界独立检查。
5. 默认只用于写作与改稿；事实提取、资料整理、默认检查和压缩不应用文风。
6. 后文改稿示例不带入前章；规则章界默认随证据保守确定，作者可明确调整。
7. 偏好不授予读取或修改权限，不自动重写旧章节。
8. 停用影响后续请求；忘记清除偏好与派生示例，阻止同批旧证据再次生成该偏好。

新证据与旧偏好冲突时提出新的待确认理解，不因时间较晚就覆盖。
来源失效与作者明确声明分开处理。

## 6. 自动分析

功能初始化后默认开启自动分析，显示状态、调用预算与关闭入口；本轮已确认此流程，
不再增加每次保存确认。分析只读冻结片段与上下文，没有正文、模块或偏好激活工具。
前台任务优先；后台暂停、取消、失败或模型不可用不阻塞保存。
未知用量不显示为零，无会话归属的分析计入作品操作。

## 7. 发布范围与依赖

1.0 完整交付编辑、可恢复草稿、版本与差异、人工来源、自动候选、作者决策、相关偏好装配、
实际使用记录、撤销与忘记、在线语义验证和桌面发布验证。

个人通用偏好推广、历史批量学习、参数训练、任意历史位置的局部恢复、多人协作和全书自动批改
留待后续。1.0 不以补齐所有历史设想为条件。

0.9 上下文统计与压缩仍独立交付。1.0 模型接入以其实际实现为目标基线，
可先开发编辑与证据，不能假定尚未实施的 0.9 接口已经可用。

效果按候选忠实度、新场景适用性和实际改稿判断；使用独立留出章节，作者成对盲读为主要证据。
详细门槛见[验收与在线评测](../../dev-notes/v1.0/acceptance.md)。
