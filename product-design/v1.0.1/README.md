# 1.0.1 想法占位：悬疑故事的分支时间线

日期：2026-10-28。状态：**仅记录产品想法，详细开发计划后续编写，尚未实施**。

作者将本轮讨论以 **v1.0.1** 占位。这里保存创作目标、已确认的区别和拟议交互；具体功能范围、数据结构、接口、实施阶段和验收计划留待后续确定。当前代码包版本仍为 `1.0.0`。

## 核心想法

先构思把真假线索、叙事骗局、读者误导与最终结局连接起来的故事结构，再展开有趣的场景与文章。空白作品也能开始，无须先写正文再提取线索。

整体形态接近一条可以分支、交叉、汇合并最终收束的时间线。作者可以从结局倒推，也可以从谜题或一个有趣的片段向前延伸；暂时没有决定的部分允许留空。

主线关注：发生了什么，读者何时知道，可能怎样理解，后来的发现怎样改变前面的解释，以及这些安排如何共同支持结局。

## 已确认：两种分支分别处理

| 分支 | 含义 |
|---|---|
| 同一个故事内的分支 | 不同人物视角、调查方向或猜测分别推进，在某个事件处印证、补全或推翻彼此；可以汇合后再次分开，最终收束 |
| 创作中的备选方案 | 从某个位置尝试不同发展、误导或结局，作为独立方案保存；比较和选择时保留原方案，不把互不相容的版本混入正式故事 |

切换备选时，希望能看见前面哪些铺垫、人物动机和后面哪些解释需要一起调整。故事内的多条线可以同时存在，备选方案则代表作者尚在比较的不同选择。

## 时间与信息呈现

真实发生顺序与读者获知顺序分开。界面可以默认按揭示顺序展开，实际事件时间按需查看。

这样才能安排倒叙、不同人物讲述同一事件、隐藏身份、时间误认与叙述省略。读者在某个位置看到的内容，必须与作者掌握的全部真相区分。

普通的揭示顺序预览只显示已安排的信息，不调用模型。若请求模型「试读到这里」，模型只接触此处之前的呈现内容，给出可能猜测及依据；它的反应不能代表所有读者。

## 线索如何改变意义

线索不必被强制分成互斥的真、假两类。一件真实物品可以承载伪造内容，一条真实信息可以引导错误解释，人物也可以说谎或误信。

例如「林岚知道遗书背面的文字」是真实细节，起初使人怀疑她接触过原件；后来出现旧照片，这条信息就获得了另一种解释。反转改变的是理解，先前确实呈现的事实仍应保留。

假线索需要有来源、可信的理由和后续回应。错误方向可以终止并得到解释，不要求所有线索直接证明最终凶手。叙事骗局应能在揭示后解释先前的时间、视角或措辞；具体叙述约定由作者选择。

汇合节点应说明几条线带来了什么、新发现改变了什么，以及下一步为什么这样推进。结局回应关键谜题和重要人物行为；有意保留的问题允许明确留下。

## 界面与操作的初步想法

- 在创作工作区切换构思与正文，构思区呈现分支时间线，对话围绕当前节点或片段展开。
- 默认一句具体安排对应一个节点，点开后才看真实作用、预期理解、后续回应和关联正文；不要求先填完整表单。
- 主要结构动作可以是延伸、分出一条线、汇合到这里、试一个版本。具体名称与布局后续再设计。
- 结构按当前创作片段展开，需要时查看整体，避免始终显示整部作品的全部节点。
- 连线表示故事如何推进、信息如何改变理解；卡片排在相邻位置并不自动证明因果成立。

这些是交互方向，不是冻结的界面规格。会话中的「遗书背面」示意仅帮助讨论，不代表产品已支持这些操作。

## 从结构展开正文

选中一段安排后，再写成有人物目的、冲突、行动和情绪的场景。例如让「林岚暴露知情」发生在分遗物的争执中，线索在人物行动里自然出现。

一个场景可以承载多个节点，一个节点也可以分布在多个篇章，不机械地把一条线索转换成一章。正文应有充分的表现空间，同时遵守该处可以呈现什么、需要保留什么以及前后推进的安排。

文章写出后，回到结构中关联实际呈现，检查遗漏、提前透露或与原计划不同的内容。新文本带来更好的构思时，可以讨论是否调整结构；作者计划与正文实际内容分别保留。

## 模型可以怎样参与

- 补齐从当前节点到目标反转之间的事件与信息，给出少量有实质差异的方案。
- 保留真相，调整误导方式，并说明暂时的理解为何合理、后来怎样修正。
- 检查分支汇合是否有实际作用，是否缺少发现过程或关键前提。
- 只依据指定位置以前的信息试读，提出几种可能猜测。
- 删除一条线、提前揭示或改变结局后，指出受影响的铺垫、后续解释与已写场景。
- 围绕选中的结构安排展开场景，再核对实际文章是否完成创作目的。

所有调用模型的节点都需要可见的真实流式输出，使用一致的暂停、继续和插话交互。作者已经确认：**暂停立即中断当前生成，保留已有内容；点击继续后接着做**。插话先中断旧生成，再按新要求继续。

人工编辑、连线、调整顺序和普通预览不隐含调用模型。模型提出的方案可修改，作者明确采用或要求保存后记录；已完成的写入与尚未完成的内容要能区分。

## 讨论中的例子

「遗书背面」从未公开的文字为何被林岚知道开始：林岚线出现知情表现与签收记录，周衡线出现保管声明与更换封套，两条调查在旧照片出现时汇合。

- 一个方案中，签收记录是伪造的，旧照片解释林岚的知情，调查转向周衡换信的经过。
- 另一个方案中，签名是真的，照片被伪称为事前拍摄；照片里的新封套成为时间破绽，最后转向两人合谋的结局。

同样的早期信息因此可以具有不同作用。两种结局是独立创作备选，图内的林岚线与周衡线则属于每个方案内部的故事分支。例子仍需补足具体发现过程，不作为完整小说或逻辑验收样本。
