## 0.3 范围决定（旧版方案）

2026-10-17 产品评审后的范围决定已确认，方案已进入实施：

| 范围 | 0.3 决定 |
|---|---|
| 主工作区 | 无正文时承接对话，有正文后以文章为中心；保留账本、图谱与执行日志 |
| 首版正文 | 由模型生成候选后采用，或导入已有正文；0.3 不提供空白首章的“直接写作”入口 |
| 人工修改 | 随时点击“手工修改”，在独立工作副本中跨章修改，点击“修改完成”后统一记录版本，再进入后续处理 |
| 模型常驻上下文 | 已确认账本与正文摘要，附来源、版本及更新状态；任务按需读取原文 |
| 模型功能启动 | 不运行默认或隐含的后台模型任务；每项模型功能均由作者通过明确操作或自然语言要求启动，并反馈范围、过程与结果 |
| 账本更新建议 | 根据正文变化建议补充或同步账本，在原对话中成组确认；不增加独立模块，不依赖 RAG |
| 结果与撤销 | 手工修改、导入和任务均有固定归属的结果记录；撤销覆盖原始正文及关联账本更新，并保护后续独立编辑 |
| 正文证据状态 | 正文保存同步核对“已出现、已披露、已知”的依据；失效关联标为需核对，无模型或尚未启动账本更新建议整理时仍生效 |
| 正文导入 | 默认新增章节；替换需明确目标，保护未完成副本，预览、去重与统一保存遵循同一版本规则 |
| 本书约定 | 与本次任务要求分开，可直接查看、修改和移除；保留来源及任务实际使用的快照 |
| 无模型记录 | 可保存多条作者消息并创建作品；草稿单独保留，连接后由作者选择继续讨论 |
| 作者模型 | **后续保留项，0.3 不实现**；不交付自动学习、偏好推断或记忆管理流程 |
| 模型一致性审计 | **后续保留项，0.3 不实现**；保留全文/章节审计及独立模型工具的设计 |
| 参考材料导入与材料库 | **后续保留项，0.3 不实现**；写作风格语料与检索用途留待后续。导入已有小说正文仍属本版 |
| RAG | 后续探索，不作为本版上下文或创作闭环的前提 |

“后续保留”指保留设计与既有资料，不进入本版开发、验收或默认后台任务，也不展示可用的占位按钮。
0.2 已有实现与数据按现状保存，具体去向在实施计划中说明；本次决定不代表已经删除或改造代码。

### 2026-10-19 写作台收拢裁决

2026-10-19 就前端「稿纸中心桌面」确认四项裁决，自本版实施：

1. **旧版本页面退出产品**：项目概览、创作台、故事账本、变更影响、修订审阅、悬疑审计六个旧页面从导航撤下，产品中不保留「旧版数据回看」入口；后端只读接口与数据不动。
2. **首章试写前端入口暂时撤掉**：移除「试写」「试写第一章」按钮与起草对话框；后端 `/drafts` 起草能力保留，后续可恢复入口。对话中由作者自然语言发起创作、候选采用的路径保留。
3. **默认桌面只留稿纸和笔**：右栏默认整体收起，账本 / 图谱 / 后续状态 / 操作结果有内容时才以边缘标记提示，点开为抽屉；左栏只留紧凑章节目录，想法与讨论默认折叠；删除「临时视图」区块。
4. **模块布局收紧留白与间隙**：模块铺满可用视口、外围空白与模块间隙压到最小、内容以细分隔线组织，不用大留白分隔。

这四项把[作家的桌面](v0.3/writers-desk-design.md)已定稿的模块化布局原则落实到具体界面与间距。

### 2026-10-20 写作台再收拢裁决

2026-10-20 就桌面形态确认：桌面只保留三件——**正文稿纸（完全只读）+ 模型对话（增删改在此发生）+ 设定集（只读查）**。其余「高级功能」先不做。自本版实施：

1. **对话成为唯一操作面**：对话区加自由输入框，回车直接发送一轮（去掉「写想法 → 接着讨论」两步）；正文的生成与设定的增删改都在对话里由模型执行。
2. **稿纸彻底只读**：撤掉「手工修改」；正文只能由模型经对话产生，作者手动改稿路径暂时移除，保留「导入正文」。
3. **账本改名「设定集」，且只读**：撤掉「新增设定 / 编辑设定」表单与「待确认设定」独立区块；内容只读，按 4 类分组展示。
4. **设定集只读展示 4 类**：人物 / 线索（含伏笔）/ 时间线 / 谜底（凶手·手法·动机·掩饰）；后端其余 kind 先不露。
5. **撤下高级入口**：关联图谱、整体调整（修订）、后续状态、操作结果、证据核对、版本历史一并从前端撤下。
6. **候选「采用」保留在对话内**：模型的写操作后端一律先「提议」，作者的「采用」是唯一落盘通道；撤掉的是独立审阅区块，对话内的候选卡 + 采用按钮保留。要「零确认直接改」需改后端，本批不做。

本轮只撤前端入口，后端接口、数据与写入规则不动。

确定性的保存、版本记录、摘要失效和正文证据状态核对可以随作者操作自动完成；对话、生成、摘要更新、
账本更新建议整理等需要模型思考的功能，必须由作者明确启动。已启动任务可以在作者离开当前视图后继续运行，
但系统不能自行创建任务、夹带另一项模型功能或自动重试。
