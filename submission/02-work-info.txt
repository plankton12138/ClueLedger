二、作品与赛道的关联

本作品契合"创意造物"赛道：它将 AI 写作从"一次性生成"升级为可管理的长周期创作工程——角色、伏笔、线索全部结构化为带状态机的数据资产，并以自动审计保障质量可控；用户是出品人，AI 是主编与执笔，创意决策权始终在人。

三、作品简介

AI 辅助长篇小说创作存在设定漂移、伏笔失控、线索对读者不公平三大痛点。本作品面向悬疑/推理小说创作者及 AI 协作写作爱好者，核心创意是把编码 Agent 管理代码仓库的方法迁移到文学创作：角色、线索、伏笔、作案手法、时间线是五本带状态机的"故事账本"，大模型只能通过工具读写，非法操作被工程层拒绝；作案手法一经锁定不可篡改，伏笔终稿前必须 100% 回收；RAG 检索加文体统计双通道模仿名家文风；写作与审计双 Agent 分离，让"线索公平"从文学口号变成可计算指标。实现上复用开源 Agent 内核 Tau，以 FastAPI + WebSocket + React 构建本地 Web 应用，数据全部文件制存储。当前已完成工程骨架、CI 质量门与确定性 Agent 测试链路，"设定角色→生成章节"最小创作闭环正在开发。可通过源码运行、演示视频与设计文档体验。
