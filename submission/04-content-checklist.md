## 二、待制作材料（按优先级排序）

### 4. 演示视频（30–120 秒）⭐ 最重要

**触发条件**：P1 最小闭环跑通（真实 LLM provider + 3 工具）后即可录制，不必等 Web 前端。

**建议脚本（90 秒版）：**

| 时间 | 画面 | 旁白要点 |
|---|---|---|
| 0–10s | 封面图 + 一句话定位 | "黑斯廷斯备忘录——会记账的悬疑小说 AI 主编" |
| 10–25s | 痛点快闪：AI 写长篇忘记设定、伏笔丢失的翻车案例 | "AI 能写一段，写不好一本书" |
| 25–40s | 架构图动画：五张账本 + 状态机高亮 | "我们把创作变成可管理的账本" |
| 40–70s | 终端实录：设定 2 个角色（工具调用可见）→ write_chapter 流式生成 → Bible 文件落盘 | "每个设定、每个状态变更都经工具落账" |
| 70–85s | 展示 audits 报告/伏笔状态表（或 P5 后的审计视图） | "伏笔必回收，线索必公平——可计算、可验证" |
| 85–90s | 封面 + 技术栈一行 + 仓库地址 | 收尾 |

**工具**：OBS Studio 录屏 + 剪映加字幕；终端用 Windows Terminal + 等宽字体，字号调大。

- **完整案例**（P5 后）：3 章短篇 + 每章审计 JSON + 伏笔回收率报告，作为简历与参赛双用资产。

## 三、原创性声明要点

参赛材料中建议明确写出：

1. **tau_agent / tau_ai 为开源框架 Tau 的上游代码，原样复用**（内核 0 改动为设计目标，非抄袭）——在源码中以目录边界与许可证标注；
2. **hastings 应用层（Story Bible、工具集、RAG、审计、评测）100% 原创**；
3. 文风模仿语料仅用于个人学习场景，检索片段只进提示词不进正文，正文为模型原创生成。
