# 线簿 · ClueLedger

[简体中文](README.md) · [English](README.en.md)

**让灵感、人物与线索，在长篇创作中始终有据可查。**

线簿是一款面向悬疑小说的 AI 写作工作台。在同一个地方记录想法、讨论情节、阅读与修改章节，保存人物和世界设定，再通过故事总览回看事件、关系与线索。

你决定故事往哪里走，线簿帮助你把创作要求、已有内容和原文依据放在一起。

线簿底层基于 [Tau Agent](https://github.com/huggingface/tau)，在其基础上构建面向悬疑小说的创作体验。

## 随手记灵感

想到一句对白、一个人物秘密，或一处尚未解释的细节，都可以先记下来，继续手头的创作。

点击悬浮的“灵感”按钮，就能看到输入框和最近的记录。按钮与面板都可以拖动，也可以用 **Alt + I** 随时打开或收起。

- **记下**：保存想法，留待以后使用。
- **记下并加入对话**：保存后，带到当前对话中。
- **加入对话**：选取已有灵感，再写下你希望如何讨论或使用它。

记录可以原处修改，也可以搜索、查看历史，或从“最近删除”中恢复。灵感加入对话后不会自动发送；你可以继续补充要求，再决定何时开始。

![灵感悬浮面板：随手输入新想法，查看最近记录，并选择加入对话](docs/screenshots/readme/ideas.png)

## 通过对话推进写作

写作台将章节目录、正文阅读和模型对话放在一起。可以从空白作品开始，也可以导入已有正文，接着讨论或修改。

把本次目标说清楚，模型就能围绕相应内容工作：

> 先讨论第一章的悬念，暂时不改正文。

> 参考第二章，把第三章结尾改成雪夜。只改第三章，保留人物对话。

> 检查这三章的时间顺序，指出问题并附上原文依据，先不要修改。

讨论、创作和检查可以分别提出。正文通过对话修改；需要参考其他章节或资料时，可以将它们加入对话，并说明哪些地方允许改动。

左侧目录用于切换章节和模块，中间保留完整阅读空间。目录与对话都能收起，方便专注阅读；需要回看处理过程时，可以展开对话中的任务信息或打开“活动记录”。

## 保存与复用设定

人物小传、世界设定、线索安排和章节计划，都可以保存为模块。一份模块既可以只写一个人物，也可以把一组相关资料放在一起。

新建时只需填写名称与正文，按自己的习惯使用小标题组织内容。添加到作品后，模块会出现在写作侧栏，小标题也会成为可点击的阅读目录。

**使用方法：** 点击侧栏“模块”旁的加号，选择已有内容或新建模块；添加后回到写作页，点击名称即可阅读，也可以直接编辑并保存。

日常保存只影响当前作品。需要在其他作品中复用修改后的内容时，选择“另存到模块库”。同一份设定可以用于多部作品，每部作品继续保留自己的安排。

![模块库：浏览人物与线索、旅馆设定和章节安排，将需要的内容添加到作品](docs/screenshots/readme/module-library.png)

## 回看故事全貌

切换到“故事总览”，先从时间线看起，再进入人物和线索。写到中后期时，可以沿着一个事件回到相关人物，也可以从一条线索查找它出现过的章节。

### 按章节或故事时间看事件

按章节查看叙述如何展开，按故事时间核对事件先后。“查看到”可以限定浏览进度，帮助你回到某一章重新审视已有内容。

每个事件都可以查看原文依据；相关人物和线索也能直接打开。人物的说法、回忆与推测会保留各自的性质，方便区分陈述与已知事实。

![故事总览时间线：按章节回看事件，并打开相关人物、线索和原文依据](docs/screenshots/readme/story-overview.png)

### 看人物关系与线索进展

作品中使用的模块会出现在总览里。人物资料可以查看人物卡片与关系图，线索资料可以回看出现与推进；其他内容仍可直接阅读原文。

作者设定、未来计划和正文已经写出的内容分别呈现。查看人物关系时，可以继续打开依据，了解这段关系来自哪份资料。

![人物卡片与关系图：查看榊原修的好友、邀约关系及作者设定依据](docs/screenshots/readme/characters.png)

新增章节或修改资料后，点击“更新总览”，整理本次变化。已有内容尚未整理时仍可直接阅读；相关原文发生变化时，总览会提示需要更新。单纯打开页面或切换视图不会开始整理。

## 开始使用

1. **打开或新建作品。** 在“作品”中选择已有作品，或为新故事建立一个文件夹；已有正文可以通过目录中的“导入”加入。
2. **选择模型。** 在“设置 → 模型设置”中连接并选择你使用的模型。尚未连接时，也可以先记录灵感、编辑模块和阅读已有内容。
3. **留下第一个想法。** 打开“灵感”，记下一段故事构想；需要讨论时，将它加入对话。
4. **提出本次目标。** 说明是先讨论、撰写内容、修改指定章节，还是只检查问题；需要时加入参考材料。
5. **保存资料，回看进展。** 将需要长期使用的设定加入模块，写作后到“故事总览”更新并核对事件、人物与线索。

## 使用时的几个约定

| 你关心的问题 | 线簿的处理方式 |
|---|---|
| 记下灵感，会自动写进小说吗？ | 不会。选择加入对话，并提出创作要求后，再决定如何使用。 |
| 只想讨论一个方案，会改动正文吗？ | 普通讨论不修改正文；也可以明确说“先讨论，暂时不改”。 |
| 修改一份模块，会影响其他作品吗？ | 作品内保存只影响当前作品；需要复用时再另存到模块库。 |
| 打开总览，就会开始整理吗？ | 不会。点击“更新总览”后才开始，整理期间可以停止。 |
| 总览能代替我判断故事是否合理吗？ | 它帮助你找关系、看进展和核对原文，人物动机、推理与结局仍需要作者判断。 |
