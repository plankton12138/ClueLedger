# v2.0.0 开发日志：全书结构改为可选

日期：2026-11-21。此处是开发记录的版本编号，不表示安装包已发布或运行时版本号已变更。

## 为什么改

T01 基线中，结构首稿已有 `## 铁律`，却因前面有一级标题被拒绝；模型移除标题后才保存。随后，评测采集器把界面文件目录当成完整快照，漏采了已经保存的结构。复盘决定放宽结构文档的位置限制，并取消「先建结构才能写正文」的前置条件。

## 改了什么

- **结构文档**：按 Markdown 的块结构识别首个有效的「铁律」二级标题，不再要求首行固定。保留首行缩进和其他段落，代码块或 HTML 块内的同名文本不计。首版仍要求铁律段；写入权限和文件指纹校验不变。
- **正文流程**：移除 `STRUCTURE_NOT_READY` 和强制先建结构的提示。空主方案可以核对并发布正文候选；不绕开授权、正文核对或发布事务。
- **文件目录与界面**：`/files` 新增 `documents` 分组，列出已保存的结构。起步页允许直接写第一章、整理结构或聊想法；结构不再固定置顶，仍可主动建立并用作写作参考。
- **评测**：保留 T01 r1 与原评分规则，增加无结构直接发布正文、铁律位置及目录可见性的回归检查。修复前后证据单独保存；人工标注绑定对应证据的 SHA-256，不能把旧轮结论误用于新稿。

## 验证与索引

- 原样复跑 T01：作品标题在首行，`## 铁律` 在第三行，首次写入成功；两项自动检查通过，新稿的三项语义检查仍待人工复核。
- 独立空作品在线回归：在没有 `STRUCTURE.md` 的情况下，成功发布第一章，未创建结构。此回归不计入 T01 得分。
- [T01 评测日志与证据索引](../../../eval/benchmark/t01-regression-log.md)区分基线人评、修复后回归及尚未完成的人评；原始运行档案留在本机 `eval/data/`。
