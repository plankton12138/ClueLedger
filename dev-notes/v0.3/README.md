# Hastings 0.3 文档

0.3 围绕正文、对话与故事账本组织创作工作区。当前默认入口是写作台；主要能力已实现，完整验收尚未完成。具体可用边界与剩余缺口见[运行与验收状态](release.md)。

## 当前实现入口

| 主题 | 入口 |
|---|---|
| 模块职责、接口、约束与已知限制 | [模块导航](modules/README.md) |
| 后端源码位置 | [后端导航](../../src/hastings/README.md) |
| 前端界面与运行方法 | [前端说明](../../frontend/README.md) |
| 启动、备份、验收与发布证据 | [运行与验收状态](release.md) |

当前工作区支持无模型记录想法、正文导入、跨章手工修改、候选预览与采用、账本维护、显式摘要与更新建议、图谱、关联撤销，以及「整体调整」：作者在写作台开预算明确的任务、逐章执行改写并一次发布（预算用完转为可继续的等待）。修正轮次尚无触发点；执行日志具有后端接口，前端面板尚未接通。
