## Agent 设计经验

- **验收表的价值在「不说通过」**：能被质疑的状态（部分/未验）比漂亮的绿表更能指导下一步。
- **文档收口不是盖章**：as-built 的意义是把「目标 vs 现状」的差异写下来，缺证据的地方留空比填满更安全。
- **发布记录要写运行条件**：真 uvicorn、本地模型名、Key 缺失这些现实约束，写在发布记录里，后来者才不会拿测试环境当生产证据。
