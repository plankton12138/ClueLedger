# V03-9 写作台收拢：稿纸中心桌面（2026-10-19 裁决，2026-10-20 实施）

> 阶段开发记录；实现范围、待办与测试结果均对应记录时点。当前行为见[模块说明](../modules/README.md)，剩余缺口见[运行与验收状态](../release.md)。计划与设计示例见[前端收拢开发计划](v03-9-frontend-collapse-plan.md)。

## 目标

按 2026-10-19 四项裁决把前端收拢为稿纸中心桌面：写作台成为唯一主视图；稿纸默认只读；右栏默认收起为边缘标记加抽屉；撤掉首章试写前端入口；清除界面开发痕迹；删除导航撤下后无引用的旧前端代码。后端零改动。

## 实际改动（M1–M8）

- **M5 撤试写入口**：删「试写」「试写第一章」按钮；空态文案改为「还没有正文。可以导入 .txt / .md 稿件，或在下方告诉 Agent 想写什么。」；删 `desk/DraftDialog.tsx`、`api/drafting.ts` 及其测试。
- **M2 稿纸默认只读 + 头部精简**：正文 `readOnly={!edit.active}`；删「保存正文」「专注写作」「整体调整」三个头部入口，「整体调整」移入右缘标记。
- **M4 左栏收拢**：章节目录为唯一默认展开区块；「想法与讨论」默认折叠为区块头 + 条数（展开状态不持久化）；删「临时视图」区块。
- **M3 右栏边缘标记 + 抽屉**：稿纸右缘常驻窄标记条（账本 / 图谱 / 修订），后续状态与操作结果有内容才出现标记；点开沿右侧滑出抽屉，Esc / 遮罩关闭。
- **M1 App 外壳收拢**：去导航栏（7 项）、顶栏搜索框、连接状态、头像、对话开关、底部状态栏与 ChatSidebar 挂载；顶栏只留作品名、模型、设置。
- **M7 布局密度收紧**：外圈内边距 `p-3 → p-2`、模块间隙 `space-y-4 → space-y-2`、面板头 `py-3 → py-2`、正文灰底 `p-4 lg:p-6 → p-2 lg:p-3`、顶栏 `min-h-16 → min-h-12`；行宽仍封顶 `max-w-[44em]`。
- **§4 候选卡平移**：写作台讨论区复用 `ChatCards` 候选卡；点开把候选审阅展开为主区 `detail/candidate` 视图；采用成功后回受影响正文，放弃或定位不到章时回原视图。
- **M6 旧代码清理**：删 `pages/*`、无引用遗留组件、chat 侧栏组件、`desk/DraftDialog`、`api/drafting`，连带孤立测试；`frontend/e2e/` 旧 spec 逐条核对后删除（对象已删者）或重写（对象仍在者）。
- **M8 测试 / 走查收敛**：见「验证证据」。

## 接口与数据影响

- 后端零改动：路由、410 拒启面、存储与事件流全部不动。
- 前端 `state/desk.ts` 的 `MainView` 增加 `candidate` detailKind；`deskStore` 不新增持久化字段。
- localStorage：对话栏开关键随 ChatSidebar 移除而废止，读取代码删除；遗留键值无害，不做迁移。

## 关键取舍

- 正文只读的手感变化（随手改一个字需「手工修改 → 改 → 完成修改」三步）是手工修改副本的既定行为，本批次只让前端回到设计。
- 候选卡依赖会话 payload；真实 API 候选消息字段与模拟器不一致时，兜底在真实服务下给出明确错误，不静默丢失采用入口。
- 所有删除经 git 可恢复，后端能力完整保留；撤除入口与保留能力清单登记于 [release.md §1](../release.md)。

## 偏差与未完成项

- 验收第 5 条（候选链路的浏览器级验证）受限：写作台没有自由对话输入框，向模型发起轮次经「想法 → 接着讨论」触发，该入口在模拟模式下禁用；e2e 服务的定速假模型只返回固定文本，不产生 task_draft / candidate。故候选卡渲染、候选审阅、采用接线改由组件层与模拟器服务级单测覆盖，浏览器级完整链路仍需真实模型。已在 [release.md §5](../release.md) 登记。
- 窄屏（<1024）右缘标记条不出现，改由正文头部「侧栏」入口进入账本抽屉。
- 真实浏览器 200% 缩放与中文输入法仍以等价视口、合成组合事件代理（沿用既有口径）。
