## 关键判断

1. **确定性替身是这套件的正确工具**：十场景验的是流程与不变量（不重复、不串作品、单版本、同 Commit），不是模型文笔；真模型证据在 8.7，两者分开登记。
2. **夹具只走 HTTP**：除隔离作品外不直接调领域命令，作者操作能复现的路径才进夹具。
3. **两处场景的边界如实写**：S5 的「证据锚点失效」要有正文引文锚（V03-2.5 覆盖）；S7 的「定位型披露 409」要有叙事结构章/节拍（V03-4.7 覆盖）。套件不伪造这两种前置条件，只在夹具层验证不臆断、不伪造证据。

## 过程中发现的接口口径（测试侧，不是产品缺陷）

- 编辑会话开始/当前返回 `{session, drafts}`；账本详情是扁平对象；批次 `finish` 的操作 ID 必须是 `op_` 前缀；
- 修订暂存的章基础是稿件 `chapter_base`（不是账本 revision）；
- 备份预览（`GET /backup`）只回清单；恢复要的 zip 来自 `GET /export`；
- 约定主题维度是枚举（tone/taboo/terminology…），不是自由文本；
- 对话引用只接受 chapter/artifact/selection（「接着讨论」的引用路径由 V03-1.5 专项覆盖）。
