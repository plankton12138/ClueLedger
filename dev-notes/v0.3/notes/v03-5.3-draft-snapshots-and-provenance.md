# V03-5.3 构建笔记：副本快照引用与候选进副本的段落来源

> 阶段开发记录；实现范围、待办与测试结果均对应记录时点。当前行为见[模块说明](../modules/README.md)，剩余缺口见[运行与验收状态](../release.md)。

状态：**已交付**（2026-10-18）。范围：把「任务读到的修改稿」冻结成不可变
引用，并让 Agent 候选只经作者动作进入副本、逐段保留生成来源——生成文字
不能事后被算成人工编辑证据。

## 场景与退出条件

计划的两个验证条件：

1. **固定 save_seq**：任务或讨论引用修改稿时，拿到的是某个已保存版本的
   不可变内容，不是界面上的未保存缓冲；副本继续前进，引用不变。
2. **生成来源不能算作人工编辑**：候选写进副本后，被写入的段落要能区分
   「模型生成」与「作者手写」，汇总正式版本时保留这份来源。

## 四个决定

**1. 快照是冻结副本，不是指向活动草稿的指针。**
`EditSnapshot` 保存文本、哈希、选区、段落来源与基础版本；创建后即使副本
继续保存，读取仍返回当时的内容。只接受已经落盘的草稿：请求的 `save_seq`
或 `text_hash` 与草稿不符就 409——不能拿未保存缓冲冒充快照。

**2. 快照 ID 与索引键都确定性派生。**
`snapshot_id` 由冻结点（章、序号、选区、文本哈希）派生，同一冻结点重复
请求得到同一个引用。另存一个不含文本哈希的索引键，使**副本前进之后**再
回放同一冻结点仍能找到原快照，而不是因为序号过期报冲突。两次写入
（快照、索引）非原子；先快照后索引，崩溃重试会命中确定性 ID，不会丢引用。

**3. 段落来源由服务端计算，客户端不能声明。**
普通保存把全文与旧草稿做段落级比较：没变的段落沿用原来源，改过/新插入的
段落标 `human`。候选写入只能走专用入口，写入的段落由服务端标 `agent`；
选区外的人工段落保留原来源，这就是「混合来源」。如果允许客户端在普通
保存里自带来源，生成文字可以被轻易申报成人工编辑，来源就失去意义。

**4. 候选「用进副本」与「正式采用」是两种终态。**
候选状态新增 `applied`：文字只落副本，尚未发布；`adopted` 仍表示已经
发布到正式正文。用进副本的候选不能再单独正式采用（否则同一段文字会被
发布两次），也不能丢弃或继续调整；重复请求按 `request_id` 幂等回放。

## 行为与接口

| 动作 | 路径 | 结果 |
|---|---|---|
| 冻结快照 | `POST /edit-sessions/{id}/snapshots` | 201；`save_seq`、`text_hash`、`paragraph_sources`、`selection`、`manuscript_ref` |
| 读取快照 | `GET /edit-sessions/{id}/snapshots/{snapshot_id}` | 不可变内容；副本结束（完成/放弃）后仍可读 |
| 候选进副本 | `POST /drafts/{candidate_id}/apply-to-edit-session` | 只写副本；返回新 `save_seq` 与逐段来源；候选转 `applied` |
| 操作来源回读 | `GET /operations/{id}` | 新增 `refs`，含 `paragraph_sources` 与既有 `merge_choices` |

完成修改时把逐章来源压成连续区间写进操作记录（`refs.paragraph_sources`），
例如 `[{"start":0,"end":1,"source":"human"},{"start":1,"end":2,"source":"agent"}]`。
合并过的章混入正式稿内容，逐段来源无法再精确判断，**整章标 `unknown`**，
不把可能来自生成的内容算成人工。

顺带修正：`_ended` 之前没有保留 `EditSession.chapters`，副本结束后归档里
读不出本轮章节清单；现在随归档保留。

## 留白

1. **前端未接线**：写作台仍是单章修改入口，没有快照/候选进副本的操作面；
   与 V03-5.1/5.2 的跨章清单、冲突选择一起随 V03-8.6 默认壳交付。
2. **候选写入与状态更新是两个事务**：最坏情况是副本已前进、候选仍是
   `ready`；用同一 `request_id` 重试会走幂等回放并补上状态。没有为此引入
   跨辅助表事务。
3. **草稿不存逐段的候选 ID**：只存来源类型；候选记录里有
   `applied_session_id/applied_chapter_id/applied_save_seq`，可反查是哪一次
   采用，但副本本身不能直接回答「这一段来自哪个候选」。
4. **选区按段落下标**：不支持字符级选区；与正文编辑的段落粒度一致。
5. **快照没有清理策略**：辅助表记录会一直保留；V03-8 的备份/恢复需要把
   快照与索引一起纳入清单（这也是「引用可追」的代价）。
