# 写作台工作区（desk surface）

> 状态：**as-built**（V03-1.1/1.3/1.5/5.x/6.4/8.5，2026-10-19）。证据：[8.5 走查](../notes/v03-8.5-visual-walkthrough.md) 37/37。
> 实际包：`frontend/src/components/desk/`、`frontend/src/state/desk*.ts`、`frontend/src/api/{desk,entries,imports,v2}.ts`。

## 1. 职责

0.3 的主工作区：把「正文、对话、故事账本」放在同一个三部分壳里，作者的阅读与写作始终是主区。前端不持有领域真相——所有写入走 `/api/v2`（统一发布），所有状态来自权威存储回读。

## 2. 壳层契约

- **三部分**：左章节/想法与临时视图，中正文 + 唯一输入框，右账本/图谱概要/证据核对/操作结果。
- **响应式**（8.5）：≥1280 三部分；1024–1279 左导航折叠为抽屉、保留右栏；<1024 主区优先，左右都走抽屉（头部「目录/侧栏」开关、Esc/遮罩关闭、互斥打开）。不按比例缩三列。
- **主区一次只展开一个**：`MainView` 是唯一变更入口（manuscript / discussion / detail:graph|history）；消息、候选、任务完成都不抢主区（A04）。
- **阅读位置四元组** `project|chapter|formal|-`：滚动保存、打开恢复（A05 的正文侧）。
- **专注写作**：收起两侧，保留正文与输入框。

## 3. 唯一输入框与零自动调用

- 输入框保存的是**想法**（`POST /api/v2/entries`），不调用模型；草稿进 localStorage，刷新恢复。
- 「接着讨论」是显式作者动作，才启动模型；`?chatMock=0` 显式走真实 API（开发模式默认模拟器，不作交付证据）。
- 组合保护：Enter 不提交（Ctrl+Enter 才保存）；IME 组合期值不被重置（8.5 实测 S6）。
- 键盘：编辑保存、专注写作、图谱文字目录方向键、停止回复、焦点轮廓可见（8.5 S5/S6）。

## 4. 视觉与可读

- 正文 18px、行高 32px（1.78）、行宽封顶 44em 居中；输入框/讨论/账本 14px；10–11px 仅辅助元信息。
- 次级文字令牌 `sub` 4.82:1（AA）；正文/纸面 8.01:1。
- 临时视图只列有真实视图的入口（关联图谱、版本历史）；版本历史未开章时禁用（无伪入口）。

## 5. 关键决策

1. **壳层消费纯函数状态**（`state/desk.ts`）：初始焦点、导航、阅读位置都可单测，组件不重写不变量。
2. **旧版对话栏不在写作台默认出现**（8.5 修复）：进入写作台自动收起，宽度还给正文；作者仍可手动打开。
3. **图谱文字目录是键盘等价路径**：画布不接键盘，listbox + 方向键 + `aria-activedescendant` 是既定入口（A22）。

## 6. 未验与留白

- 前端执行日志面板消费端未接（见 [execution-log](execution-log.md)）。
- 旧变更集 impact/plan/hunk 详情不再前端渲染（8.6 决定，数据可 API 回读）。
- 真浏览器 200% 缩放与真实 IME 组合由作者日常确认（headless 以等价视口 + 合成事件代理）。
