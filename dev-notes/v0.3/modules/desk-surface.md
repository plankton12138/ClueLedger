# 写作台工作区

写作台是产品的唯一主视图，桌面只保留三件：正文稿纸（只读）、模型对话（增删改在此发生）、设定集（只读查）。入口即写作台，无导航栏与状态栏；顶栏只保留作品选择、模型与设置。异步消息、候选与任务结果不自动抢占作者正在阅读的中区。

## 布局与导航

- 宽屏（≥1024）四列：左栏（章节目录 + 对话历史）｜中区稿纸｜右侧固定对话栏（消息 + 输入框）｜右缘标记条。中屏及以下（<1024）左栏、右侧对话栏、右缘标记都折叠为抽屉，正文头部给出「目录 / 对话 / 侧栏」三个入口。
- 左栏只有「章节目录」（头部「导入正文」）与「对话历史」：章节目录列出作品章节，「导入正文」打开导入对话框；对话历史按作品列出会话，点击切换右侧固定对话栏显示的会话。
- 中区恒为稿纸，只读展示当前章正文，支持滚动并保存阅读位置。头部只有当前章标题与抽屉开关，无任何编辑按钮。
- 右侧固定对话栏（消息 + 自由输入框）：随时可输入，回车发送一轮，Shift+Enter 换行；连接未就绪时禁用输入并提示去模型设置。消息区渲染助手回复、任务建议、执行任务、候选卡（含「接受候选并提交」）与结果。回复失败时标出「失败」并写明原因与下一步，附「重试这一轮」；作者停止时保留已收到的部分回复。
- 右缘标记只剩「设定集」一枚，常驻；点开沿右侧滑出抽屉，Esc 或遮罩关闭，关闭后不留痕迹。
- 主区一次只显示一种视图（当前只有「哪一章正文」），导航由 `state/desk.ts` 的状态函数控制。阅读位置按作品、章节、稿件来源与副本身份四种键保存；切换作品时不带入旧作品的操作回执。

## 正文与设定

- 正文只读：只能由模型经对话生成候选、作者采用后落盘，或从外部导入；前端不提供手工编辑入口，导入仍保留。
- 设定集只读：内容按 4 类分组展示——人物 / 线索 / 时间线 / 谜底（凶手·手法·动机·掩饰）；后端其余 kind（地点、关系、事实、认知·证词、世界规则、故事前提）不在此显示。设定的增删改都在对话里由模型提议、经对话内「采用」落盘。
- 候选采用链路在对话内闭环：对话区渲染「待审阅候选」卡，点「接受候选并提交」经写通道落盘，成功后出现「已接受 · 正式版本」结果卡。不再有独立的候选审阅主区视图。

正文使用 18px 字号、32px 行高与最大 44em 行宽；对话输入框使用 14px。

## 输入与数据

对话输入框是写作台唯一的文字入口，回车发送一轮（组合输入期间不提交）。正文与设定内容来自服务端回读，浏览器保存草稿、阅读位置等界面状态。正文发布走统一管线；无模型记录和副本暂存不等于发布正式正文。开发聊天默认模拟，`?chatMock=0` 使用真实 API。

## 当前限制

- 撤下的高级入口（图谱、整体调整、后续状态、操作结果、证据核对、版本历史）后端接口与数据保留，前端未接通。
- 整体调整执行是后端同步请求：执行中无法取消，也没有逐章进度。
- 候选链路的浏览器级完整验证仍需真实模型：写作台 e2e 使用的假模型只返回固定文本、不产生候选；候选渲染与采用已在组件与模拟器服务级单测覆盖。
- 浏览器真实 200% 缩放与真实中文输入法仍缺专门验收证据；现有自动走查使用等价视口和合成组合事件。
