# 图谱与时间线

图谱只投影已有账本、关系与正文依据，不保存第二份故事事实，也不让模型补画缺失关系。作者可通过画布或文字目录查看来源与缺口。

所有图谱读取同一提交版本；节点和边区分真相、角色认知、读者披露与计划，并带证据状态。以下路径省略 `/api/v2/projects/{project_id}`。

| 视图 | 接口 | 当前行为 |
|---|---|---|
| 统一图谱 | `GET /graphs` | 提供节点、关系、语义层和来源 |
| 人物关系 | `GET /graphs/characters` | 真关系与角色认知分层；角色视角隐藏其不可见的真实状态 |
| 线索关联 | `GET /graphs/clues` | 计划出现与已有正文披露分开；无记录返回缺口，不推断已经出现 |
| 手法结构 | `GET /graphs/method` | 围绕真相与已有事件、事实、线索引用投影；完整度只数记录是否齐全，不证明手法成立 |
| 时间线 | `GET /graphs/timeline` | 真实事件与证词分轨，按参与者或地点分组；保留时间原文，不按章节顺序推断发生时间 |

叙述位置仍可使用章或节拍解析；这属于现有类型依赖，不能因为起草不要求节拍就认为类型已经退出。

## 交互与边界

拖动只保存浏览器本地布局，不修改账本；布局位置不表示事实重要性。文字目录提供同等的查看、定位与加入讨论路径，键盘选择不修改领域内容。来源定位通过证据查询打开正文，返回时恢复原阅读位置与副本。

无人物、线索或依据时显示合法空结果与补充提示；字段缺失、引用悬空与来源待核对分别报告，不补成确定事实。图谱不能作为模型逻辑审计或质量评分。
