# V03-8.6 API 调用矩阵（0.3）

> 状态：as-built，2026-10-19。方法：从运行中 OpenAPI 生成 126 条 V2 路由（`build_v2_app` + `V2Runtime.memory()`），
> 逐条标注处置、调用方与门禁；V1 面按 V03-0.1 盘点 + 本轮复核归组。
> 证明：`tests/v2/test_legacy_entry_guard.py`（20 项）逐条落地本文的「必须拒启」与「统一管线」两列。

## 分类定义

| 类别 | 含义 | 门禁/证明 |
|---|---|---|
| **0.3 消费面** | 写作台/客户端直接使用，有前端调用点 | 走统一发布或只读投影；有 0.3 专项测试 |
| **内部/演进保留** | 有 0.3 真实用例，但不作为逐章审批流的一部分 | 凭据、预算、来源核对等既有限制 |
| **V1 兼容保留** | 旧工作区读写继续兼容；0.3 装配不消费、无入口 | 0.4 零自动调用证据；语料静态守卫 |
| **必须拒启（410）** | 本版排除的功能 | `FEATURE_RETIRED_IN_03` + 三要素；测试证明无副作用 |

## 1. 必须拒启（本版排除功能，HTTP 410）

| 路径 | 排除理由 | 替代路径 | 证明 |
|---|---|---|---|
| `POST /changes/{cs}/analyze` | 逐章审批流已退出 0.3 | 对话整体调整 / 手工修改 / 修订任务 | 守卫测试 13 项参数化 |
| `POST /changes/{cs}/plan` | 同上 | 同上 | 同上 |
| `POST /changes/{cs}/approve` | 逐章批准凭证不再签发 | 意图三分授权 | 同上 |
| `POST /changes/{cs}/execute` | 旧按变更集执行 Patch 的写路径 | 统一发布（采用/完成修改/撤销） | 同上 |
| `POST /changes/{cs}/execute-agent` | 按变更集启动模型的旧入口 | 修订任务 / 试写候选 | 同上 |
| `POST /changes/{cs}/review` | 独立修订审阅页退场 | 编辑会话 / 版本历史 | 同上 |
| `POST /changes/{cs}/merge` | 旧合并写路径（不经统一发布） | 编辑会话完成（三方合并 + 一次发布） | 同上 |
| `POST /audit` | 独立一致性审计本版不提供启动 | 历史报告只读；写作台证据核对/披露边界照常 | 同上 |
| `POST /rewrites`、`GET /rewrites/{run}/compare`、`POST /rewrites/{run}/execute`、`POST /rewrites/{run}/{action}` | 修订工作流属旧审阅链 | 手工修改 / 修订任务 | 同上 |
| `POST /coordinate` | 多 Agent 协调入口退役（前端 0 调用） | 对话意图区分 | 同上 |
| `POST /agent-jobs`（`role=style_observer`） | 作者模型自动链角色不签发凭据 | planner / writer / auditor / coordinator | `test_excluded_agent_role_cannot_start` |

**无副作用证明**：上述调用后版本头不变、Job 数不变（`test_retired_surfaces_leave_no_state_behind`）。
**历史仍可读**：`GET /changes`、`GET /changes/{cs}` 保留（`test_change_history_stays_read_only_available`）。

## 4. 0.3 消费面（写作台/客户端）

- 作品与正文：`POST /projects`、`GET /manuscript`、`GET /chapters/{id}`、`GET /chapters/{id}/history`、`/chapters/{id}/summary(-jobs)`
- 账本：`GET /ledger`、`/ledger/schema`、`/ledger/entries`（POST/PATCH）、`/ledger/candidates`（含 accept/skip）、`/agreements`
- 导入/副本/候选/撤销：`/imports/previews/*`、`/edit-sessions/*`、`/drafts/*`、`/operations/{id}(/impact|/undo)`
- 图谱与证据：`/graphs`（+characters/clues/method/timeline）、`/evidence-links`
- 上下文与披露：`/context/background`、`/disclosure-boundary(/check)`、`/revision-work/*`、`/revision-tasks/*`、`/summaries`、`/suggestions`
- 讨论与任务：`/conversations/*`（含 intents、author-messages、turns、SSE）、`/task-drafts/*`、`/agent-jobs/*`
- 运维：`/capabilities`、`/desk-state`、`/execution-events(/stream)`、`/export`、`/backup`、`/restore`、`/recovery`、`/entries`

## 5. V1 兼容与材料隔离

- V1 面（`/api/{slug}/*`、`/api/workspaces`、providers/ollama、`WS /ws/{slug}`）继续服务旧壳与迁移数据；0.3 装配不自动调用（V03-0.4 零自动链证据）。
- **语料/材料（RAG）**：`GET/POST /api/corpus`、`DELETE /api/corpus/{name}`、`GET /api/corpus/style-profile` 只在 V1 出口与 `rag/` 模块存在；0.3 代码零引用（`test_03_code_does_not_consume_corpus` 静态守卫），无隐藏检索/自动风格学习。
- **作者模型**：资料面路由已移除（V03-4 收口）；`/openapi.json` 无 `author-model` 路径，请求 404（`test_author_model_surfaces_are_gone`）；`style_observer` 角色不签发凭据。

## 7. 留白（带去向）

- V1 语料写接口仍可被**手工**调用（数据保留策略），但 0.3 无任何入口、无自动消费——是否在 8.8 一并拒启待产品裁决。
- `coordinator`/`auditor` 角色仍可创建 Job（有凭据门禁）；它们服务旧任务回看，不是 0.3 日常入口。
- 逐章审批流的底层服务（review/audit/rewrite）保留在运行时，未删除；本版只保证入口不可达。
