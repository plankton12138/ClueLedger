# P2 在线冒烟：真实生成里暂停与继续

日期：2026-10-29。连接：`conn_db37ffaa`（deepseek），模型 `deepseek-flash`。密钥来自系统凭据存储，本文不记录。

## 1. 这次做了什么

一次短要求、两次模型请求，没有重试：

> 用大约 120 字写一个雪夜旅馆的开头，只讨论文字，不修改任何文件。

流程：受理 → 收到第一条真实增量后暂停 → 等待这一轮收尾 → 继续（新代次）→ 等待完成。

## 3. 发现

**第 1 代只在思考，没有公开正文。** 暂停发生在 1 秒左右，模型还没写出正文；这一代收尾时没有可保存的公开文本。这符合预期，也说明暂停确实发生在生成早期。

**继续的提示需要写明「还没写出正文时直接开始」。** 第 2 代的回复第一句是「上一轮没有保存下来的文字，我直接给出这一段」，说明模型把「继续完成上一条要求」理解成需要解释上文。这不是数据错误，但会让作者读到一句与正文无关的话。已在应用补的继续说明里加一句「如果还没有写出正文，就直接开始写，不要说明进度或道歉」，插话说明同样处理。这条修改只影响提示文字，没有重新消耗额度验证。

## 4. 结论

写作轮次在真实模型下可以受理、真实流式、立即暂停、继续并完成；暂停之后旧代次没有写入。压缩与连接测试尚未并入同一张操作表，见[阶段记录](../notes/P2-operations.md)。
