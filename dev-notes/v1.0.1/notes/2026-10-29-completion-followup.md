## 本轮改动

| 事项 | 实际结果 |
|---|---|
| 精确采用的请求键 | 在结构锁内核对完整请求与两端修订；无改动也登记收据，同键不同负载冲突，重试返回原计划与收据。 |
| 结构记录身份 | 界面和模型工具生成独立变更标识；重复变更标识不能覆盖历史。 |
| 中断恢复 | 创建备选的提交标识保持一致；恢复前核对原状态和目标状态的字节摘要，发现外部编辑时停止并保留待提交记录。 |
| 待提交记录完整性 | 提交决定固定目标摘要；恢复时复算候选摘要并与决定对照，内容或摘要被改动时拒绝恢复并保留记录。 |
| 暂停与结构提交 | 结构提交决定和暂停共用操作锁；决定之前再次检查代次。已经决定的完整结构单元保留。 |
| 插话 | 新代次、插话和控制收据一次保存；重试检查原代次与文本，等待期间失效的代次不请求模型。连续插话保留全部作者要求。 |
| 作品隔离 | 作品服务恢复时只处理所属作品的操作，不中断其他作品正在运行的任务。 |
| 后续写入资格 | 每次文件或其他受控写入都重新检查代次；准备过历史基线不代表后续仍有写权限。 |
| 必需约定与裁决来源 | 模型工具拒绝新增、修改或移除必需约定，也拒绝将核对结论伪称为作者或应用裁决；作者授权修改必需约定的完整流程仍待接通。 |
| 模型创建内容的来源 | 模型新增线索标记为授权创作；偏好标记为模型建议并由应用生成修订。更新时保留原来源，不能伪造作者消息；模型不能删除作者或应用裁决。 |
| 未接通的联合提交 | 含正文补丁或读取依赖的结构变更明确拒绝，不再返回未实际完成的成功收据。联合提交本身仍待实现。 |
| 界面 | 避免灵感入口遮住选段操作或应用设置；较长且已有多个片段的结构默认显示一个片段，片段较多时通过选择框切换。 |
