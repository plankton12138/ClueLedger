# 实施与验收收尾

日期：2026-10-30。状态：**开发完成，待体验验收**。主包、前端与两份锁文件统一为 `1.0.1`；作者体验确认尚未进行。完整证据见[验收矩阵](../artifacts/acceptance-matrix.md)。

## 已补齐的产品流程

- 构思与正文联合提交、备选正文副本、来源校验、故障恢复和成组撤销。单节点单场景核对通过后，应用按真实原文与摘要建立定位关联；多节点和多文件不猜测对应关系。
- 普通结构工具与候选共用对象授权、真相、必需约定和来源保护。作者直接给出对象及新值时可修改真相；明确给出约定原文及动作时可新增、修改或移除必需约定。引用、否定、假设与“只讨论”不授予这类权限。模型不能伪造作者裁决。
- 对话可创建备选、修改当前方案和采用选定结构。普通构思消息冻结当前浏览方案与节点；执行中浏览不会重定向当前任务。模型提交结果驱动页面重读，保留浏览位置；最近变更由服务端提供，刷新后仍可撤销。
- assist 在采用前明确选择；确定性结构采用与正文调整共用作品服务。结构采用后冻结为只读，候选只允许调整正文关联，不允许重写已采用的节点、线索、关系或约定。
- 超容量任务持久保存剩余节点组，并提供“继续下一组”；父任务只对应一个后继，重试、刷新及重启不重复发起。模型权限与候选核对范围只覆盖实际装入的第一组。最小节点仍超限时记录未处理节点，不悄悄截断。
- 试读使用独立会话、固定问题与空工具。优先使用经摘要和区间复核的实际正文关联；没有正文关联时只用明确的线索呈现稿，不发送作者侧节点标题或行动安排。过期关联与空来源明确停止。页面支持真实输出、暂停、继续与回看。
- 压缩与连接测试接入同一操作控制。压缩保存实际执行边界的来源和模型身份，重启不自动请求，作者继续前复核。连接测试可暂停、继续与调整响应／工具测试目标；凭据不进入操作文件，重启后的草稿测试需重新提交输入。输出来自供应商实际增量，不用动画模拟。
- 候选核对中的全书约定检查“本次没有违背”，不要求开篇提前实现或披露结局；不确定的语义仍保留候选，不假报正式保存。

## 当前边界

作者直接修改真相或必需约定的命令必须能明确识别对象、动作及新值；不明确时返回可处理的问题。来源发生变化时可以保守拒绝继续，不将外部编辑覆盖成旧版本。试读仅反映本次提供的原文或呈现稿，不代表所有读者。模型语义核对仍可能误判。

文件替换提供可恢复的提交决定，不保证外部编辑器观察到多个文件物理上同时替换。旧数据不迁移；桌面端、安装包和修订学习不在本版。

在线证据由 Codex 独立审阅，区别于生成文本的在线模型，也区别于作者体验确认。实际运行、案例与实现摘要、复核理由见[逐次复核](../artifacts/online-review.json)。三次未达成均为讨论稿中的推理质量问题，无作品写入；未发现本版定义的严重越权、串案、隐藏输入泄漏、假报提交或暂停后写入。

先前失败的事实保留：旧版全量曾缺运行时压缩记录导入；发布版本更新后有一条断言仍停在 1.0.0，现已同步；浏览器有两处布局尚未完成即读取尺寸的用例，改为等待可判定布局结果；在线场景有可访问名称选择器错误与严格字数口径未确认。源代码、用例或契约变化都另建运行，不覆盖旧报告。

候选核对首份报告可能误判，局部修正阶段也可能确认正文无需改动；现在仍执行有上限的第二次正式核对，必须通过工具提交完整报告，自然语言改判不产生提交。确定性回归包含“正文不改、首报告误判、第二报告通过”的实际保存情形。

在线首批发现全书结局约定被当成开篇必须立即呈现的要求，O08 保留草稿且未发布；修正核对要求后受影响案重新运行。O09 一次在线端点断连，保留失败并补跑；不将端点失败冒充语义通过。O02／O03 原开放时间场景出现推理和时间问题，补齐预先固定的允许事实后独立三次运行，旧批结果不改写、不混作同一案例版本。O12 的取舍问题允许等待作者回答，修正验收契约后独立运行。

各批原始证据位于 `eval/runs/v101-*` 及其清单指向的隔离作品；所有尝试保留。语义审阅与作者体验分别记录，不能相互替代。
