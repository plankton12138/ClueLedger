# 全部模型入口清单

日期：2026-10-28。状态：**P0 登记完成，未实施统一操作**。本文件是 P2 的施工依据：每个模型调用都要能从一个界面动作反查到这里，再从这里的记录反查到实际请求。

## 1. 判定口径

- **调用模型**：服务端会向供应商发起请求（含流式）。这类入口必须有持久操作、真实增量、可暂停／继续／插话。
- **不调用模型**：读写文件、列表、搜索、Git、导入、模型发现、页面打开、普通预览、选中节点。这类入口不得伪装成生成，也不得在背后顺手调用模型。
- **无调用方**：服务端受理入口存在，但当前界面没有任何地方发起。1.0.1 要么接回新流程，要么删除；不能留两套能力各自维护。

## 2. 调用模型的入口

| 界面动作 | 请求 | 服务端受理 | 模型阶段 | 备注 |
|---|---|---|---|---|
| 写作区对话发送 | `POST /api/file-workspaces/{id}/conversations`（首次）或 `/conversations/{cid}/turns`（续聊），`purpose=chat` | `TurnService.accept` → `_run` → agent 循环 | 写作／讨论；含工具调用与写后检查 | 唯一能写正文的入口 |
| 对话内「检查本次改动」 | 同上，`purpose=review` + `review_paths` | 同上，进入检查阶段 | 只读检查（可带写后修正） | 只读工具集，报告落 `reviews` |
| 线索推理「核对」 | 同上，`purpose=review` + `clue_review{inference_id, inference_revision, clue_ids, as_of_chapter}` | 同上，冻结核对范围 | 推理核对 | 报告失效跟随来源改动 |
| 故事资料页「整理」 | `POST /{id}/material-tasks` | `accept(purpose="organize_materials", material_scope=…)` | 资料整理（单域） | 一个任务只更新一个域 |
| 本章线索「整理本章」 | 同上，`scope.domain=clues` | 同上 | 资料整理（线索域） | 与上表同一受理路径 |
| 会话用量条「压缩」 | `POST /{id}/conversations/{cid}/compactions` | `CompactionRunner.start` → `_summarize` | 摘要（无工具） | 独立停止接口 `…/compactions/{op}/stop` |
| 设置页「测试连接」 | `POST /api/model-connections/probe` | `ModelConnectionService.probe` | 连接测试（生成＋工具能力） | 不落作品状态，直接返回汇总 |

### 一个入口内部的多个模型阶段

写作轮的 agent 循环里，以下阶段属于**同一次受理**，在 P2 合并到同一个可见操作下，不再各算一次任务：

- 写前材料装配与参考预读（不调用模型，只读文件）。
- 正文写作与工具调用（`write_chapter`、`edit` 等）。
- 写后检查（`purpose=review` 的独立轮次，或同轮内声明的检查阶段）。
- 章节索引、身份／状态更新（当前为独立轮次，P2 起并入声明阶段）。
- 上下文压缩（当前独立入口，P2 起作为独立可见操作或当前操作阶段）。

## 3. 不调用模型的入口

| 入口 | 说明 |
|---|---|
| 作品登记：列表、打开、改名、删除、清理失效登记 | 只动登记表与目录 |
| 文件：目录、读取、搜索、导入、阅读位置 | 只读文件；导入走解析，不调模型 |
| 章节索引读取、来源定位、报告读取 | 读已落盘结果 |
| Git：状态、差异、日志、初始化、补记、回退 | 只执行 git |
| 活动记录：列表、详情、导出、重建 | 重建只读事件，不调模型 |
| 会话：列表、改名、消息回读、界面偏好 | 只读事件 |
| 模型设置：列表、连接增删改、模型发现、选择 | 发现走供应商 `/models`，不是生成 |
| 模块库：预设、列表、修订、记录、发布、派生 | 装配只写文件 |
| 灵感：列表、详情、新建、修改、删除、恢复、修订 | 纯文本存储 |
| 线索：列表、详情、计划关联、来源 | 读账本 |

## 5. 与 1.0.1 目标的差距

| 目标 | 当前状态 | 归属阶段 |
|---|---|---|
| 每个模型入口可暂停／继续／插话 | 只有整轮 stop，压缩有独立 stop；无统一操作 | P2 |
| 真实流式增量 | 已有 `text_delta` 事件；工具参数增量进候选缓冲 | P2 复核并统一 |
| 暂停后迟到输出无效 | 有取消标志，但没有持久代次资格 | P2 |
| 刷新不重复调用模型 | 会话事件可回读；重启后标为中断 | P2 补操作快照与游标 |
| 连接测试也走同一控件 | 目前一次性返回汇总 | P2 |
| 无后台漏接入口 | 本清单已穷举；新增入口必须同步登记 | 持续 |

## 6. 登记规则

新增任何模型入口时，同一个提交里必须补齐三件事：本文件的表格一行、`api-and-frontend.md` 的接口归属、一个能证明“受理即可见、可暂停”的测试。缺任一项按未完成处理。
