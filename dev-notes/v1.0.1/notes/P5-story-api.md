## 1. 本阶段做了什么（第一部分）

| 计划项 | 落地 |
|---|---|
| 打开构思、方案切换 | `GET W/story/variants` 返回方案列表、修订、主方案与各自的对象计数 |
| 图数据与片段折叠 | `GET W/story/variants/{id}?group_id=` 返回节点、连接、分支、约定；指定片段时只返回该片段，其余列为折叠 |
| 点节点看详情 | `GET W/story/nodes/{node_id}?variant_id=` 返回安排、线索的真实作用（含作者真相与呈现方式）、知情、正文入口与进出连接 |
| 确定性结构操作 | `POST W/story/changes`：带 `expected_revision` 与 `request_key`，修订不符 409，同键同负载返回同一收据 |
| 从某版建备选 | `POST W/story/variants`：只复制确定基线，不调用模型 |
| 看差异 | `GET W/story/comparison`：按对象比较新增／删除／修改，明确不宣称语义完整 |
| 查看改动与撤销 | `GET W/story/changes/{id}`、`POST …/undo`：撤销只恢复当时涉及的对象 |
| 前端客户端 | `api/story.ts`：与接口一一对应的类型与请求，标识全部来自服务端 |

这一层没有调用模型的路由：点比较不会偷偷生成，建备选只复制基线。需要语义整理的动作（采用备选、局部采用）走对话与操作接口。

## 2. 关键取舍

**写入先比修订，再谈幂等。** 界面发起的每次变更都带受理时看到的修订；不是当前修订就 409，避免把两次编辑悄悄合并。同一请求键与同一份负载只应用一次，重复点击返回同一收据。

**差异只比较对象。** 接口返回的是「哪些对象新增、删除、内容变了」，不是「两个方案在语义上是否等价」。跨边界依赖与语义成立要单独核对，接口文案里写明了这一点。

**折叠由服务端给列表。** 片段折叠后哪些节点不在当前图里，由服务端返回 `collapsed`，界面不按坐标或标题猜。自动布局仍是界面的事，接口只给结构与折叠结果。

**详情包含作者真相。** 这是作者自己的界面，不按读者阶段过滤；试读的过滤在装配层（P3）单独做。两处不共用一个「脱敏」开关，避免一边改坏另一边。

## 4.1 第二部分：构思面

写作区新增「构思」按钮，与正文共用同一个纸面：切换只换内容，不新开页面，也不打断正在运行的任务。

| 页面元素 | 行为 |
|---|---|
| 方案标签 | 来自 `GET /story/variants`；主方案在标签上标「主」 |
| 结构图 | 按 `next` 关系分层自动排布；推进关系实线，重新解释与回收用虚线；节点上的数字是线索条数 |
| 点节点 | 就近展开详情：安排、线索的呈现与作者真相、知情、正文引文与「打开正文」 |
| 建备选 | 从当前方案复制基线，建完切到新方案；主方案不变 |
| 与主方案比较 | 只在备选上出现，显示新增／删除／修改的对象数 |
| 撤销上一次 | 本次会话里刚提交过结构改动时出现 |

状态在 `state/story.ts`：只放「看哪个方案、选中哪个节点、图与详情」。写入成功后按服务端返回的修订重读图、方案列表与详情，不在本地拼一份「大概是这样」的结构。

## 5.1 第二部分：采用、片段、引用与定位（同日补齐）

| 计划项 | 落地 |
|---|---|
| 采用方案／片段 | `POST W/story/adoptions`：`mode: exact\|assist`、`node_ids` 空为整案、`replace` 控制覆盖。`exact` 先算计划（复制了什么、哪些已一致、为支撑所选内容带入了什么），再作为一次结构变更提交；目标里已有同 ID 但内容不同的对象时返回 409 与逐项原因，不静默覆盖。同键重试返回当时收据 |
| assist 采用 | 先按同一计划确定性提交结构，再受理一次可见操作（`purpose=revise`），由模型读取受影响节点与已关联正文，补足铺垫、更新不再成立的呈现；未产生结构变化时不启动模型。响应带 `operation_id`，可在任务面板暂停、继续或插话。结构本身不会被模型改写 |
| 片段折叠 | 节点带 `group_id` 时，图上方出现片段按钮；折叠后显示「N 个节点不在这个片段里」，片段列表在折叠时保留 |
| 引用到对话 | 节点详情「引用到对话」：草稿区出现「本轮构思」条目（可移除），下一条消息带 `context.story`（方案 + 修订 + 节点），服务端按 P3 的结构装配复核；发送成功后引用清除 |
| 正文定位 | 节点详情的正文关联直接按区间打开正文；区间与引文对不上时按「已失效」显示，不假装高亮。来源提示的「返回构思」回到结构视图 |
| 窄屏与大字号 | 390 宽 + 150% 字号下构思面无横向溢出；详情移到图下方，操作按钮仍在视口内 |

采用只复制结构：正文关联指向的是某个方案自己的正文副本，复制到目标方案会指向不存在的段落，所以不复制并在结果里说明。计划与冲突都在响应里，界面展示的是服务端给的事实，不由前端拼。

模型入口的采用范围后来收紧为「冻结选择优先，空选择必须由作者明确要求整案」，界面按钮仍是作者的直接动作；关系与实际时间的范围规则见[授权与采用修复](2026-10-30-authorization-adoption-fixes.md)。
