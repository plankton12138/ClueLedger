# P2 补充：写作操作重启恢复

本文件保留分批实施和验证记录；最新实现、已关闭事项及验收结果以[收尾记录](P7-implementation-and-acceptance.md)为准。
日期：2026-10-29。状态：**写作操作可在重启后由作者显式继续；压缩重启后转暂停且不可继续；模型连接测试的输入只在进程内，重启后需重新测试。**

操作受理时保存材料快照、当前正文指纹、模块装配摘要、原模型的公开身份与容量信息，以及任务用途和目标。凭据不进入记录。服务重启时旧代次失效，操作进入“需要处理”；不会自动调用模型。重复执行恢复不会反复推进代次。

作者点继续时，应用重新冻结材料并与原快照比对，检查当前正文、构思修订、装配摘要，以及模型连接、名称、思考级别和容量信息。发生变化时拒绝继续，保留当前操作和代次；模型连接会在实际启动前再次检查。新一代沿用既有事件、收据与已保留候选，候选仍需模型主动读取，并在当前轮重新授权、核对后提交。

这项检查保护可观察的版本身份。连接地址或凭据在同一连接标识下发生变化时，目前没有独立配置修订可以比较。引用文件或当前正文由本操作本身改动后，恢复也会保守拒绝，尚未根据已提交收据自动区分本操作的改动与外部修改；应检查结果后重新发起。早期缺少恢复快照的操作不可继续。重启不会自动重跑模型。

压缩在重启后转为暂停并标记不可继续：它没有可以承接的冻结请求，恢复只把未结束的摘要请求补成中断，不重新调用模型，现有摘要与上下文保持原样。连接测试的输入（包括草稿 Key）只存在内存，重启后同样不提供继续，需在设置页重新测试。

## 验证

受控后端测试覆盖重启不自动调用、显式继续、重复恢复不推进代次、参考文件／当前正文／构思修订改变后拒绝，以及模型连接变化时不消费继续请求；压缩重启后转暂停、不可继续，并补记中断请求而不重跑。操作控制单独测试 16 项通过。静态检查与类型检查通过。本轮未调用在线模型。模型语义、全部入口和浏览器旅程仍需按验收计划执行。
