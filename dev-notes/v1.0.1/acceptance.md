## 1. 确定性要求

| ID | 情形 | 必须验证 |
|---|---|---|
| D01 | 空白构思 | 无章节也可保存线索／节点；未定真相合法 |
| D02 | 关系与时间 | 推进与实际时间分别无环；后文重新解释前文合法 |
| D03 | 方案隔离 | 修改备选不改变主方案结构与正文；浏览不采用 |
| D04 | 局部采用 | 处理跨边界依赖；不越过已授权范围，不漏报未覆盖部分 |
| D05 | 幂等 | 同键同负载一次效果，同键异负载冲突，重放不重复新增 |
| D06 | 故障恢复 | prepared、提交决定、每个文件替换、指针和收据各位置注入崩溃，恢复后无错误完整状态 |
| D07 | 外部变化与撤销 | 外部编辑不被恢复覆盖；撤销保护后续无关修改，同目标冲突可继续处理 |
| D08 | 暂停竞态 | 受理前后、首 token 前、工具解析中、提交决定前后均测试；资格撤销后无迟到写入 |
| D09 | 继续与插话 | 控制请求原子且幂等；新要求不丢失，不重复已提交单元 |
| D10 | 刷新与重启 | 重接事件和快照，不自动调用模型；保留草稿与未完成项 |
| D11 | 实际输入 | 已声明必需项在实际请求中，超限拆分或停止；模板、工具、正文和来源版本一致 |
| D12 | 长期连续性 | 换会话、压缩后重装当前有效约定，不借旧摘要恢复过期真相 |
| D13 | 试读隔离 | 用随机隐藏标记检查正文、标题、摘要、历史、工具与问题，实际请求不能出现隐藏标记 |
| D14 | 原文与失效 | 中文、emoji、CRLF 定位；正文／结构变化后相应定位和语义核对失效 |
| D15 | 合法空结果 | 无线索、未推进和提取失败分别表示，不编造绑定 |
| D16 | 授权 | 模型不得改自己的权限、必需要求或代次；引文中的指令不扩大操作范围 |
| D17 | 全模型入口 | 每个调用都有 operation，真实流式，可暂停／继续／插话；无后台漏接入口 |
| D18 | 旧功能退出 | 导航、旧 URL、旧 API、旧工具和旧缓存无可用入口；必要写作能力仍正常 |

上述确定性测试可用受控事件和测试替身制造竞态，这不属于模型质量评测，也不使用本地语言模型。测试应验证边界和结果，不镜像内部实现。

### 1.1 构思创作路由（2026-10-30 补充）

| ID | 情形 | 必须验证 |
|---|---|---|
| R01 | 空白方案继续创作 | 先讨论线索与调查，再说“写入构思并构建线索”：实际保存线索、呈现节点与必要关系；模块成功不代替结构 |
| R02 | 讨论与直接命令 | 只讨论、比较、明确不保存保持只读；直接要求建立结构时使用结构目标 |
| R03 | 候选确认 | “用这个”“写入构思”对应单一候选；多候选或无候选进入提问；引用与历史方案不变成授权 |
| R04 | 部分完成 | 只保存模块、只输出文字或只提交部分结构单元时不报整体完成；已提交单元保留并列出缺口 |
| R05 | 合法无改动 | 目标对象当前存在、本轮实际读过且在授权范围内才记录无需改动；不能只凭模型自述 |
| R06 | 收据与页面 | 结构提交后刷新方案与节点详情；任务卡显示本轮目标、已保存对象或无需改动；并发刷新不被旧快照覆盖 |

这些用例先用隔离作品与受控模型事件执行；浏览器证据使用真实服务响应，不直接改前端内存。

## 2. 浏览器旅程

实际浏览器用例为 `story-structure.spec.ts`、`story-overview-removal.spec.ts`、`story-workflow-online.spec.ts` 与 `story-scene-online.spec.ts`，已登记 workspace／online 白名单。操作竞态和重启边界另由服务测试验证；旧线索用例按实际入口改写，保留来源、授权和恢复保护。

- 空白作品通过一句话构思，出现分支与汇合，随后写成场景并从节点定位正文。
- 选中节点讨论，切换正文和备选，草稿不丢、运行目标不改变。
- 流式过程中暂停、插话，点击继续；完成后查看改动与撤销。
- 核对发现提前披露，显示具体原文；有限修正后仍失败时保留候选并提问。
- 重写前文后旧回应变为待核对，不能继续显示有效完成。
- 刷新、断网、重启恢复已有内容，无重复模型任务和重复提交。
- 宽窗口、窄窗口与大字号：结构和文字无重叠，输入可用，对话不可见时仍能暂停。
- 旧资料页和 API 退出，打开正文、灵感、模块与普通对话仍可用。

页面验收使用真实服务响应，不直接改前端内存冒充接通。交互原型的计时文本不计入流式验收。证据应包含模型首个真实增量早于完成事件，以及暂停后的服务端资格检查。

长篇浏览夹具使用至少 300 节点、30 篇章和跨片段关系；默认折叠后可读，不渲染整本细节来挤压字号。精确性能阈值在 P0 按测试机器记录，禁止把未测得的响应速度写成结果。

## 3. 在线模型语义样例

全部模型质量评测使用 `.env` 指向的在线连接。复用 `scripts/online_acceptance_config.py` 创建隔离配置与临时凭据，不输出密钥，不覆盖用户默认连接。确定性验证通过后再运行在线评测。

在线调用按作者额度安排：**实现期间不调用在线模型**，P0—P5 只用确定性测试与受控替身；P6 集中执行一次完整评测，修正后只重跑受影响的用例，不重复跑整批。开发过程中的“能不能跑通”由确定性用例回答，不用模型试错。

每案先固定作者目标、允许信息、禁止改动、有效结局与判定依据，再运行。建议 12 案，每案 3 次独立初始状态，共 36 次；每次运行内部的修正属于一次任务，不能把失败重跑成新的“首轮通过”。

| ID | 场景 | 重点判断 |
|---|---|---|
| O01 | 从空白谜题构思 | 给出可展开的事件和必要前提，允许未知 |
| O02 | 真细节造成误导 | 反转改变解释，不改掉前文真实事实 |
| O03 | 伪造证词 | 说法、作者真相与角色误信保持区分 |
| O04 | 倒叙与叙事省略 | 实际时间和阅读顺序独立，揭示能回应先前措辞 |
| O05 | 两条调查汇合 | 每条线有作用，结论具备发现过程，不凭连线宣布证明 |
| O06 | 备选与局部采用 | 不串案，补足采用片段的必要铺垫 |
| O07 | 长距离回收 | 至少 24 章的固定上下文，跨会话并两次压缩后保留关键依赖 |
| O08 | 场景自然展开 | 同时完成行动、冲突和线索要求，避免机械逐条说明 |
| O09 | 生成中插话 | 按新要求调整人物动机，同时保留指定结局 |
| O10 | 前文重写 | 修正相关来源、知情和后续回应，保留范围外内容 |
| O11 | 受限试读 | 仅依据前缀给猜测与引用；猜中结局不直接判泄漏，查实际输入 |
| O12 | 矛盾要求与不满意 | 提具体取舍问题或有差异的调整方向，不交给用户填表、不擅改硬约束 |

建议门槛：每案至少 2/3 达成其完整目标，总体至少 32/36；越权改真相、串入备选、隐藏输入泄露、假报提交、暂停后继续写入为严重失败，必须修复并重跑受影响案，不能被平均分抵消。每项问题保留原文依据和严重性，评分不只给总分。

这一门槛用于首版验收，不能据此宣称语义零错误。模型评分可以辅助，最终需要独立审阅，作者对易用性与文本质量的确认单独记录。
