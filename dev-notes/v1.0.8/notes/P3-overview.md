# P3 全书只读总览

日期：2026-11-02。对应 M4。

## 1. 交付

- 新增 `components/workspace/ObjectReadDetail.tsx`：构思与线索共用的只读详情；没有字段 setter、保存按钮、分类切换或关系表单；空字段不渲染。
- `WorkspaceDetail.tsx` 重写为读取器：节点显示构思内容、关键变化、时间、计划章节、用到的线索与已登记出处；线索显示作者意图、作者真相、正文出处与只读关系列表。
- 构思页默认改为按讲述章节分组的情节列表（`StorySurface.groupNodes`）；时间轴改为「查看时间轴」按需进入。
- 线索页默认显示全书列表与详情；关系图改为「查看关系图」按需进入。
- 移除 `StoryCreationDialog`；空构思入口只打开对话。输入区已有文字时不再写入建议要求，避免覆盖未发送内容。
- 移除正文选段的名称／用途表单与直接标记写入；删除前端 `markSelection` 表单写入路径和旧表单专用样式。

## 2. 读与写边界

- 详情只调用既有 `GET /story/variants/{v}/nodes/{id}`、`/prose-marks`、`/clues/{id}` 与 `/clues`；不新增编辑入口。
- 所有调整通过「讨论调整」进入对话；创建、改名、删除、关联与用途修改继续由对话工具和联合提交完成。
- 全书列表保留分页与搜索；随章列表不改变全书范围。
- 没有构思文件时，线索页与详情回退到账本读取，仍可查看与讨论；阅读与讨论都不建立主方案。

## 3. 验证

- `frontend/e2e/clueledger-workspace.spec.ts`：详情无输入框与保存按钮；线索关系图按需打开且无添加关系表单。
- `frontend/e2e/story-structure.spec.ts`：空白构思只进入对话，不弹创建表单，不覆盖已有草稿；时间轴默认不占用首屏。
- `frontend/e2e/clue-without-story.spec.ts`：无构思时账本线索可列、可看、可讨论，且不建立主方案。
- `frontend/src/components/story/storyOverview.test.ts`：讲述位置分组、计划章节兜底与未安排节点保留。
- 前端单元测试 351 passed（P5 删除旧线索引用动作后复核）；`npm run build` 通过。

## 4. 留白

- 节点详情的出处按绑定章节逐个读取，最多显示前 8 章；更多章节时提示「暂未显示」。没有新增节点级聚合读接口，避免超出本版计划。
- 时间轴与关系图仍是只读投影；没有拖动、补造时间或自动补边。
- 未做 200% 缩放与 320px 宽度专项；现有浏览器用例覆盖 390、640、1024、1440。
