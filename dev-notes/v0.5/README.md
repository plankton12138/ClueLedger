# Hastings 0.5 开发入口

当前运行版本为 `0.5.0`。本版将人物小传改为一名角色一个 Markdown 文件，并交付对话展示：
回复流式到达界面、思考与工具过程默认折叠、公开回复按 Markdown 阅读，可复制、展开与回到
最新位置。正文、线索和真相的组织方式沿用文件工作区，没有旧版小传兼容或迁移流程。

上下文与作品信息另有开发计划，覆盖章节名称、人物标签、本轮材料和带来源的章节索引；
会话压缩、预选项与专用可视化组件不在这两项计划范围。
