# Hastings 0.5 开发入口

当前运行版本为 `0.5.0`。本版将人物小传改为一名角色一个 Markdown 文件；正文、线索和真相的组织方式沿用文件工作区。没有旧版小传兼容或迁移流程。

模型对话框的流式、Markdown 阅读、默认折叠的思考与工具过程，以及复制回复、展开阅读和回到最新位置仍待实施。上下文与作品信息另有开发计划，覆盖章节名称、人物标签、本轮材料和带来源的章节索引；会话压缩、预选项与专用可视化组件仍不在这两项计划范围。
