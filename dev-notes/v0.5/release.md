# 0.5 运行与验证

当前包版本为 `0.5.0`。人物小传位于 `设定集/角色小传/姓名.md`，接入目录、搜索、只读阅读、
文件工具、Git 和模型按需读取。对话回复流式到达界面，思考与工具过程默认折叠，公开回复按
Markdown 阅读，可复制、展开与回到最新。目录与接口以[当前模块说明](modules/README.md)为准。

## 运行

在仓库根目录执行：

```powershell
uv run python -m hastings.server
# 或启动时预先打开作品
uv run python -m hastings.server --workspace <作品目录>
```

前端开发在 `frontend/` 执行 `npm run dev`，生产构建执行 `npm run build` 后由后端托管。模型连接在应用设置中配置；已有连接、凭据和会话机制沿用，不使用进程环境中的模型 Key。新建作品提供空角色目录以及线索、真相两份空文件。旧版汇总小传无兼容或迁移入口。

## 对话展示

- **流式**：模型增量按约 100 毫秒或约 1,024 字符合批写盘，写完才推给界面。界面上出现的
  文字刷新后仍在；没有增量的端点收到完整回复后一次展示，不伪造分段过程。
- **过程**：思考与工具默认折叠，运行中也只有一行状态。思考文本来自供应商实际返回的内容，
  没有返回时不显示面板；耗时是应用观察到的输出持续时间。
- **阅读**：公开回复按 Markdown 渲染，宽表与代码在栏内横向滚动，需要舒适阅读时用展开视图。
  复制得到该条回复的 Markdown 原文。
- **中断**：停止、厂商报错、输出上限、服务重启各自标记内容是否完整，已保存文字保留；
  重启只恢复已保存内容，不自动再次调用模型或工具。
- **重连**：连接断开后按 1、2、5 秒有限退避重连，仍失败时保留运行状态与「重新连接」入口。
- 下一轮模型输入仍只有作者提示与正式公开文本，思考与展示增量不进入上下文。

## 当前限制与未验证项

- 浏览器层面的确定性流式用例未接入：需要可脚本化供应商在真实服务内产生增量，本轮没有为
  测试新增这类开关。流式行为由后端受控用例与真实供应商走查覆盖。
- 断线重连只在状态层与后端用例覆盖，没有用真实网络中断在浏览器里复现。
- 供应商差异仅在实际调用过的 DeepSeek 一个模型上取证；思考展示取决于模型是否返回思考文本，
  其他模型未验证。
- 角色修改复用现有文件工具；没有调用真实供应商验证模型是否遵循「先读小传」的提示，没有
  执行桌面安装包构建。
- 角色改名不自动同步标题或正文人名，没有自动合并人物、人物关系图或文件监听。
- 预选项、方案卡、可视化组件、上下文压缩仍不在范围内，界面没有放占位按钮；上下文与作品
  信息见[独立计划](context-management-plan.md)。
