# 0.6 模块导航

当前运行实现为 **0.6 上下文与文件操作**，包版本 `0.6.0`。本版在 0.5 的文件工作区之上
增加：本轮材料的来源与版本核对、可选文件参考、本轮修改范围、章节索引、有原文依据的
只读检查，以及状态层（身份披露、人物状态、故事时间、专有名词、线索台账）与按用途分区
的上下文装配。没有变化的会话、连接和执行契约按下列具体链接读取，不从历史计划推断能力。
