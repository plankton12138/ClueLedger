# v1.2 验收计划：单入口写作与上下文指引

日期：2026-11-04。状态：**确定性实现已验证，单入口浏览器用例通过。2026-11-05 作者裁决：完整浏览器流程与在线模型评测豁免，本版收尾视为完成**。目标版本：1.2.0。

## 1. 核心判定

通过不能只看接口或单测存在，必须同时证明：

1. 作品意图整条链路已经退出；
2. `STRUCTURE.md` 是唯一全局语义提示；
3. 模块库为空时模型能建议创建，而不是要求作者先去模块库；
4. 接受或拒绝建议后都能自动继续原请求；
5. 主写作区只有对话输入能改变创作内容。
6. 未装模块通过名称、摘要和条目标题可发现，相关正文可以只读且不改变装配。

## 2. 确定性用例

### A. 删除与格式

| # | 用例 | 通过标准 |
|---|---|---|
| A01 | 新作品格式 | 创建格式 5；序列化结果没有 `book_intent` |
| A02 | 旧格式 | 格式 4 明确拒绝；不迁移、不写新文件 |
| A03 | 搜索残留 | 生产代码与前端不再出现作品意图接口、页面、错误码和辅助 kind |
| A04 | 空状态建章 | 无 variant 时建章联合初始化格式 5，无额外门槛 |
| A05 | 正文写入 | 不因缺作品意图或缺结构产生 HTTP 写入拒绝 |
| A06 | 路径保护 | 已登记章节仍不能绕过事务直接改正文路径 |

### B. 结构唯一来源

| # | 用例 | 通过标准 |
|---|---|---|
| B01 | 装配快照 | 全局语义分区只有 `STRUCTURE.md`；无 `book_intent`、`STYLE.md` |
| B02 | 空作品创作 | 结构写入成功后同轮 `structure_ready=true`，正文工具才放行 |
| B03 | 空作品讨论 | 只讨论时不创建结构 |
| B04 | 结构预算 | 6000 字符内直接写；超限先压缩，不要求作者处理 |
| B05 | 外部结构修改 | 下轮按磁盘现状注入；铁律标记缺失走已有降级说明 |
| B06 | 作者建章与导入 | 不存在 `/imports`、`/story/chapters`、`/story/chapters/adopt` 路由与前端入口；正文只由对话提交 |

### C. 模块目录与建议

| # | 用例 | 通过标准 |
|---|---|---|
| C01 | 空模块库 | 目录返回 `empty`；模型仍可提出 create 建议 |
| C02 | 无匹配 | 库非空但无相关项时可提出 create 建议 |
| C03 | 有匹配 | 返回精确版本元数据；建议 attach，不重复创建 |
| C04 | 元数据边界 | 目录结果没有条目正文或长预览 |
| C05 | 建议上限 | 一次 1—3 份；同轮第二次建议被拒绝 |
| C06 | 排除内容 | 作者明确“暂不需要”的资料不能出现在 proposal |
| C07 | 无必要建议 | 结构和已装模块足够时不产生问题卡 |

### D. 回答、授权与恢复

| # | 用例 | 通过标准 |
|---|---|---|
| D01 | 接受创建 | 只创建 proposal 列出的模块，装入作品并更新结构索引 |
| D02 | 接受装入 | 只装入 proposal 的精确版本，不改库 head |
| D03 | 拒绝 | 不创建、不装入；同一任务不再建议并继续原请求 |
| D04 | 自由发挥 | “你决定/自由发挥”采用最小推荐组合 |
| D05 | 修改建议 | 非明确接受的自由回答不直接执行；模型按回答收敛一次 |
| D06 | 原请求承接 | `carried_from_seq` 指向原作者请求，完成后继续该任务 |
| D07 | 重复回答 | 返回 `AUTHOR_QUESTION_ANSWERED_CONFLICT`，不重复创建 |
| D08 | 装配过期 | 回答前装配变化，旧问题失效，不在新状态上强行应用 |
| D09 | 中途失败 | 已完成子步骤被撤销，不声称完成；恢复成功后不用新模块自动继续原任务 |
| D10 | 新装配边界 | 模块应用轮在 `finalizing` 结束；续接轮冻结新 digest 后才读取模块或继续写作 |
| D11 | 进程重放 | 同一 question 只产生一份履行收据、一次模块提交和一个续接轮 |

### E. 单入口界面

| # | 用例 | 通过标准 |
|---|---|---|
| E01 | 空作品 | 默认展开并聚焦对话；主区显示“先定结构，再写正文”的提示与示例，不出现确认页或第二个创作输入；示例只填草稿 |
| E02 | 稿纸 | 正文只读；无 textarea、保存、续写和方向按钮 |
| E03 | 目录 | 顶部常驻只读全书结构并说明其作用；下方只有定位、章节改名与只读的「作品模块」折叠区；无新建章节、导入、把未登记正文并入章节或正文编辑 |
| E04 | 对话输入 | 默认没有“添加文件”选择器；选段和灵感仍可加入对话 |
| E05 | 上下文建议 | 复用问题卡，只显示原因、推荐组合和两个主要选项 |
| E06 | 响应式 | 宽屏对话常驻；窄屏切换不产生第二个创作输入 |
| E07 | 管理例外 | 模型设置、历史和撤销在项目菜单可用，不混入章节目录 |

## 3. 浏览器真实流程

### U01 空库：接受创建

1. 使用隔离空模块库创建新作品。
2. 粘贴“西部吸血鬼”完整提示。
3. 说“你自由发挥吧”。
4. 模型建立 `STRUCTURE.md`，建议创建“人物小传”和“故事背景”。
5. 点击“按建议创建并继续”。
6. 验证两份模块创建、装入、结构索引更新；无需再次输入，系统以新装配自动续接原任务。

不能发生：作品意图、设定卡确认、前往模块库、文件路径输入、`BOOK_INTENT_REQUIRED`。

### U02 空库：拒绝创建

执行 U01 到建议卡，选择“不创建，直接继续”。模型必须继续原任务，不再建议，也不能说缺模块无法完成。

### U03 有相关模块：建议装入

预置“人物小传：金·舒尔茨与姜戈”和不相关的雪山资料。模型只推荐相关精确版本；接受后下一轮实际读取
已装模块。不能读取未装正文、不能把不相关模块一起装入。

### U04 阶段性任务与排除要求

使用 `mynotes/my-prompts.md` 的“雪山温泉杀人事件”提示，当前要求只写人物小传，并明确暂不需要作案手法、
调查过程和刻画人物的情节。建议最多包含人物小传与人物关系/共同往事；不能创建真相、手法、调查或章纲模块。

### U05 单入口修改

完成一章后依次执行：

- “把开头改得更克制”；
- “新增下一章，先从尸检开始”；
- “把舒尔茨的底线调整为不主动伤害无辜者”；
- “撤销刚才的人物调整”。

所有修改都从同一对话输入发起；稿纸、目录和结构页无写入控件；回执能说明实际结果并撤销。

### U06 无模型

已有正文和结构仍可阅读，项目管理可用；对话说明需要连接模型。不能恢复手工构思或正文编辑作为绕过路径。

## 4. 在线模型评测

使用仓库 `.env` 的在线模型，不使用本地模型。每个模型先单例；失败修复后只重跑失败用例。

| # | 目标 | 判定 |
|---|---|---|
| O01 | 空库创建建议 | 识别跨章资料，推荐 1—3 份最小模块，不泛滥 |
| O02 | 相关模块装入建议 | 能从元数据找到相关项，不读取正文后再倒推 |
| O03 | 上下文足够时沉默 | 不为了展示功能而建议模块 |
| O04 | 排除内容遵守 | 不把“暂不需要”内容保存到模块 |
| O05 | 接受后承接 | 模块操作完成后继续原任务，不要求重输提示 |
| O06 | 拒绝后承接 | 不消极降级，不重复建议 |
| O07 | 结构先行 | 空作品正文任务先建立结构，同轮继续候选 |
| O08 | 纯讨论 | 不写结构、不创建模块 |
| O09 | 长篇连续写作 | 结构常驻、模块按需，人物和世界规则保持一致 |
| O10 | 语言体验 | 不使用模块 ID、字段、装配、注入等内部术语要求作者操作 |

保存完整输入、模型输出、工具事件、最终文件和装配快照。效果判定由产品行为与实际状态共同决定，不能只按
助手文字声称通过。

## 5. 质量门

P1—P4 每阶段跑受影响的定向测试；P5 执行一次必要的广泛回归：

- 后端：格式、写作动作、结构工具、问题恢复、模块库与装配、Agent 工具、活动记录；
- 前端：消息归并、问题卡、写作布局、目录、只读稿纸、响应式布局；
- 静态：ruff、mypy、前端类型检查与构建；
- 浏览器：1440、1024、760、390 宽度与 200% 缩放；
- 在线：O01—O10。

仅文档和版本号调整不重复跑后端全量。
