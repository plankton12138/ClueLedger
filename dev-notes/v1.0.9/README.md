# v1.0.9 开发入口：全书构思、连续稿纸与实时信息索引

日期：2026-11-02。目标版本：**1.0.9**。状态：**P0—P6 已实施；P7 验收与版本统一并入 v1.1，不再单独交付 1.0.9 版本号**（见 [v1.1 开发入口](../v1.1/README.md)）。当前主包与前端版本仍为 1.0.8；不得从本目录推断 v1.0.9 已经可用。

本版把正文、构思和线索收敛为一个写作工作区。全书构思是唯一的写作前置：章节建好就能直接写，章节内不再有构思输入与确认；线索、伏笔与回收由保存后的正文索引给出候选，作者只确认入账。所有创作性文本输入都同时提供人工与模型路径。视觉在现有基础上进一步统一为 Mac OS X Aqua 风格。

## 基线事实

- 基线提交为 `23f02ff`，运行版本为 1.0.8。
- `AppHeader.tsx` 仍提供正文、构思、线索三个入口；`navigation.ts` 仍使用 `story / clues / chapter` 三种写作模式。
- `WritingLayout.tsx` 在 `StorySurface`、`ClueSurface`、`Paper`、`ChapterContext` 之间切换；`Paper.tsx` 是只读 Markdown 阅读器，不是正文编辑器。
- 当前 `StoryVariant` 包含阶段、节点、线索计划、关系、时间和绑定等多类内部对象，作者仍需通过页面或对话理解这些概念。
- `files.py` 的 `write` 与 `create_chapter`、Agent 的 `write_file / edit_file` 是正文写入关键路径；现状没有统一的章节构思前置策略。
- v1.0.8 已有章节聚合、精确正文锚点、联合变更、会话受理、回执与撤销能力，应复用其来源校验、修订和提交语义。
