# Aqua 视觉强化跟进

日期：2026-11-02。状态：**已实施并完成前端定向验证**。版本仍为 1.0.8；P6 在线模型与正式发布未执行。

## 1. 反馈与原因

作者反馈当前前端与预期的经典 Mac OS X Aqua 仍有差距，并指向[少数派《Mac 视觉史（三）：浴“水”重生的 Mac 视觉美学》](https://sspai.com/post/60888)。实际页面已有银灰渐变，但高光弱、控件偏扁平方形、目录选中项偏实心蓝块，整体更像通用后台。

本次继续遵循 [Aqua 视觉实施规范](../style-document.md)：强化材质、受光和控件状态，但不增加假的系统标题栏、红黄绿窗口按钮、装饰性玻璃球或无功能高光。

## 2. 实际调整

- `frontend/src/index.css`
  - 扩展全局 Aqua token：银灰 chrome 增加细腻 pinstripe 纹理、顶部内高光和蓝色三段光泽渐变；普通控件增加默认、悬停、按下三套渐变与按下内陷阴影。
  - 顶栏、写作工具条、稿纸工具条、对话框标题、模块库头部、对话头部与输入区统一使用 chrome token。
  - 按钮与旧聊天按钮改为圆润胶囊，悬停增强高光，按下使用内陷和下移；主按钮保留白字与清晰蓝色边界。
  - 作品导航和分段控制改为胶囊容器；当前项使用蓝色光泽。
  - 列表与目录选中态改为浅蓝背景、深色文字和边界，不再使用整块实心蓝；写作目录同时铺满整行。
  - 下拉选择使用银灰控件材质；文本输入保留内凹底色与蓝色焦点环；滚动条改为 Aqua 蓝色胶囊。
  - 章节编辑器的工具条和稿纸组成连续稿纸组，正文仍保持平整、深灰衬线文字，不添加内容区渐变。
- `frontend/src/theme.ts`
  - 页面与工作区底色调整为更中性的银灰，与 Aqua chrome 和白色内容面板区分。
- `frontend/e2e/aqua-layout.spec.ts`
  - 增加 chrome pinstripe、胶囊按钮圆角和浅蓝目录选中的浏览器断言。

## 4. 边界

本次只调整视觉材质与共享控件状态，不改变写作流程、接口或数据。正文内容层继续保持低干扰稿纸；没有添加假系统外框、交通灯按钮或装饰性图标。后端与在线模型验收不属于本次改动范围。
