## 环境

## 主流程（`--phase main`）

```text
初始会话数： 0 ｜活动轮次： None
首次发送： 202 {"conversation_id":"c_dd7c5df0e2fd","turn_id":"t_8e7b752f",...,"title":"记住一条创作约束：这本书不允许出现超自然解释，所…"}
第一轮状态： completed
第二轮受理： 202 {"turn_id":"t_8ec2b3eb","conversation_id":"c_dd7c5df0e2fd",...}
第二轮状态： completed ｜记录： committed
第二轮改动： ['正文/0001 雨夜抵达.md', '设定集/真相.md', '设定集/线索.md', '设定集/角色小传.md']
章节文件： ['0001 雨夜抵达.md']
会话数： 1
```

第一次请求就同时建会话并受理首轮（没有空会话），第二轮在同一会话里按「刚才那条约束」继续写，产出章节与设定改动，并提交一次 Git：

```text
2dce53a 写作：按刚才那条约束，写第一章的开头，雨夜，侦探刚到旅馆。
c7c47cc 写作：记住一条创作约束：这本书不允许出现超自然解释，所有怪事都必须有人为原因。
aa27413 初始化作品目录
```

## 重启后继续（`--phase restart`）

停掉进程、重新启动同一个状态目录后：

```text
重启后会话数： 1 ｜恢复会话： c_dd7c5df0e2fd
重启后活动轮次： None
第三轮受理： 202
第三轮状态： completed
第三轮回复： 这本书不允许任何超自然解释，所有看起来怪异的现象都必须有一个真实的人为原因，
            即有人做了手脚、有人误判、有人撒谎，或者只是被误读的普通机制。
```

第三轮没有重新声明约束，模型复述出的正是第一轮定下的约束——说明跨轮上下文确实恢复了，而不是靠作品文件里的「创作铁律」（那条是模型第一轮自己写进 `设定集/真相.md` 的，第二轮之后才存在；第三轮回复的措辞与第一轮提示一致）。

## 新会话隔离

同一作品另开一个会话，问「能不能看到别的会话讨论过什么约束」：

```text
B 会话受理： 202 {"conversation_id":"c_9b60e92611ac",...}
B 会话状态： completed
B 会话回复： 看不到别的会话本身，只能看到这个工作区里留下的痕迹。
            **1. 我看不到的东西** 其他会话的聊天内容、讨论过程、谁提过什么方案……
            **2. 能看到的痕迹之一：git 提交标题** …
会话数： 2
```

B 只看到共享的作品文件与 Git 历史，看不到 A 的聊天与草稿——与设计一致（作品共享、聊天独立）。
