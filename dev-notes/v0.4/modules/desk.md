# 写作台界面

核对日期：2026-10-21。本文描述界面当前行为：顶栏、章节目录、只读稿纸、对话栏、改动与历史、作品位置的选择与新建（V04-7、V04-8），以及模型设置与日常模型选择（V04-9）。

## 1. 职责

界面直接反映作品目录：左栏是文件，中区是文件内容，右栏是对话与结果，抽屉是 Git 历史。所有数据来自 `/api/file-workspaces`，没有「只在前端成立」的能力——按钮背后都有真实接口。

界面不提供写正文的入口：修改走对话里的 Agent，或在应用之外的编辑器改文件。稿纸是只读的，这一点在 0.4 没有例外。

## 2. 布局

```text
顶栏：品牌｜作品目录选择｜打开 / 新建｜模型设置｜刷新｜改动与历史
左栏：搜索｜正文（章节目录 + 导入）｜设定集（三份固定文件）｜底部当前路径
中区：只读 Markdown 稿纸
右栏：对话（会话选择、当前连接与模型、事件过程、结果卡、输入框、停止）
对话框：作品位置｜模型设置（供应商 → 连接 → 模型）
抽屉：未记录的改动、工作区差异、历史、某次提交的差异
```

左栏只列真实存在的入口：正文各章与三份设定。没有大纲、时间线、第四类设定，也没有「候选」「采用」这类 0.3 的中间对象。

## 3. 打开与新建

- 「打开 / 新建」分两个页签：打开已有选「作品文件夹」，新建作品先选「存放位置」再填「作品名」。位置一律由系统文件夹对话框选出（由本机服务弹出），界面上没有可手输的路径框。
- 新建会建立 `正文/`、`设定集/`、三份空设定与 Git 基线提交，最终目录是「位置 / 作品名」；起始位置默认是系统「文档」目录。打开已有目录只读取，不初始化、不改写。
- 对话框里保留「最近打开」列表，点一条即按该目录打开，目录已不存在的登记会标注。
- 没有已打开目录时，中区显示打开提示，右栏留空。

## 4. 阅读与搜索

- 正文与设定共用同一个只读 Markdown 阅读器，`skipHtml` 关闭内嵌 HTML，避免正文里的标签被执行。
- 搜索逐行匹配正文与设定，结果显示路径、行号与摘录；点一条即打开对应文件。无法解码的文件单独列出。
- 外部编辑不会被推送：切回窗口或点「刷新」时重新扫描目录并回读当前文件。

## 5. 对话

- 输入框回车发送、Shift+Enter 换行；一轮进行中禁用输入并提供「停止」。
- 事件按 `seq` 显示：作者消息、工具调用（如「写入 正文/0001 雨夜.md」）、回复、错误。
- 结果卡分开显示执行状态与记录状态；已记录时提供「撤销这次修改」，未记录时提供「补记到历史」。
- 新会话按首条消息自动命名；左栏可切换历史会话。

## 6. 改动与历史

- 未初始化时显示「启用版本记录」，点击后建立仓库并记录当前内容。
- 显示未记录的改动（含未跟踪文件）、工作区差异、提交历史；点一条提交查看它的完整差异。
- 只有最新一次提交旁有「撤销」；后端会校验 HEAD 与工作区是否干净，界面不替它判断。
- 工作区差异不含未跟踪的新章节，抽屉里明确说明这一点，避免把「差异为空」误读成「没有改动」。

## 7. 模型设置与选择

- 顶栏「模型设置」是应用级入口：没有打开作品也能用。对话框左边是已保存的连接，右边按「选择供应商 → 填写连接 → 选择模型并保存」推进；编辑已有连接时跳过第一步。
- 供应商列表可搜索，来源是后端目录；「自定义服务」在末尾，地址与协议在高级设置里手填。需要选区域的服务（如通义千问）在预设里给出区域选项。
- 连接表单默认只显示名称与 API Key；地址与接口类型收在高级设置里。Key 输入框在编辑时留空表示沿用旧 Key，脱敏值不会被回填。
- 模型页提供「获取模型列表」与手动添加；作者勾选日常可用模型并选一个默认模型。获取失败时保留已有勾选与手填入口，并显示失败原因。
- 「测试响应」「测试工具调用」是独立按钮，旁边说明会发出少量请求；两种结果分开显示，测试结果随地址、协议、Key、模型的变化回到「未测试」。
- 保存连接不自动切换；列表里每个连接有「设为当前」，对话栏顶部也能直接切换「连接 / 模型」，列表末尾是「管理」入口。删除当前连接会先说明「会清空当前选择」。
- 没有可用模型时，输入区上方提示「连接模型后开始对话」并给「去设置」入口；已输入的草稿保留，配好后由作者自己点发送。
- 凭据只能存系统存储或内存降级时，对话框顶部提示「Key 只在本次运行有效，重启后需重新填写」。

## 8. 当前缺口

- **没有真实浏览器内的创作走查**：界面构建、状态与组件行为有测试覆盖，真实模型链路在接口层取证，未在浏览器里逐屏点完一轮创作。
- **没有 token 级流式**：回复在模型结束后整条显示，没有打字机效果。
- **没有自动刷新**：只在切回窗口或手动刷新时重新扫描，没有文件系统监听。
- **小屏未适配**：当前是固定三列，宽度不足时左栏与对话栏会挤压；0.3 的响应式规则没有迁移。
- 0.3 的写作台组件与状态仍在源码中，默认页面已不引用，待 V04-5 清理。
