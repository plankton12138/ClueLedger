# 写作台界面

核对日期：2026-10-21。本文描述界面当前行为：顶栏、章节目录、只读稿纸、对话栏、改动与历史、作品位置的选择与新建（V04-7、V04-8）、模型设置与日常模型选择（V04-9）、会话切换与任务归属（V04-10）、三栏宽度与对话栏显隐（V04-11），以及 iOS 6 浅色视觉（V04-12）。

## 1. 职责

界面直接反映作品目录：左栏是文件，中区是文件内容，右栏是对话与结果，抽屉是 Git 历史。所有数据来自 `/api/file-workspaces`，没有「只在前端成立」的能力——按钮背后都有真实接口。

界面不提供写正文的入口：修改走对话里的 Agent，或在应用之外的编辑器改文件。稿纸是只读的，这一点在 0.4 没有例外。

## 2. 布局

```text
顶栏：品牌｜作品目录选择｜打开 / 新建｜对话开关｜模型设置｜刷新｜改动与历史
左栏：搜索｜正文（章节目录 + 导入）｜设定集（三份固定文件）｜底部当前路径
中区：只读 Markdown 稿纸
右栏：对话（会话选择与改名、当前连接与模型、事件过程、逐轮结果卡、输入框、停止）
对话框：作品位置｜模型设置（供应商 → 连接 → 模型）
抽屉：未记录的改动、工作区差异、历史、某次提交的差异
```

左栏只列真实存在的入口：正文各章与三份设定。没有大纲、时间线、第四类设定，也没有「候选」「采用」这类 0.3 的中间对象。

三栏宽度可以调整：目录栏与对话栏内侧各有一条 6px 宽的把手，按住左右拖动改宽度，双击恢复默认（目录 260、对话 380）；聚焦把手后方向键微调、Home 复位。宽度限制在目录 180–400、对话 280–560，超出按边界停住。宽度与对话栏显隐记在浏览器本地存储里，重开窗口保持。

顶栏「对话」开关收起或展开右栏。收起后只是不渲染对话面板，中区接过它的宽度；会话状态在另一份状态里，重新展开时草稿、事件与运行状态都还在。

## 3. 打开与新建

- 「打开 / 新建」分两个页签：打开已有选「作品文件夹」，新建作品先选「存放位置」再填「作品名」。位置一律由系统文件夹对话框选出（由本机服务弹出），界面上没有可手输的路径框。
- 新建会建立 `正文/`、`设定集/`、三份空设定与 Git 基线提交，最终目录是「位置 / 作品名」；起始位置默认是系统「文档」目录。打开已有目录只读取，不初始化、不改写。
- 对话框里保留「最近打开」列表，点一条即按该目录打开，目录已不存在的登记会标注。
- 没有已打开目录时，中区显示打开提示，右栏不显示。

## 4. 阅读与搜索

- 正文与设定共用同一个只读 Markdown 阅读器，`skipHtml` 关闭内嵌 HTML，避免正文里的标签被执行。
- 稿纸横线画在随内容滚动的内层，不是滚动容器的背景，所以滚动时线格跟着正文移动。线格周期与段落行高一致，段落区大致对齐；标题、列表高度不是行高倍数，跨过它们后按装饰处理，不强制对齐。
- 搜索逐行匹配正文与设定，结果显示路径、行号与摘录；点一条即打开对应文件。无法解码的文件单独列出。
- 外部编辑不会被推送：切回窗口或点「刷新」时重新扫描目录并回读当前文件。

## 5. 对话

- 输入框回车发送、Shift+Enter 换行；当前会话的一轮进行中提供「停止」。
- 事件按 `seq` 显示：作者消息、工具调用（如「写入 正文/0001 雨夜.md」）、回复、错误。
- 结果卡按轮次挂在它自己的位置后面，分开显示执行状态与记录状态；已记录时提供「撤销这次修改」，未记录时提供「补记到历史」。
- 「新对话」只切到临时输入状态：没有提示就不建会话。输入了没发送就切走，内容作为「新对话草稿」保留，入口标「草稿」。
- 切换会话会先保存当前草稿再读另一份；每个会话的草稿互相独立，切换不停止服务器任务。
- 另一个会话正在进行时，输入区提示「「标题」还在进行」，发送按钮不可用；切回那个会话可以查看进度或停止。
- 第一个会话按首条提示自动命名；「改名」可以随时改标题，后续轮次不会覆盖。列表按最近活动排序，排序变化不改变当前选择。
- 刷新或重启后回到上次查看的正式会话，并恢复该会话的运行状态；不会自动发送草稿，也不会自动重跑中断的轮次。

## 6. 改动与历史

- 未初始化时显示「启用版本记录」，点击后建立仓库并记录当前内容。
- 显示未记录的改动（含未跟踪文件）、工作区差异、提交历史；点一条提交查看它的完整差异。
- 只有最新一次提交旁有「撤销」；后端会校验 HEAD 与工作区是否干净，界面不替它判断。
- 工作区差异不含未跟踪的新章节，抽屉里明确说明这一点，避免把「差异为空」误读成「没有改动」。

## 7. 模型设置与选择

- 顶栏「模型设置」是应用级入口：没有打开作品也能用。对话框左边是已保存的连接，右边按「选择供应商 → 填写连接 → 选择模型并保存」推进；编辑已有连接时跳过第一步。
- 供应商列表可搜索，来源是后端目录；「自定义服务」在末尾，地址与协议在高级设置里手填。需要选区域的服务（如通义千问）在预设里给出区域选项。
- 连接表单默认只显示名称与 API Key；地址与接口类型收在高级设置里。新增时连接名称已预填供应商名（重名加序号），作者可以直接往下走，也可以先改名。编辑时 Key 输入框留空表示沿用旧 Key，脱敏值不会被回填。
- 模型页提供「获取模型列表」与手动添加；作者勾选日常可用模型并选一个默认模型。获取失败时保留已有勾选与手填入口，并显示失败原因。
- 「测试响应」「测试工具调用」是独立按钮，旁边说明会发出少量请求；两种结果分开显示，测试结果随地址、协议、Key、模型的变化回到「未测试」。
- 保存连接不自动切换；列表里每个连接有「设为当前」，对话栏顶部也能直接切换「连接 / 模型」，列表末尾是「管理」入口。删除当前连接会先说明「会清空当前选择」。
- 没有可用模型时，输入区上方提示「连接模型后开始对话」并给「去设置」入口；已输入的草稿保留，配好后由作者自己点发送。
- 凭据只能存系统存储或内存降级时，对话框顶部提示「Key 只在本次运行有效，重启后需重新填写」。

## 8. 视觉

- 整体是 iOS 6 拟物浅色：金属拉丝顶栏、浅灰织物工作区、米白稿纸；没有暗色模式切换。
- 目录栏是浅灰底上的白色行，选中行用蓝色高光渐变并把文字转白；正文与设定集两组各有一个小标题。
- 对话栏是浅色面板：作者提示在右侧绿色气泡里，Agent 回复在左侧白色气泡里；工具调用是小字行，失败标红；每轮结果卡完成时绿底，部分完成、失败、停止与中断为琥珀底，状态文字与记录状态都在卡内写明。
- 输入框、搜索框、会话选择与重命名都用内凹的浅色输入井；按钮沿用凸起高光样式，主操作（发送、新建并打开）用金色。
- 颜色事实源是 `src/theme.ts`（纯色令牌）与 `src/index.css`（渐变、内阴影、组件类）；页面不再写内联色值。
- 浮层（作品位置、模型设置、改动与历史抽屉）与主界面同一套浅色样式。

## 9. 当前缺口

- **没有真实浏览器内的创作走查**：界面构建、状态与组件行为有测试覆盖，真实模型链路在接口层取证，未在浏览器里逐屏点完一轮创作。
- **没有 token 级流式**：回复在模型结束后整条显示，没有打字机效果。
- **草稿不做多窗口合并**：两个窗口同时编辑同一草稿时按版本先到者为准，后到者的文字保留在本地并提示。
- **不能从其他会话直接停止**：进行中的会话在列表里标「进行中」，要停止需切回该会话。
- **没有自动刷新**：只在切回窗口或手动刷新时重新扫描，没有文件系统监听。
- **小屏未适配**：三栏宽度可拖、对话栏可收起，但没有响应式重排；窗口过窄时中区会被挤压，需要手动收对话栏或缩目录栏。
- **稿纸宽度固定**：正文区限制在 `max-w-3xl`，收起对话栏后两侧留白较大，是为保持阅读行宽。
