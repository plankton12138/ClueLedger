# 故事资料（0.7）

资料页回答四个问题：有哪些资料、依据哪些章节、现在是否可用、如何补充或重新整理。
它是只读页面：正文与设定仍由对话修改；作者明确启动的整理任务只发布派生资料，不获得
作品写权限。

## 页面与导航

- 顶栏主导航为**写作**与**故事资料**；活动记录保留原入口。不开放独立「检查报告」页面，
  也不显示未开放的导航或占位按钮。对话内的检查与报告回看按 0.6 契约继续工作。
- 故事资料左侧导航：**章节概览、人物、时间线、线索与伏笔、名词表**。
- 页面位置放在 hash 里：`#/workspaces/{id}/writing`、
  `#/workspaces/{id}/materials/{section}?chapter=8&entry=...`。刷新、前进后退与从证据返回
  都按 URL 恢复；未登记的作品回到当前作品，不把 URL 当成读取本机任意路径的指令。
- 切换页面不重建会话状态：写作草稿、参考、当前文件与运行状态都保留。
- 「查看截至第 N 章」只控制浏览时点，默认全书末章；它不修改写作任务的截止章。

## 作者视图

`GET /api/file-workspaces/{id}/story-materials/{domain}` 返回条目、证据、覆盖统计、实际
采用的时点，以及本时点可选的章节与人物。`domain` 取六个值：

| 域 | 页面 | 条目 |
|---|---|---|
| `chapter_index` | 章节概览 | 一章一条：摘要、事件、人物、时间地点、线索与证据 |
| `disclosure` | 人物（身份） | 一人一条：社会身份、别名、读者已知、未到期披露、作者计划 |
| `roster` | 人物（状态） | 一人一条：位置、生死、立场、最近核对章与落后章数 |
| `timeline` | 时间线 | 一章一条：原文时间说法、跨度、地点；没有锚点的章显示「时间未知」 |
| `clues` | 线索与伏笔 | 一条线索：埋设章、计划章、状态、超期与回收依据 |
| `glossary` | 名词表 | 一个词：正名、别名、类别、首次依据章、来源与冲突 |

- 条目 ID 由域与稳定键散列得到，详情用 `GET .../story-materials/{domain}/entries/{id}`
  按 ID 取；不接受任意磁盘路径当记录标识。
- 人物没有核对记录时，`alive` 返回 `null`（未知），不用 `true` 冒充「还活着」。
- 名词表完整返回作者数据，搜索与分类在作者视图上执行，不受模型注入预算的 24 词限制。
- 列表支持 `q` 与 `cursor`；`next_cursor` 为空表示没有更多。搜索、截止章或域变化时
  前端重置分页。

## 覆盖与有效性

三个状态分开表达，不合并成一个「状态」：

| 维度 | 取值 |
|---|---|
| 整理覆盖 | `found`（有结果）、`empty`（已整理无发现）、`insufficient`（信息不足）、`unrecorded`（未整理） |
| 版本有效性 | `valid`、`stale`（来源已修改）、`source_missing`（来源已删除）、`unavailable`（无法读取）、`none` |
| 执行状态 | 已受理、运行中、完成、部分完成、失败、已停止、中断 |

- 覆盖记录存作品状态目录的 `materials-coverage.json`，键为「资料域 + 正文路径 + 人物路径」。
  记录带提交时的正文指纹；正文一改，这条覆盖即失效，空结果也一样。
- 覆盖的最小单位：章节概览/时间线/名词/线索为「域 + 正文路径」；身份与人物状态为
  「域 + 人物路径 + 正文路径」。只整理第 6—8 章时，不宣称第 1—5 章已整理。
- 统计按截止章内的目标计算：章节域以章节数为总量，人物域以「人物 × 章节」为总量。
- 没有覆盖信息的旧记录显示「未整理」，不从一条锚点推断整章已核对；升级时不自动启动模型。

## 整理任务

`POST /api/file-workspaces/{id}/material-tasks` 受理一次整理，请求体是请求键与范围：

```json
{
  "request_key": "…",
  "scope": {
    "domain": "timeline",
    "chapter_paths": ["正文/0006 归途.md"],
    "entity_paths": [],
    "as_of_chapter": 8,
    "observed_digests": {"正文/0006 归途.md": "…"}
  }
}
```

- 一次只更新一个域；人物页的身份披露与人物状态是两次独立任务。人物域必须同时给
  1–10 份小传与 1–10 个章节，其他域不接受人物目标。
- 服务端重新核对真实路径、章序唯一性、截止章、文件存在性与指纹。章序重复（两个文件
  同号）按冲突拒绝；目标章超出截止章按输入错误拒绝；`observed_digests` 与当前不符时
  提示重新读取资料页。
- 受理冻结范围与依赖版本，返回 `turn_id`、`conversation_id`、`origin=materials`、
  实际模型与范围。HTTP 202 只表示已受理。
- 资料任务使用专用会话（`origin=materials`），不挂在当前写作会话上；写作会话列表默认
  不列它们，任务通过资料页与活动记录回看。创建会话、受理与响应丢失的处理沿用轮次
  服务：同一请求键只对应一次任务。
- 作品级互斥与写作共享：作品忙时返回 `WORKSPACE_BUSY_CONFLICT`，不排队。
- 完成度由服务端目标清单与已发布结果计算：正常结束但仍有目标没有提交结果，任务记为
  **部分完成**；模型回复「已经整理完」不算完成。

### 工具权限

资料任务只装配目录、搜索、读取与该域唯一的结果提交工具（`publish_material_result`）。
没有 `write_file`、`edit_file`、`move_file`、`delete_file`，也没有检查报告工具。

- 提交目标必须是本次范围内的章节；人物域另要求小传在范围内。域不一致、目标越界、
  证据来自未来章都会被拒绝。
- 发布前要求目标当前全文已通过 `read_file` 提供，人物域还要读完小传；证据区间、引文、
  章号与指纹沿用既有校验。
- `found` 必须带记录，`empty` / `insufficient` 必须不带记录并写一句说明；章节概览有正文
  时必须提交摘要，不能用空结果绕过。
- 空结果只写覆盖记录，不写域存储：没有发现不等于清空已有记录。

### 上下文

资料任务使用独立的装配档（`materials`）：只装任务要求、作品目录与本次范围说明，不装
设定集、谜底、作者计划与旧索引摘要。范围说明列出资料种类、目标章节与人物、截止章、
必须读完的文件与完成条件；已有记录单独标为「待核对，不是当前依据」。

## 接口

| 接口 | 用途 |
|---|---|
| `GET /story-materials/{domain}?as_of_chapter&q&limit&cursor` | 作者视图：条目、证据、覆盖、实际时点、章节与人物清单 |
| `GET /story-materials/{domain}/entries/{id}?as_of_chapter` | 完整条目与证据；找不到返回 404 |
| `POST /material-tasks` | 受理整理，返回任务与会话标识 |
| `GET /material-tasks?domain&limit` | 本域最近任务，含仍在运行的任务 |
| `GET /material-tasks/{turn_id}` | 规范化目标结果、进度、未完成项与 `conversation_id` |
| 既有会话事件订阅与停止接口 | 持续进度与停止；不新增第二条 SSE 协议 |
| 既有受管文件读取接口 | 读取当前原文 |

旧 `/state`、`/chapter-index` 与已保存会话事件继续兼容；它们只服务既有调用，不用于
新页面。

## 前端模块

| 模块 | 职责 |
|---|---|
| `state/navigation.ts` | 主页面与资料位置的 hash 解析、生成与订阅 |
| `api/storyMaterials.ts` | 作者视图、条目详情、任务受理与查询的类型与请求 |
| `state/storyMaterials.ts` | 按作品、域、截止章与查询缓存；迟到响应丢弃；切作品清空 |
| `state/materialTasks.ts` | 受理、请求键复用、事件进度、停止与结果回读 |
| `components/materials/StoryMaterialsPage.tsx` | 页面容器、五页列表与详情、截止章与整理按钮 |
| `components/materials/ChapterRangePicker.tsx` | 本次章节与人物范围选择（1–10 章，默认预选未整理或失效章） |
| `components/materials/MaterialTaskBar.tsx` | 当前任务条：范围、模型、已处理目标数、停止与活动记录 |
| `components/materials/EvidencePane.tsx` | 原文依据、失效说明、打开原文与带到对话 |

资料任务不使用写作会话的 `send()`：发送会清空草稿并切换选中会话。任务订阅放在作品级
状态层，离开页面只停止数据读取，不停止已经受理的任务。字号仍使用既有 80%–150% 偏好。

## 兼容与限制

- 旧派生记录可读；没有覆盖信息时显示「未整理」。升级不自动启动模型，也不自动补跑。
- 资料任务不自动重试；失败或停止保留已发布的目标，由作者重新选择未完成范围。
- 时间线只有章级锚点：不解析日期、不按日历排序、不推断同章多事件的先后。
- 名词与线索的同一目标只保留最近一次发布的依据，不做多来源贡献合并；重建某章不会
  删除其他章节仍有依据的条目（不同键各自保留），但同一条目在另一章的旧依据会被覆盖。
- 不提供手工资料编辑器、关系图、自动整理、自动修稿或跨任务队列。
