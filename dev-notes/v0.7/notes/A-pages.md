# A：页面结构与阅读基础

目标：把资料管理从覆盖写作台的多层抽屉改成独立页面，保留阅读位置、会话与草稿。

## 实际改动

- 新增 `frontend/src/state/navigation.ts`：hash 路由类型、解析、生成与订阅；只接受登记
  过的作品 ID、枚举内的资料页与整数章号。
- `WorkspaceShell` 增加「写作 / 故事资料」主导航；作品选择、写作页与资料页按 URL 同步；
  URL 里的作品未登记时回到当前作品。
- 删除 `ChapterIndexPanel.tsx`、`StatePanel.tsx` 及其入口；顶栏「索引」「状态」按钮移除。
- 「刷新」改为作品操作中的「重新读取文件」，资料页另有「重新读取资料」。
- 新增 `components/materials/StoryMaterialsPage.tsx` 容器：左侧资料导航、截止章选择、
  覆盖摘要、任务条与内容区；窄窗口下导航横排、详情改为上下排列。
- 新增 `.materials-nav` 样式，沿用暖白内容区与蓝灰界面。

## 接口与数据影响

本阶段只读：作者视图接口在阶段 B 一并接线。没有新增写路径。

## 取舍

- 用 hash 而不是 History API：静态托管与桌面入口都不需要服务器页面路由，刷新与前进
  后退由浏览器直接支持。
- 资料页不显示对话栏：资料整理任务与写作草稿是两件事，隐藏对话避免误以为任务挂在
  当前会话上。

## 验证

- `npx vitest run src/state/navigation.test.ts`：解析、非法输入与往返。
- 走查截图 `artifacts/walkthrough-v07/01-chapters.png`、`08-1024.png`、`09-narrow.png`。
- 走查断言：从资料页返回写作后草稿仍在；页面没有「检查报告」「章节索引」「状态面板」。
