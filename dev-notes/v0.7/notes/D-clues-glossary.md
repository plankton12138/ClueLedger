# D：线索与名词表

目标：补齐两页只读视图与独立任务，处理跨章线索、稳定 ID、重复名称与冲突。

## 实际改动

- 线索页：按「未回收 / 已回收 / 已废弃」分组；超期项标「已超期」；详情显示埋设章、
  计划章、回收章与指向；证据同时包含埋设处与回收处。
- 线索任务允许整理回收章时更新已有线索的回收字段；提交的埋设证据必须来自埋设章，
  回收证据必须来自回收章，发布前逐条复核。
- 名词表：人物姓名来自小传声明（来源标「人物小传声明」），地名、组织、物件来自正文登记；
  别名与冲突逐项显示，不自动合并。
- 名词与线索条目 ID 由「域 + 内容」散列，不随排序变化。
- 空结果只写覆盖：某章读完没有新名词，不删除其他章节仍有依据的条目。

## 接口与数据影响

沿用阶段 B 的接口；新增 `clues`、`glossary` 两个域的条目结构与发布分支。

## 取舍

- 计划回收章与「已废弃」只接受作者在任务中给出的值，模型不能凭「读完后没再出现」设定。
- 同一目标只保留最近一次发布的依据，不做多来源贡献合并；不同键的条目互不影响。

## 验证

- 确定性测试：空结果不写域存储、空结果随来源失效、域与目标越界拒绝、覆盖统计。
- 走查 `04-clues.png`、`05-glossary.png`（空分组与声明词条）。
