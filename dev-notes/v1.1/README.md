# v1.1 开发入口：全对话创作

日期：2026-11-03。目标版本：**1.1.0**。状态：**方案冻结，P0—P5 待实施**。当前运行版本仍为 1.0.8。

本版在 v1.0.9 拆门槛成果上，把作品链路收敛为全对话：对话是唯一输入面，作者不手写任何作品内容；正文只由模型产出，稿纸退位为阅读面；一切修改经「模型暂存执行 → 对话回显差异 → 作者一次确认」落盘，可整体撤销。0.3 时期「2026-10-20 写作台再收拢裁决」的方向在本链路正式兑现。无可用模型时作品链路如实说明，不提供手写绕过（作者裁决）。

**v1.0.9 处置**：其 P0—P6 已实施；P7 验收并入本版 P5，不再单独交付 1.0.9 版本号，运行版本自 1.0.8 直接提升为 1.1.0。理由：本版会撤除 1.0.9 刚建成的手写编辑面，先做其完整在线验收是重复投入。
