# v1.1 验收计划：全对话创作

日期：2026-11-03。状态：**待执行**。目标版本 1.1.0。判定口径随用例冻结，执行时按实际交付修订并保留历史记录。

## 1. 前期流程用例（UC-D01—UC-D08）

共用故事材料沿用 [v1.0.9 可用性用例](../research/ideas-clues-usability-cases.md) 的《雪夜旅馆》设定；受训数据污染防护规则不变。

| # | 用例 | 应当发生 | 不能发生 |
|---|---|---|---|
| UC-D01 | 引导提问起步 | 一次只问一个问题；每问可跳过；随时可说「就这样开始」；问题数不超过上限；未知保持未知 | 追问时间线、人物关系等内部属性；为完整而补造结局 |
| UC-D02 | 自由发挥起步 | 一句话产出设定卡候选；确认后写入意图、门槛通过 | 设定卡未经确认进入正式数据；确认后仍出现意图输入框 |
| UC-D03 | 首章起草 | 空正文经对话起草；采用候选后正文入稿纸；页边索引正常 | 作者为起草打开任何输入框；候选自动写文件 |
| UC-D04 | 一句话修改 | 说一句改动 → 回显三要素（改了什么、影响哪里、基于哪个修订）→ 确认 → 联合提交；整体撤销后正文、意图、索引一起恢复 | 确认前产生任何正式变更；撤销只恢复一半 |
| UC-D05 | 驳回与再改 | 驳回后暂存丢弃无残留；再说一句可重新发起 | 驳回后残留半状态；旧暂存覆盖新修订 |
| UC-D06 | 无模型状态 | 作品链路如实说明需要模型设置并给入口；已有内容只读可见 | 出现绕过对话的手写路径；散布禁用按钮 |
| UC-D07 | 结构提议 | 建章提案确认即建章（含可选标题）；标题想改回对话说一句 | 作者填写任何章节字段；建章失败留半登记 |
| UC-D08 | 索引时点 | 暂存期间页边索引不更新；确认落盘后才出现候选与出处 | 未确认正文被当作已入账信息；索引沿用旧结果冒充最新 |

## 2. 统一记录指标

| 指标 | 通过标准 |
|---|---|
| 零手写 | 作品链路全程无输入框（对话输入除外）；灵感与模块库不受影响 |
| 零内部概念 | 作者不需要理解章节构思、信息线、对齐等概念即可完成第一章 |
| 确认语义 | 确认前零正式变更；确认后联合提交、可整体撤销 |
| 回显完整 | 每次修改回显差异三要素；未回显的暂存视为未完成动作 |
| 恢复能力 | 撤销、驳回、过期、刷新、重启后无半状态 |
| 降级处理 | 环境故障明确归因；不调模型猜 |

## 3. 确定性矩阵

覆盖：起步双模式上限与跳过、设定卡确认幂等与撤销、起草候选采用与过期、暂存执行模式（全写入路径无绕过）、确认 / 驳回 / 撤销、索引时点、建章提案事务、无模型错误码、并发修订。全部走隔离新作品，不迁移旧数据。

## 4. 浏览器走查

从空作品连续完成：引导提问 → 设定卡确认 → 对话起草第一章 → 阅读面与页边索引 → 说一句修改 → 回显差异 → 确认 → 撤销。覆盖 1440 / 1024 / 760 / 390 宽度与 200% 缩放；对话与索引的辅助区切换不丢阅读位置；无模型状态页。
