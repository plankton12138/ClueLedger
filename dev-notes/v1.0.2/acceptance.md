# 1.0.2 验收计划

日期：2026-10-30。状态：**A01—A15 确定性边界已实现并通过；在线验证（§3）与作者体验验收待执行**。计划编写和示例代码不算实现或测试通过。

## 1. 确定性边界

| 编号 | 场景 | 必须证明 |
|---|---|---|
| A01 | DeepSeek 模型列表字段 | 已有解析器正确识别 `context_window` 与 `max_output_tokens`，发现→保存→重启保留，模型 ID 不错配 |
| A02 | 官方 DeepSeek 无已存元数据 | 两个精确 ID 从目录得到 W=1048576、O=393216；目录携带官方依据 |
| A03 | 元数据比目录容量小 | 元数据优先，有效输入不超该连接实际公布的限制 |
| A04 | 未收录模型、自定义中转无元数据 | W 为 null，B=128000，预算状态和自动压缩正常，不冒用原厂窗口 |
| A05 | 小窗口 W=16000、R=4096 | S=800，B=11104；不能套用 128000 扩大容量 |
| A06 | 仅 I 已知、W 未知 | B=min(P,I)，窗口仍未知；仅 O 已知不能推算 W |
| A07 | 配置与容量无效 | bool、字符串、零、负数、非正窗口剩余明确失败，不静默回退到更大预算 |
| A08 | 输入预算边界 | B=128000 时，115199 不触发、115200 触发；128000 可容纳、128001 进入处理；系统/工具/协议开销均计入 |
| A09 | 无法缩小的必要输入 | 压缩或裁剪后仍超 B 时在网络请求前拒绝；当前原话、有效摘要、最新完整工具单元不截断 |
| A10 | 摘要和其他阶段 | 未知 W 的摘要也按 B 分段；无工具摘要、检查、结构操作和连接生成测试都有实际预算检查 |
| A11 | 冻结与恢复 | 受理后改 P/模型不改变该轮；暂停继续、手动压缩和重启按既有统一操作规则恢复预算，不自动付费重跑 |
| A12 | 估算与实际参数 | R 同时约束 provider 参数与预算；小 O 下正确收紧，四类协议适配构造均检查 |
| A13 | 用量与接口 | 新字段贯穿事件、运行/空闲投影和 JSON；空闲估算不被摘要请求覆盖；策略改变使估算指纹失效 |
| A14 | 纯读取 | 打开容量面板、刷新、读取接口均不调模型、不写入会话事件、不读取密钥 |
| A15 | 配置往返 | 策略默认及显式值能加载、保存；编辑连接不丢策略；不新增手填模型容量入口 |

优先扩展现有 `test_model_limits.py`、`test_model_probe.py`、`test_context_usage.py`、`test_context_boundaries.py`、`test_activity.py` 和用量接口/统一操作恢复测试。测试放在真实执行边界，不能仅复制计算公式；尤其要断言过大请求没有到达 provider。

## 2. 页面与联调

- 已知 W：主区域显示约 19023/128000、14.9%，明细显示模型窗口 1048576；页面与真实后端响应联调。
- 未知 W：主进度仍依据 B；明细仅模型窗口显示未获取，不出现“无法判断余量”覆盖项目预算的说明。
- 首轮前估算 null、未选择模型、空闲重建、压缩中/成功/失败、停止与暂停继续分别验证。
- 快速切会话、切作品、切模型、迟到响应和刷新不能串用旧分母；运行中明确冻结模型归属。
- 输入超过 B 时文字不截断，进度条不溢出；320/640/1024/1440 宽度和 150% 缩放可读，保留键盘和停止入口。
- 沿用 `frontend/e2e/context-usage.spec.ts` 并核对测试白名单；受控接口页面测试与真实后端联调分别留证，不相互替代。

## 3. 在线验证

使用 `.env` 中已授权在线模型，不使用本地模型。实施后按当前评测工具契约建立最小专项用例，以下是验证场景，不是可直接执行的现有命令。

1. 调用官方模型列表，脱敏保存目标模型容量字段，并与目录和页面对照；这是元数据读取，不伪装成生成评测。
2. 发起小规模真实对话，核对身份、B、R、请求估算、真实供应商用量和页面响应；不为验证 1M 窗口而填满窗口。
3. 在隔离测试状态中将 P 调小，使用合法完整历史跨越 90% 阈值，观察真实自动摘要和之后的完整请求。P 必须足以容纳系统与工具固定开销，不能通过删掉必要说明让场景通过。
4. 小预算下执行工具往返、压缩失败后继续、暂停继续；断言保存改动不重复执行，记录实际路径与失败。

记录模型、日期、代码指纹、预算配置、所有尝试、摘要调用数、输入/输出、耗时及未知用量。价格没有可靠来源则不估算金额。不以某次更快、更便宜证明默认 128000 最优；确定性注入拒绝也不能称为真实服务商自然溢出。

在线前后对照用于发现默认预算带来的退化。已有裁剪语义风险和摘要损失需保留观察；本版不宣称消除。无法取得指定官方服务访问权限时如实标未执行，不以其他中转结果替代官方容量实测。
