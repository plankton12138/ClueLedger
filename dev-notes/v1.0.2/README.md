# 1.0.2 开发入口：上下文容量与输入预算

日期：2026-10-30。状态：**实现完成，待在线验证（验收 §3）与作者「窗口与预算」体验验收**。目标发布版本为 `1.0.2`；当前主包与前端版本仍为 `1.0.1`，版本号按验收 §4 在发布门槛达成后同步。

本版解决模型容量没有识别时，页面只显示未知、请求也缺少项目输入上限的问题。模型容量作为供应商事实，项目预算作为应用策略；运行中的页面、压缩和请求检查使用同一份受理快照，空闲页面读取当前容量与预算，切换模型后等待新的输入估算。
