# 2026-11-01 删除结构视图与阶段筛选

构思页做减法：只保留悬疑时间轴，不再提供第二套结构展示与筛选入口。

## 删除范围

- 「悬疑视图 / 结构视图」切换按钮，以及结构画布、画布滚动条、故事线表头与阶段折叠。
- 顶部阶段筛选按钮（全部 / 各阶段标题）与对应提示；时间轴内的阶段分组标题保留。
- 节点详情面板：包含「写这一段」「引用到对话」、线索真实作用、知情与正文依据。
- 节点详情接口 `GET /story/nodes/{node_id}`、前端详情状态、构思引用状态与对话中的构思引用 chip。
- 前端依赖 `@xyflow/react`、`elkjs`。

## 交互变化

- 时间轴节点标题仍可点击，但只用于让左栏全书线索按该节点过滤，不再打开详情或切换视图。
- 写正文改由对话发起；从正文校准与撤销上一次保留。
- 节点详情删除后，原「引用到对话」入口不再存在；当前选中节点仍随构思页的下一轮普通消息进入请求。

## 验证

- 前端 30 个测试文件、337 项单测通过；`tsc --noEmit` 与 `npm run build` 通过。
- `tests/workspace/test_story_api.py` 21 项通过。
- 浏览器 `story-structure.spec.ts` 9 项通过：无结构视图与阶段筛选、节点过滤左栏线索、窄屏与大字号、线索联动、多作品切换。
