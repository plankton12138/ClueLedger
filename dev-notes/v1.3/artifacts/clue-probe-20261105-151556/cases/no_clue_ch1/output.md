# 第一章 雨夜

末班车在青石桥头停住，车门开了一半卡住，司机用脚踹了两下才滑开。

“到这儿就到头了。”司机没回头，“前头塌方，明天早上才有人清。”

雨从车门外斜着灌进来。林远把帆布包抱在胸前跳下车，鞋底落进水里，没过脚面。车灯扫过一段石阶，又收回去，尾灯在雨里红了一小会儿，没了。

石阶往下是青石街。两边铺面都上了门板，只有檐下几盏灯笼亮着，纸糊的，被雨压得往下坠。他数门牌：十五号，一家关了门的杂货铺；十九号，卷帘门上贴着“旺铺转让”；中间是一段青砖墙，墙头长草，没有十七号。

他退回来，又数了一遍。十五，墙，十九。

伞是司机借的，黑布，断了一根骨，撑开是歪的。他把信封从内袋里摸出来，就着灯笼看。纸面被雨气洇开一小片，字是圆珠笔写的，力很重，把背面划出了印子：青溪镇 青石街十七号。邮戳模糊，只能看清一个“七”字。

街尾还有一块招牌亮着，四个字，最后一个“社”字的灯管坏了半边，一明一暗。门虚掩着，缝里漏出光和收音机的声音，是评书，说书人正说到“且听下回分解”。

林远推门进去。

屋里比外面暖。柜台后坐着一个女人，四十来岁，头发在脑后用一个黑夹子夹住，正低头剪一沓纸。她抬头，把剪刀放下。

“住店？”

“住店。”林远把伞收在门边，水顺着伞尖在水泥地上淌出一条线，“多少钱一晚？”

“六十。押金二十。”女人翻开柜台上的一本硬壳登记簿，抽出夹在里面的圆珠笔，笔尾拴着一根红绳，绳头用图钉钉在柜面上，“身份证。”

林远把身份证递过去。女人看了一眼，又看了一眼他，低头写。她的字很快，横平竖直。

“六号房。”她撕下一张收据，用剪刀裁齐，“热水到十一点。楼道灯是声控的，跺一脚就亮。”

林远数出八十块，钱在柜面上摊开，女人一张一张捻过去，捻完把钱压进一个铁皮盒。他伸手去拿登记簿上的笔，女人先一步把本子翻到了新的一页。

“我写就行。”

翻页的时候，林远看见上一页的最后一栏。姓名那一格空着，后面写着房号“6”，日期“7.14”，再往后是退房时间，也是空的。

墙上挂着一只钟，白瓷盘，黑指针，停在十一点四十。钟摆不动。

“钟停了？”

“停了好些年了。”女人把钥匙推过来。白铁钥匙，木头牌子，牌子上用烙铁烫了个“6”。

门边的小方桌旁坐着一个人，灰夹克，背对着柜台，正在吃面。桌上一个搪瓷大碗，碗沿磕掉了一块瓷。他吃得很慢，筷子挑起来，吹两下，再送进去。左手小指短了一节，伤口早就长平了。

林远把信封从内袋里又摸出来，摊在柜台上。

“大姐，问一下。青石街十七号在哪儿？我数了两遍，十五号完了就是墙。”

女人把钥匙往前推了推，指头压在木牌上。

“这条街没有十七号。”她说，“从前也没有。”

方桌那边，筷子在碗沿上磕了一下。很短的一声，接着又开始吸面。

林远把信封收回去，捏着钥匙转身。楼梯在左手边，木头的，一共十一级，第四级中间凹下去一块，像被很多人踩过。转角处放着一个红色塑料桶，桶里积了小半桶水，天花板上一滴一滴往下掉，落进去，声音很匀。

二楼走廊尽头还有一扇门，门后头有人走动，拖鞋底擦着地板，一下，一下，来回三趟。

六号房在走廊中间。锁眼有点涩，他拧了两次才开。

屋里一张单人床，一条军绿色棉被，叠成方块。一张两屉桌，桌面上一个暖水瓶、一只倒扣的搪瓷盆、一个玻璃烟灰缸，缸底有一点干掉的水。窗户是木框的，合不严，风把窗帘吹起来一角，又落下去。

窗外是一栋同样的两层楼，隔着一条窄巷，对面黑着，只有最东边一扇窗亮着灯，灯光照在玻璃上，看不见里面。

林远把帆布包放在床沿，坐下，床板响了一声。他把信封里的东西倒在桌面上：一张火车票，一张写着电话号码的纸条，还有一张折了两折的收据，纸边发毛。

抽屉的把手是铜的，拉第一下没拉动，卡住了。他两只手抠住两边，往外一使劲，抽屉开了，里面滚出来半盒火柴，红色火柴盒，印着“前进”两个字。

还有一张照片，两寸，黑白的，边角有点卷。

照片上一个女人站在一扇门前。那扇门他认得，就是楼下这扇：门框左边有一块补过的水泥，右脚台阶缺了个角。女人二十来岁，白衬衫，头发到肩，两手垂在身侧，看着镜头，没有笑。

他把照片翻过来。背面是蓝圆珠笔写的一行字，笔画浅，压得也轻：

97.7.14 云来

楼下传来一声轻响，是柜台的抽屉被推回去。

窗户那边，对面楼最东边那扇窗的灯，灭了。
