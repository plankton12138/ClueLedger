# 锁孔

前台说锅炉坏了，302 今晚没有热水。林远要了一只手电。

锅炉房在楼梯底下，门虚掩着。他用肩膀顶开，铰链响了一声，潮气涌出来，像有人把一块湿布按在他脸上。

手电光照出去发黄。锅炉是冷的，铁壳上积着灰，灰面上有一道擦痕，从炉门一直划到墙角。地上的煤渣被踩出一条路，往里去，又折回来。

墙角蹲着一只铁柜，深绿漆。锁孔周围剥掉一圈，露出底下的红漆。

林远把钥匙从口袋里摸出来。铜牌在钥匙圈上转了半圈，磕在手背上。他蹲下去，把钥匙举到锁孔边。齿缝里嵌着一点暗红，薄薄一层，像从谁那儿刮下来的。锁孔下方缺了一角，缺口里的漆也是红的。

他把钥匙插进去。涩，转了半圈，咔哒。

柜门开了。上层空着，灰上有一个方印子，像是放过什么，被拿走了。下层摆着一只火柴盒、一叠单据、半截蜡烛。

火柴盒是旅馆的，盒面印着“雾山旅馆”，四个字印得歪。林远抽开盒屉，里面剩六根火柴，梗上有捏过的痕。盒屉底上有一行铅笔字，很小：302。

他翻那叠单据。都是煤单子，年月的字迹被水汽泡发了。最底下一张不是单据，是一页信纸，只写了半行，划掉了，划得很用力，纸背都戳穿了。能认出来的只有头一个字：别。

走廊上有脚步。

林远把火柴盒和那页信纸塞进口袋，关柜门，钥匙拧回来拔出来。铜牌撞在柜门上，响了一声。

门被推开。老周站在门口，端一盏煤油灯，灯从下往上照着他的脸。

“你怎么在这儿。”老周说。

“锅炉停了。”林远说，“前台说 302 没有热水。”

老周把灯举高，光扫过锅炉、煤渣、铁柜。他的目光在锁孔上停了一下。

“柜子锁着的。”他说。

“现在开着。”林远说。

老周把灯放在煤堆上，走过来，拉开柜门。他看了一眼空着的上层，又看一眼下层，伸手拿起火柴盒，晃了晃，放回去。

“你拿了什么。”他问。

“火柴。”林远摊开手。六根火柴躺在掌心里。

老周看了一眼，嘴唇动了动。“这盒是我放的，防停电。”

“盒底写着 302。”林远说。

老周把煤油灯从煤堆上拿起来，换个手端着。“嗯。”他说，“锅炉明天修。今晚冷，回房多要一床被子。”

他走到门口，停下，不回头。

“柜子的钥匙，明天还我。”

“这不是柜子的钥匙。”林远说。

“现在它是了。”老周说。门在他身后合上。

林远把手电照到锁孔上，又照了照手里的钥匙。齿缝里那点暗红还在。

他上楼。走廊顶灯只亮着一盏，302 的门牌在尽头。他站定，掏出房门钥匙开锁，进屋，摸墙上的开关，灯没亮。

手电扫过桌面。桌角空着——他出门前搁在那儿的火柴盒，不在了。

### 自查

**必发生核对**
作者补充为“（无）”，无自列必发生项；按计划线索清单，本章两项必发生：回收 CL-03、回收 CL-07。
- CL-03（旧钥匙）：正向锚在“他把钥匙插进去。涩，转了半圈，咔哒。”，回收动作落在“齿缝里嵌着一点暗红……锁孔下方缺了一角，缺口里的漆也是红的”与结尾“齿缝里那点暗红还在”。
- CL-07（火柴盒）：回收动作分两处落锚——“下层摆着一只火柴盒……盒屉底上有一行铅笔字，很小：302”与结尾“桌角空着——他出门前搁在那儿的火柴盒，不在了”。
建议：若作者另有必发生项，请补骨架；本节不猜。

**铁律自查**
- 不写心理分析：全篇为动作、对白、物件。擦边两处——“像有人把一块湿布按在他脸上”是明喻，“像是放过什么，被拿走了”是物件推断，均未写“他意识到/他感到”，在边界内。
- 林远在第 5 章之前不得知道真相：本章他仅取得实物（钥匙开柜、盒底 302、划掉的信纸），没有拼出事件经过，没有获知谁做了什么，未越过边界。擦边处：结尾 302 门牌与盒底“302”的呼应已足够让读者自行连线，但林远本人没有下判断，合规。

**读者认知**
- 误读立住处：老周“这盒是我放的，防停电”可被读成看守人的解释，读者会疑其说谎；“现在它是了”可读成强硬，也可读成遮掩，两种读法都立得住。
- 提前起疑风险：盒底“302”与结尾门牌“302”相距很近，敏锐读者会当场锁定“有人进过林远房间”。可执行修改：本章只写“盒屉底上有一行铅笔字，被磨得只剩几个数”，把“302”延到下一章林远对光细看时再读出。
- 第二处建议：老周“这不是柜子的钥匙／现在它是了”一来一回已把钥匙归属挑明，疑点透支；可改为老周只说“明天还我”，把“这把钥匙到底开什么”留到第 6 章。

**线索核对**
- CL-03：本章落锚并回收，动作与登记一致；第 2 章失联锚点“回到房间，他把钥匙放在桌上。铜牌……”虽未逐字复述，但钥匙＋铜牌在本章三处出现（摸出钥匙、铜牌磕手背、铜牌磕柜门），可据此重锚到本章，建议在登记层同步。
- CL-07：本章落锚并回收。系统记录其第 3 章“声明埋设但无 planted 记录”的哑火，本章以“同一只盒出现在铁柜、房内那只消失”补上因果，建议登记时把埋设点补挂到第 3 章对应段落，避免继续悬空。
- 新埋线索：拟把“划掉的信纸，只余‘别’字”作为新线索，埋设段落为本节“最底下一张不是单据……能认出来的只有头一个字：别。”一句；如不打算续用，请登记 retired 并写明理由。
