# 湿手套

水还在。

林远蹲下去，把手指按在门缝下的地毯上，指腹压出一小圈深色。水不凉，接近室温，边缘已经干了一半，剩下中间一条窄窄的湿痕，从门缝底下伸进来，像有人用湿布沿着缝隙拖了一道。

他拿过桌上的便签本，撕下一页，折成三角，插进门缝。纸角很快洇湿。他推到最里面，再抽出来，纸尖上沾着一点灰白的绒毛，还有两粒发白的粗沙。

他起身开门。

走廊里只亮着两盏壁灯，楼梯口的天窗是黑的。地毯上一行浅浅的印子，不是鞋印，是布片按下去又抬起来那种，断断续续，往楼梯方向去。他沿着走，走到楼梯口前一公尺，印子拐了个弯，进了走廊尽头那扇挂着「布草间」木牌的门。

门没锁，一条缝里透出潮湿的暖气和洗衣粉的味道。

布草间里堆着叠好的床单、五条毛巾、一只塑料桶。桶里泡着两条抹布，水面上浮着几粒沙。靠墙的塑料筐里搭着一副手套。

林远把它挑起来。

那是一只劳保手套，掌心一面是灰胶，指节处磨得发白，食指和中指的胶皮裂开了口子。手套是湿的，不滴水，握在手里能压出水汽。他把手套翻过来，内侧的棉布衬里沾着细沙，靠近手腕的松紧口上有一圈深色印子，像被水泡久了的线。

他把自己那张便签纸摊在架子上，纸角上的沙粒抖在掌心，又从手套衬里捻下两粒。颜色一样，都是发白的粗沙。

筐底还压着一只。右手那只，同样湿，同样沾沙，拇指处缺了一小块胶。

「你在这儿干什么？」

门口站着阿珍，旅馆的帮工，手里端着一只搪瓷盆。她看见林远手里的手套，脚步顿了一下，把盆放在门边的架子上。

「这手套谁的？」林远问。

「我的。洗碗、擦地都用。」阿珍走过来，把筐往墙边推了推，「昨天洗床单湿了，晾这儿。」

「你夜里来过三楼走廊？」

「三楼？没。」她说，「三楼地毯我隔天才吸一回，今天没轮上。我十点半就回后院了，老板娘知道。」

林远低头看手套。

「这沙哪儿来的？」

「海边吹上来的。这镇上一到下半夜就刮风，沙子往窗台上扑。」阿珍把手套从他手里抽走，往筐里一丢，「你房间门底下也进水了？我待会儿给你拿条毛巾堵上。」

「门缝里的水，」林远说，「和你这手套上的水，一样的。」

阿珍看了他一眼，没接话。她端起搪瓷盆往外走，到门口才回头：「林先生，你订到哪天？」

「后天。」

「后天的房钱，老板娘说得先结。」她把门带上，脚步声往楼下去了。

林远把那只右手手套又拿起来。缺胶的拇指处露出棉布，边缘磨得起了毛。他把手套摊在架子上，张开手掌比了比，比他的手长出一指半。

他回房，把便签本上那张湿了角的纸翻过来，画了一条从门缝到布草间的线，标了三个点。做完把纸夹进本子，塞进旅行箱夹层，拉好拉链。

走廊尽头传来拖把撞墙的声音。他打开门，阿珍正跪在走廊那行水印上，用抹布一下一下地擦。她擦到楼梯口，把抹布在桶里涮了涮，水面上浮起一层灰。

「不用擦，」林远说，「留着看看。」

「老板娘说了，客人看见地上有水不好。」

「阿珍。」楼梯下方有人喊。

阿珍提着桶下去了。林远站在门口，看地毯上被擦掉一半的水印。剩下那一段从门缝伸出来，到楼梯口就断了——再往前，是刚被抹布抹过的深色。

他关上门，蹲下再看门缝。纸角还卡在里面，湿透的一截贴在地毯上，水没有再往里渗。
