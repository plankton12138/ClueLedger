# 空房

林远拿钥匙捅207的门。锁芯涩，拧了两下才开。

房间里没开灯，窗帘拉着。他摸到墙上的开关，啪一声，顶灯亮了。单人床靠墙，被子叠成方块，枕头搁在上面，没有压痕。床头柜上放着一只玻璃烟灰缸和一盒火柴。

他走过去，拿起火柴盒。红底，金字，印着“云来旅馆”。盒子轻，摇一摇，里面有哗啦声。翻开盒盖，火柴码得齐整，一根没少。他翻过盒子看底部，磷面上有指甲划痕，横竖交叉，竖在中间，左边三道横，右边三道横。

门外有脚步声。一个五十来岁的男人站在门口，穿着旅馆的灰工装，手里拎着一串钥匙。

“你哪间的？”

“205。”

“205在楼下。你上二楼干什么？”

“前台说207可以看看。”

“哪个前台？”

“姓刘的，圆脸。”

男人看了一眼走廊尽头。“小刘让你来的？”

“她说207空着，门没锁。”

“门是没锁。锁芯坏了，今天刚修好。”男人走进房间，看了一眼床头柜上的火柴盒，“你动过了？”

“拿起来看了看。”

男人伸手把火柴盒拿过去，翻过来看了一眼盒底的划痕。“上个月的客人划的。”

“上个月有客人住207？”

“住了一晚，第二天就走了。落了只火柴盒在床头柜上。”

“你说门没锁，锁芯今天刚修好。客人上个月落的火柴盒，你前天打扫的时候没看见？”

“看见了。没扔。”

“为什么没扔？”

“旅馆的东西，扔了要赔。”

“那为什么现在还在床头柜上？”

“你问我我问谁。”男人把火柴盒放回床头柜，“你赶紧下去。207不让待。”

“你叫什么？”

“老周。值夜班的。”

林远看了一眼门锁。锁孔边上有一道新鲜的金属划痕，锁芯亮铮铮的，确实像新换的。

“锁换过了。”林远说。

“今天下午换的。”

“换锁的师傅呢？”

“我就是。”

“你下午换锁，晚上接着值夜班？”

“我替老陈。他今天有事。”

“那你手里这串钥匙，哪把是207的？”

老周把铜钥匙抽出来。“这把。旧钥匙配新锁芯，能开。”

“锁芯换了不换钥匙，不白换吗？”

“防盗。锁芯换了，旧钥匙开不了。”

“你刚才拿这把钥匙开的门。”

老周停了一下。“我换锁芯没换彻底。里面那个卡簧有问题，旧钥匙还能进去。明天再换。”

“新锁芯有问题，你还锁上？客人来了打不开怎么办？”

老周把钥匙拔出来，没接话，直接出了门。林远跟出去，站在走廊上。老周锁了门，拿手拽了两下把手。

“锁好了。你下去吧。”

“火柴盒给我。”

“那不能给你。旅馆的东西。”

“我住205。你把207的火柴盒送一只到我房间去，说是旅馆赠送的。”

“207不送。送了乱套。”

“那你把这只给我当纪念品。”

老周看了他一眼，从兜里掏出火柴盒，拍在他手里。“拿了走。”

林远把火柴盒装进口袋，下楼。老周跟到楼梯口就没再跟。

前台小刘正在看手机。

“退房。205。”

“好的先生。”她抬头看他，“207看过了？”

“看了。老周在楼上。”

“老周？”小刘看了一眼墙上的钟，“他六点就下班了，现在快十二点了。”

“他说替老陈值班。”

“老陈今天没请假啊。老陈十一点来的，在楼下值班室呢。”

“那老周在楼上干什么？”

“我不知道。他可能加班修锁吧。”

林远把火柴盒掏出来放在台面上。“这个在207捡的。”

小刘看了一眼。“火柴盒？我们不用火柴了。”

“你们招牌上写云来客栈。火柴盒上写云来旅馆。”

“老板以前换过招牌。火柴盒是旧货。”

“207空了大半个月，哪来的旧火柴盒？”

“客人落下的呗。”

“老周说上个月底有个客人住了一晚，落下的。”

“上个月底？”小刘翻了一下登记本，“没有啊。207一直空着。上个月只有201和203住过人。”

林远把火柴盒收好。“房费多少？”

“三百六。”

他给了钱，出了旅馆。走到街上，雨停了。他从口袋里掏出火柴盒，对着路灯又看了一眼盒底的划痕，然后数了一遍火柴，九根。

他把盒子翻过来。背面的电话号码下面印着地址：柳巷街47号。他抬头看了一眼旅馆门牌。柳巷街47号。

地址没错。

他把火柴盒装回口袋，往巷口走。走了十几步，停下来回头看了一眼旅馆二楼。207的窗户没亮灯，但窗帘拉开了一道缝，缝里有一截黑色的影子，竖直着，没动。他转回头，走进巷子里。

雨又下起来了。

### 自查

1. **必发生核对**：本章计划线索为回收CL-07火柴盒。正文对应位置：开头“床头柜上放着一只玻璃烟灰缸和一盒火柴”→中段“上个月的客人划的”→“落了只火柴盒在床头柜上”→末段“老周看了他一眼，从兜里掏出火柴盒，拍在他手里”→结尾“盒底的划痕”“火柴，九根”。核心动作（发现—被夺—追讨—到手）完整，火柴盒的物证属性（划痕、数量、地址印字）与前台登记本矛盾均有落点。但需注意：CL-07的“埋”在台账上无记录（见第4条），因此本章的“收”实际缺少前期铺垫，回收动作成立但读者缺乏前期印象，建议在第3章正文中补一处火柴盒的可见描写，或在本章回收时用一句简短回顾补锚（如“林远想起昨晚走廊地上那只火柴盒”），目前无此句。

2. **铁律自查**：
   - 不写人物心理分析：全章未出现“他想”“他觉得”“心里一紧”等心理描写。可观察的动作、对白、物件贯穿全文，如“他摸到墙上的开关，啪一声”“男人伸手把火柴盒拿过去”“林远数了一遍火柴，九根”。
   - 林远在第5章之前不得知道真相：林远在本章只获取了三条事实——①207有火柴盒且被人划了痕；②老周自述与登记本矛盾（老周说上月底有人住、小刘说207一直空着）；③火柴盒地址与旅馆门牌一致、火柴数量为九根。他没有做出任何真伪判断，没有点破老周说谎，没有得出“老周有问题”的结论。结尾只有“一截黑色的影子，竖直着，没动”，属观察而非认知推断。铁律未破。

3. **读者认知**：当前读者的误读基础是——207“空房”里出现不该出现的火柴盒，老周作为值班人员的说法前后矛盾（“上个月客人落的”vs 小刘“207上个月没人住”），读者会自然怀疑老周与207有关。这一误读立得住，因为正文中老周的可疑行为（在楼上声称值班、被拆穿后不接话、随意把证物塞给林远）足够支撑。提前起疑的风险点：结尾“窗帘拉开一道缝，缝里一截黑影”略偏灵异暗示，可能让读者从“有人在隐瞒”滑向“有鬼”，冲淡了现实悬疑的张力。建议修改：将“一截黑色的影子，竖直着，没动”改为更具体的可观察物（如“窗帘缝里露出一截黑色雨伞的尖，滴水”或“缝里亮了一下，像手机屏幕的光”），保持现实指向。

4. **线索核对**：本章计划线索CL-07（火柴盒）在本章有回收动作——林远到手火柴盒，盒底划痕被两次描写，物证属性（九根火柴、地址印字、划痕形状）已锚定在正文段落中。回收动作本身与计划一致（本章为回收章）。但系统对账显示CL-07在第3章无planted记录，这意味着本次回收缺乏前章埋设，读者对火柴盒的首次印象是在第4章才建立。按计划线索该埋未埋属前章遗留问题，本章已用回收动作尽量兜底，但建议在第3章正文中补一笔火柴盒的出现（哪怕是一句“走廊地上扔着一只红底金字的火柴盒”），否则第4章的回收在结构上仍是悬空收束。
