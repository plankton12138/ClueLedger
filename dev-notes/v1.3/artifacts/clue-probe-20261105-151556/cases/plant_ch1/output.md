# 第一章 雨夜

雨是下午四点开始下的，到了晚上九点，整条山路上只剩下雨声。林远把车停在旅馆门口时，前轮已经蹭到边沟里，溅起的泥水糊了前灯。他熄火之后又在座位上坐了一会儿，直到又一片雨落下来敲在车顶上，才推开门。

旅馆的招牌是木头的，字迹被雨水泡得发胀，“云来”两个字只剩上半截。门廊下挂着一盏灯，光黄得发锈，照得雨丝全是斜的。

玻璃门推起来很沉。柜台后面没人，一只老式搪瓷缸搁在账本上，缸口缺了一块瓷。林远收伞，把伞立在门口的铁皮桶旁边，伞尖的水很快在瓷砖上洇出一小片。

“有人吗？”

走廊深处传来一声门轴响，然后是脚步。一个五十来岁的男人走出来，灰夹克，手在裤子上蹭了两下。

“住店？”男人走到柜台后面，把搪瓷缸挪开，露出下面的登记本，纸页受潮，边角卷着。

“还有房间吗？”

“有。就剩二楼靠里那间。”

林远掏出身份证放在柜台上。男人拿起来对着灯看，翻了个面，又对着灯看。登记本翻开一页，笔尖戳在纸面上，墨水洇开一小团。

“林远……从哪儿来的？”

“市里。”

“这个天还往山里跑。”

男人把身份证推回来，钥匙从身后墙上的木板上摘下来，木头牌子，铜钥匙，牌子上用刀刻了个“２”。

这时楼梯上传来响动。一个女人走下来，手里拎着一只方形皮箱，棕色，四个角包着铜，箱扣是浅黄铜的。她走到柜台边，把箱子放在地上，箱子落地时闷响了一声，箱扣上有一处漆没补，露出底下发暗的铜色，像是被什么东西磕过。

“钥匙放这儿了。”她对男人说，声音不高。

“走啊？这雨——”

“车在门口，东西搬了两趟了。”女人看了林远一眼，没有点头，也没有笑，目光在他湿透的肩头停了一瞬，又回到箱子上。

男人从抽屉里摸出几张零票递过去。女人数了数，对折塞进外套内袋。她弯腰拎箱子时，手在箱扣上按了一下，那处缺漆的位置被手指盖住又露出来。

“梁姐——”楼梯上又下来一个人，二十出头，短发，穿一件大了两号的矿工雨衣，下摆滴着水。“后座还塞得下吗？”

“塞得下。你先去把车打着。”

年轻人从林远身边挤过去，门开时灌进一团冷雨，雨衣蹭过林远的手臂，布料冰湿。门关上之后，年轻人站过的地方留下三滴水的印子，很快被踩散了。

“她也住这儿？”林远问。

“住了四天。”男人把钥匙推过来，“二楼左转，热水到十一点。”

林远拿起钥匙，铜的，齿槽里有一点绿锈。他上楼的时候听见身后女人说：“梁姐，那箱子搁后座靠左，别压着。”

二楼的走廊很短，四扇门，两扇锁着。墙纸起泡，有一处翘了边，露出底下的白灰。他找到“２”号门，钥匙转了两圈才开。

房间不大，一张床，一桌一椅，窗子正对着后山，全是黑的。他开灯，灯绳拉了一下没亮，拉第二下才闪起来。桌上有一层薄灰，灰上有四个圆印子，像是之前放过一张方凳。

他放下包，换了件干衬衫，把湿衣服搭在椅背上。窗外雨声更密了，打在瓦檐上噼噼啪啪的。他推开窗试了试——正对着楼下的后院，院里停着一辆深色面包车，一个人正往后备箱里塞东西，雨衣帽子翻下来，是刚才那个年轻人。后备箱里已经塞了不少行李，他用力按了按箱盖才扣上。

林远关了窗，把窗帘拉上。布帘子很薄，透出车的尾灯闪了两下，然后引擎发动的声音，在雨里闷着响了一会儿就远了。

他坐到床边，正对着门。门锁是老式的，锁舌只卡进去一半。他伸手把锁钮拧了拧，拧到底才卡紧。

楼下传来男人咳嗽的声音，然后是搪瓷缸碰在柜台上的脆响。再然后，有人在走廊里走动，脚步很轻，经过他门口没有停，继续往走廊尽头去了。尽头是另一扇门，锁着的。脚步声到了门口，停了。大约半分钟，又原路返回，这回比刚才快，带着一点急促。

林远听着那脚步下了楼，才躺下来。床板很硬，弹簧一翻身就响。他把手枕在头下面，盯着天花板上那块水渍，形状像一只歪着的鞋印。

楼下的女人在说话，隔着一层楼板听不真切，只听见“明天”“码头”两个词。男人回了一句什么，女人声音高了点：“那就别让他看见后座。”

然后安静下来，只有雨。十点半，走廊尽头的门响了一声，有人开了那扇锁着的门，进去，又关上。

林远闭上眼。钥匙在床头柜上放着，铜的，凉。

   - **提前起疑风险**：“码头”与“别让他看见后座”两句之间的闭合过于连贯，读者可能直接跳过“箱扣缺漆”这一物理线索而锁定“藏匿物品”方向，使 CL-01 显得像冗余描写。可执行修改：将“码头”改为更日常的“镇上”，或把“别让他看见后座”改为女人对年轻人单独说的“把东西放好”，切断两句之间的因果暗示，让缺漆箱扣独自承担埋线功能。
   - 修改建议：正文末段“楼上女人说‘明天’‘码头’”处，可替换为“明天”“镇上赶集”等低信息量词，避免提前触达运输类猜测。
