# 第 3 章 箱扣

雨落在铁皮雨棚上，一阵紧，一阵松。檐口的水连成线，砸在楼下水泥地上，溅起来的水星子贴到玻璃上，再慢慢往下淌。

七号房在三楼拐角。门框上的漆掉了一小片，露出底下的木头。林远把钥匙插进锁孔，转了两圈，锁舌咔地一声，门开了。钥匙上挂着一块铜牌，牌上刻了个“七”，边缘磨得发亮。

屋里一张单人床，一张两屉桌。桌上摆着一只搪瓷脸盆，盆底的红双喜掉了一半。暖水瓶立在墙角，瓶塞上盖着叠好的毛巾。窗户糊了半扇报纸，剩下那半扇玻璃上有一道裂缝，贴着透明胶带。墙上挂着一本挂历，翻在三月份。

他把帆布箱子提进来，搁在行李架上。箱子四角包铜，箱扣是黄铜的，漆还亮。他扳开箱扣，掀盖，摸出毛巾和牙刷，合上，把箱扣按回去，咔哒一声。箱扣朝外，在灯下亮着一小块。

走廊里没有声音。楼下漏上来一线灯光，落在楼梯口的墙上。

他下楼要热水。柜台后面没人，登记簿摊开着，他那行字还没干透。他往上看，上面有一行字被划掉了，横着一道墨，墨迹压得很实，把底下的名字盖住了。

灶间在楼梯背后，有铁壶碰灶沿的响。

“有人吗？”

“水还没开。”老人的声音从灶间里出来，闷闷的。

林远站在柜台前等。柜台上摆着一只算盘、一个玻璃罐，罐里是水果糖，还有一盏罩子熏黑的煤油灯。登记簿旁边没有笔。

“笔在抽屉里，自己拿。”老人又说。

抽屉在柜台左边，木头的，铜搭扣。他伸手去扳，搭扣上缺了一块漆，缺口的边翘着细毛刺，刮过他的虎口。

他拉开抽屉。里面有几支秃头铅笔、一支钢笔、一叠收据、一把断齿的木梳，角落里躺着一枚黄铜箱扣。

箱扣上的漆掉了一大块，掉漆的地方露出铜色，和搭扣缺口露出的是一个颜色。两个螺钉还拧在扣上，其中一个螺钉头上连着一小截木屑，木屑的颜色比抽屉的木头浅。箱扣背面有一道横划痕，划得很深。

他把箱扣拿起来，翻了个面，又放回原处，位置差了一指宽。他拿了那支钢笔，把抽屉推回去，搭扣扣上，响了一声。

老人提着水壶从灶间出来，看见他站在柜台边上。

“笔找到了？”

“找到了。”

老人把水壶放在柜台上，壶嘴冒着白汽。抽屉没关严，露着一条缝。老人伸手推了一下，把搭扣按紧。

“那扣子，”林远说，“是从箱子上撬下来的。”

老人把水壶往他那边推了推。“客人留下的。”

“店里还有别的客人？”

“没有。”老人说，“半个月没来人了。”

他弯腰从柜台底下抽出一块抹布，擦柜台上的水渍，从登记簿那边擦过来，一直擦到手边。

“扣子扔了吧。”他说。

林远旋上笔帽，把钢笔搁在登记簿旁边。

“热水提上去，洗完脸早点睡。”老人说，“后半夜雨更大。”

他提起水壶上楼。走到第二个平台，回头看了一眼，老人还站在柜台后面，背对着楼梯，抽屉拉开了一条缝。

七号房里，他把水壶放在桌上，倒了半盆水。洗脸的时候，水声盖住了雨声。

他把箱子从行李架上取下来，放在床脚，箱扣朝墙。窗户上那半扇报纸被风掀起一个角，又贴回去。

楼下，铁皮雨棚上响了一声，像有什么东西被风刮上去，滚了两下，停了。
