# 雨夜

雨从傍晚开始下，到晚上九点没有停。

林远把车停在旅馆门前的碎石地上，熄了火。雨刷停在挡风玻璃中间，水顺着玻璃一层一层往下淌，把门口那盏灯拉成一条竖着的黄线。

招牌是铁皮的，“雨夜旅馆”四个字里，“夜”字左边那一点不亮。

他从后备箱拎出旅行袋，抱在胸前，跑上三级台阶。门是玻璃的，推开时有一股潮味扑出来。前台在左手边，一盏台灯亮着，灯罩歪向一侧。台灯后面坐着一个女人，四十来岁，灰色毛衣，袖口卷到小臂。她在看一本翻旧了的杂志，听见门响，把杂志合上，压在台灯底座下面。

“住店？”

“嗯。”林远把旅行袋放在脚边，水从袋底渗出来，在地砖上积了一小片，“单间，一晚。”

女人从抽屉里抽出一本登记簿，推过来，又推过来一支笔。笔用细绳拴在簿子封皮上。

林远低头写名字。雨声在玻璃外面，一阵大一阵小。

登记簿一页五个格。最上面一格是三天前的日期，姓名栏里写着一个“陈”，后面两个字被水洇开了，看不清。退房时间那一栏空着。

他写完，把簿子推回去。女人看了一遍，从墙上摘下一把钥匙，铜牌上刻着“3”。

“三楼，楼梯上去右转，最里面。”她说，“热水十点断。早饭七点到八点，过了没有。”

“好。”

“伞放门口桶里。”她指了指门边的铁皮桶，“别人的东西别拿。”

桶里立着三把伞：一把黑的长柄伞，一把蓝格子的折伞，还有一把湿的，伞尖朝下，水正一滴一滴落进桶底。那把伞的伞骨上缠着一小截红绳。

林远看了一眼，把钥匙揣进外套口袋，拎起旅行袋往楼梯走。

楼梯是木头的，第三级踩上去响了一声，第七级又响了一声。墙上贴着相框，一路往上挂，照片里是一栋两层小楼，门前站着几个人，脸太小，看不清。相框玻璃上积着灰，只有最上面那一幅的角上被擦过，露出一小块干净的地方。

三楼走廊只有一盏灯，灯泡发黄。走廊尽头是 3 号房，门板上有一道从上到下的木纹，像一条干了的水痕。

他把钥匙插进去，转了两下才开。

房间不大：一张床，一个床头柜，一把椅子，窗下一张桌子。窗帘拉着，雨点打在上面，鼓一下，瘪一下。空气里有股旧木头和消毒水混在一起的味道。门背后贴着疏散示意图，图上三楼走廊画得比走廊本身短了一截。

林远把旅行袋放到椅子上，拉开拉链，先摸出充电器，插在墙上。插座松，插头往下坠，他用旅行袋的带子垫了一下。

然后他走到窗边，把窗帘拉开一条缝。

楼下碎石地上，他的车旁边多了一辆车，黑色的，车头朝着大门，雨刷没动，车灯也没开。车牌被雨糊着，看不清。

他站在窗前，看了大概半分钟。那辆车里没有人下来，也没有人上去。

走廊里有脚步声，从楼梯那边过来，不快，一步一步，走到一半停住了。

林远侧过头听。

停了几秒，脚步声又响起来，往回走，下了楼。

他把窗帘拉上，回到床边坐下，床垫陷下去一块。床头柜上放着一个白瓷杯，杯口有一道缺口。他拿起杯子看了看，杯底粘着一圈干了的茶渍。

十点差十分，他去走廊尽头的公共盥洗室洗漱。镜子左上角缺了一块，剩下的部分照出他的半张脸。水龙头拧开，先是响了一阵，然后才出水，凉的。

回来时，他路过楼梯口，往下看了一眼。

前台那盏台灯还亮着，女人不在。登记簿摊在台面上，翻开着。门边的伞桶里，那把缠着红绳的湿伞不见了。

林远回到 3 号房，把门关上，反锁。

锁舌进槽的时候，走廊里的灯闪了一下。
