# 三点十分

雨水从窗框的下沿渗进来，在窗台上积成一小条，慢慢往墙上洇。林远把湿鞋脱在门口，鞋尖朝外。

他拉开桌子的第一层抽屉找布。抽屉里是一本电话簿，封面用胶带缠过；半盒火柴，火柴头受了潮；还有一张折起来的旅馆须知，纸角卷着。没有布。

第二层抽屉是空的。底板上有几道划痕，横的，长短不齐，像钥匙尖划出来的。

第三层抽屉拽不开。他蹲下去，两手扣住抽屉两边的凹槽，往上一抬再往外拉，抽屉才出来一半。里面塞着旧报纸，报纸压着一块蓝布。

他把报纸抽出来。报纸已经发黄发脆，边角一碰就掉渣。蓝布包着一样东西，四四方方，比手掌小一圈。

蓝布洗得发白，四个角剪得齐。他把布打开。

是一只怀表。

表壳是银的，磨得发亮，边上有一处小凹。表链断了一截，剩下的半截缠在表耳上，扣环是开的。他拇指按住表冠往上推，表盖弹起来。

表盘上的指针停着。时针过了三，分针压在十上。三点十分。

表蒙子上有几道细划痕，横着，长短不齐。他拿手指抹了一下，划痕里的灰没抹掉。

他把表翻过来。表盖内侧是光的，靠近铰链的地方，有一行小字，是用针尖一类的硬东西划出来的：

三点十分

划痕不深，笔画沟里留着一线黑。

他合上表盖，把表凑到耳边。没有声音。他用拇指拨了一下表冠，表冠很紧，拨不动。

走廊上有拖鞋底蹭地板的声音，从东头过来，在他门外停了一下，又往西头去了。门下透进一线光，跟着脚步声扫过去，然后没了。

他站起来，走到门口，把门闩推上。插销孔有点松，推到底，门还能晃。

楼下有人开收音机。声音隔着楼板传上来，先是一段电流声，然后有人报时：二十二点整。

隔了一会儿，楼下有人喊：“热水在楼梯口，自己提。”

林远应了一声：“知道了。”

他回到桌前。怀表还摊在蓝布上，表链的半截垂到布外面，碰着桌面。

抽屉还开着。他把旧报纸折回去，放回抽屉，手指碰到抽屉底板的边缘，摸到一层薄灰。

他把抽屉推回去，推到最后卡了一下，再用力，才合上。

怀表没有收起来。蓝布也没有包。

窗外的雨还在下。窗台上那条水往墙里洇开了一小片，颜色比周围深。

### 自查

1. 必发生核对：作者补充本章要求两件事。其一，“林远在抽屉底层发现一只停摆的怀表”已落到“里面塞着旧报纸，报纸压着一块蓝布”至“是一只怀表”“表盘上的指针停着”；其二，“表盖内侧刻着‘三点十分’”已落到“表盖内侧是光的，靠近铰链的地方，有一行小字……三点十分”。两条均在正文中有短引定位，本章无其他必发生项。

2. 铁律自查：
   - “不写人物心理分析；只写可观察的动作、对白与物件”：正文通篇以开抽屉、拆蓝布、推表冠、凑耳、拨表冠、推门闩等动作与物件推进，未出现“他想”“他觉得”“他意识到”一类句子。对白只有楼下喊话与“知道了”一句，符合“只写可观察”。擦边处已处理：原稿“像钥匙尖划出来的”与“划完之后有人拿布擦过”属人物推断而非可观察事实，已分别改为“横的，长短不齐”和“划痕不深，笔画沟里留着一线黑”。
   - “林远在第 5 章之前不得知道真相”：本章林远只做了三件事——看表盘、看刻字、拨表冠；他没有把表盘停摆时间与盖内刻字并置比较，也没有对表的来历作任何判断，正文中不存在指向真相的认知落点。遵守。

3. 读者认知：当前误读基本立住——蓝布包着、压在受潮发脆的旧报纸下、抽屉卡住拽不开，读者容易先归因为“前住客遗落”或“旅馆旧物”。风险在“表壳是银的，磨得发亮”与“报纸已经发黄发脆”并置：磨亮无锈会让部分读者提前猜“有人近期放进去”，从而过早贴近真相。可执行修改建议：将“报纸已经发黄发脆，边角一碰就掉渣”改为“报纸边角发脆”，删去年代暗示；或把“报纸压着一块蓝布”改成“蓝布塞在抽屉最里侧”，使藏匿感减弱、偶然感增强。另一处可执行建议：把“表链断了一截”与“扣环是开的”分开两段写，避免读者把断链直接读成“有人匆忙扯下”。
