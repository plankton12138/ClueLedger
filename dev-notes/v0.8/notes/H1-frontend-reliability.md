# H1 前端可靠性修复

日期：2026-10-25。版本保持 `0.8.0`。本记录对应[体验计划](../frontend-experience-plan.md)的第一阶段，不代表 H2–H6 已实施。

## 设计与实际行为

这一阶段先保证输入和操作结果有明确归属，再调整页面结构。模块依旧使用现有抽屉，正文仍是只读阅读器。

- 模块按库、模块、基础版本保存会话草稿；灵感按作品和条目保存，新建草稿有独立临时身份。切换条目、版本、作品和页面不清空输入，放弃修改只处理当前草稿。
- 模块记录按既有 `start/end` 接口连续读取；核对条目、摘要指纹、码点长度、区间及游标，全部记录完整后才显示编辑表单。读取失败不会把部分原文交给发布流程。
- 详情和查询使用独立请求代次，关闭、重开和 A→B→A 都使旧结果失效；成功、错误和加载状态遵循相同规则。
- 保存冻结内容、基础版本、编辑序号、请求键和目标作品。返回后保留后续输入；网络结果未知时，同一内容的显式重试使用同键同体。
- 发布成功、作品应用失败时同时展示两项结果，保留新精确版本，提供单独的应用重试。重试读取最新装配，保留其他绑定、标签和关联，拒绝覆盖已被更换的目标版本。
- 未配置可用模型时保留聊天输入、禁用发送并保留设置入口；中文输入法确认不提交。
- 对话结果中的撤销先展示提交及受影响文件，取消不请求回退，执行期间阻止重复请求。沿用现有回退接口与范围。
- 灵感选中摘要继承行文字颜色；资料和章节范围悬停改用浅色背景；金色按钮使用深色文字。原有布局与其余控件规则继续在 H2 迁移。
- 页面刷新或关闭前提示未保存内容；没有新增原文的浏览器持久化，不承诺刷新后恢复。

## 职责与接口

`moduleEditor.ts` 管原始编辑输入及基线，`modulePublication.ts` 管发布命令和应用恢复；库状态只装配选择、读取与既有管理动作。
灵感继续使用现有状态容器，增加条目草稿和提交快照。没有新增服务端接口或修改后端发布、装配权限。
预设字段清单、无作品库管理、默认预览、路由和布局迁移留在 H2/H3；历史分页与资料页面迁移留在 H4。

版本列表的时间精度为秒，同秒修订不能按列表首项判断 head。界面“最新”标记改为比较实际 head，回归按保存后选中的精确版本读取结果。

## 验证与边界

当前执行结果、截图、基线缺陷和未执行项统一见[验证记录](../artifacts/frontend-experience/verification.md)。

640px 正文宽度为 0 的布局问题仍在 H2，已有预期失败回归，不计为通过。全轮对比、缩放、焦点和页面能力验收尚未完成。
