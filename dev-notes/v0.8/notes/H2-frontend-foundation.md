## 产品行为

正文空间优先于辅助栏。宽屏显示目录、正文和对话；紧凑桌面显示正文和对话，目录通过抽屉打开；
空间不足时在正文与对话间切换，目录仍可独立打开。字体放大后按真实空间重新选择组合，自动适配不改写长期栏宽。

作品菜单收纳打开、新建、重新读取与失效登记清理；主导航是三个页面链接，设置收纳模型连接与显示偏好。
写作工具区只放目录、对话、阅读显示和活动记录。正文基准17px，对话与目录基准14px，保留原稿纸横线。
新控件共用语义色、字号处理和完整状态，兼容按钮继续服务尚未迁移的页面。

模块库成为应用级页面，支持精确模块／版本链接。作品内“作品模块”与顶栏打开同一页面。
库的全局读取和发布不再依赖作品，装配、旧资料导入与派生仍需要已登记作品。
URL 中的作品上下文只作为登记 ID 核对；不存在的上下文被移除，不当作磁盘路径读取。

切页保留正文、对话与已访问页面的实例；阅读位置、目录搜索与作品页面位置留在当前会话。
浏览器前进后退保留 H1 草稿，不发送或启动任务。跨作品重新读取原选择文件，不沿用另一作品原文。

## 结构与接口

- AppHeader、WorkspaceMenu、WorkspaceNavigation 管应用入口；WritingLayout 按容器和字号计算空间，WorkspaceToc 管目录。
- Button、Field、ListItem、Tabs、StatusMessage、EmptyState 与 AppDialog 提供共享状态与键盘规则；字号仍只经既有样式处理乘一次比例。
- `navigation.ts` 的 parser／serializer 同时处理作品页、旧资料链接和库页，不新增服务器页面路由。
- 模块不在当前筛选页时，客户端复用已有库分页查找身份，不以列表第一项猜测模块或 head。
- 关闭或隐藏辅助面板不停止会话；隐藏时不改变正文阅读位置和聊天跟随状态。
