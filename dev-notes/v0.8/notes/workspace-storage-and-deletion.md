# 作品目录与真实删除

日期：2026-10-26。状态：已实施，版本保持 `0.8.0`。
产品行为见[作品目录方案](../../../product-design/v0.8/workspace-storage.md)。

## 交付范围

作品和共享模块的默认位置统一归入系统文档目录下的 `ClueLedger`。
作品位于 `作品/<名称>`，共享模块继续位于 `ModuleLibrary`。
新作品只建立正文目录和版本历史，不预建 `设定集/角色小传`。
灵感与装配记录沿用按需创建，读取默认位置本身不写磁盘。

普通新建允许更改位置；基于当前组合新建未指定目录时也使用默认作品父目录。
用户新建入口遇到已有目录返回 `WORKSPACE_NAME_CONFLICT`，不向已有目录补写文件或初始化历史。
内部文件夹具仍可补齐正文结构，不改变作品文件工具的职责。

本轮不迁移、复制或批量清理历史测试作品，也不新增迁移流程。

## 删除契约

`DELETE /api/file-workspaces/{workspace_id}` 必须携带：

```json
{ "confirmed_path": "作品列表返回、确认框展示的完整路径" }
```

请求体缺失返回 422，确认路径与当前登记不一致返回 `WORKSPACE_CONFIRMATION_CONFLICT`。
确认框提供「取消」和「删除作品及文件」，描述永久删除范围与无法通过应用恢复。
作品菜单和作品位置对话框中的最近列表均可打开确认框，列表删除无需先切换当前作品。

成功时先删除完整作品目录（包含正文、灵感、装配、历史与其他文件），再删除对应应用状态目录，
最后移除登记。成功或部分删除失败后均清除服务缓存，后续请求重新核对真实目录，避免缓存服务重建已删除内容。
响应保留 `removed`、`workspaces`，被删除作品的 `exists` 为 false。
删除当前作品后选择仍存在的另一部作品；无可用作品时清空当前稿纸、会话和模块选择，
递增页面请求版本以排除迟到的读取结果。删除其他作品不切换当前作品。

路径校验覆盖作品目录和应用状态两个实际删除范围：

- 确认路径必须与登记一致，拒绝目录被换成符号链接、联接或解析到其他位置。
- 保护磁盘根、用户主目录、系统文档目录、当前运行目录、ClueLedger 总目录、作品父目录、
  应用状态根、共享模块库和其他已登记作品；共享库即使位于本作品状态目录内也受保护。
- 存在的作品目录必须包含正文文件夹，避免把任意打开过的普通目录当作品删除。
- 作品仍有写作或整理轮次时拒绝删除。删除与轮次受理在同一事件循环内执行，
  校验和文件删除之间不让出执行，避免新轮次在目录删除中途受理。
- Windows 只读文件（包括 Git 对象）在权限错误时解除只读属性并重试当前删除操作；
  不跟随作品内部链接删除外部内容。

文件删除或状态清理失败时返回 `WORKSPACE_DELETE_FAILED`，保留登记并显示具体路径及原因。
部分文件可能已删除；已缺失的目录允许继续清理，因此状态清理失败后可重试完成。
本轮采用永久删除，不提供恢复或额外回收站。
