# H3 模块库预览、编辑与作品应用

日期：2026-10-25。版本保持 `0.8.0`。本阶段已实施；当前完整交付见[H6记录](H6-frontend-verification.md)。

模块库默认展示保存版本的正文与字段，显式进入编辑后才显示表单。未修改时不允许发布，历史版本可预览或另存变体。
编辑区只有“保存新版本”作为主操作；“同时用于〈作品名〉”默认不勾选。发布和作品应用继续沿用 H1 的独立结果与重试命令。
已有未保存修改时显示“继续编辑”，返回列表或其他页面不会丢弃草稿。

浏览列表、原文预览、编辑器、字段、版本选择和作品装配分别由领域组件承担。窄窗口在列表／详情间切换，
返回保留筛选与草稿；列表和版本选择继续消费分页。装卸、升级、排序、旧资料导入、变体、删除恢复与派生保留。
变体失败后保留名称，只有成功后退出输入状态；无作品时全局库仍可读取和发布。

## 字段契约核对

服务端预设响应增加 `allowed_fields`，值来自既有类型定义，前端不维护第二份允许字段表。
作者已确认沿用既有服务契约：文字、数字、布尔值和标量列表合法；普通控件处理前三类，列表放高级字段区。
数字0、布尔false、未填写与清除分别处理。未知字段、嵌套对象、含非标量的列表或损坏JSON保留原始输入，给出诊断并阻止发布。
此前计划与示例中“数组全部被拒绝”的描述已修正，没有借界面迁移收窄既有后端能力。
