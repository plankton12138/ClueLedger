# H5 公共入口与操作确认

日期：2026-10-25。版本保持 `0.8.0`。公共浮层与错误反馈已迁移，当前结果见[验证记录](../artifacts/frontend-experience/verification.md)。

目录、设置、模型连接、宽阅读、活动记录和领域弹窗共用焦点管理：进入浮层、限制焦点范围、Esc关闭、
关闭返回入口。连续从作品菜单打开目录、从设置打开模型连接时，也能返回稳定的顶栏入口。
关闭阅读或活动不停止后台任务。旧宽阅读和资料导航外壳样式已移除；模块主页面按实际职责命名为 ModuleLibraryPage。

目录继续调用系统选择器；取消选择不更换作品。打开接口失败返回明确结果，浮层保留位置与错误，不按成功关闭。
模型连接的普通输入在失败后保留；临时 API Key 仅在当前表单，关闭卸载后清空，不写会话草稿或浏览器存储。
浏览器生命周期验证只用合成哨兵；截图在密码框清空后采集。服务端返回的脱敏连接视图不回填密码框。

活动保留事件读取、详情、文件版本、导出与设置，危险清理和重建移入独立“维护工具”。
150%字号下时间列随字号分配宽度，防止时间与类型重叠；窄窗口统计与事件各自可滚动。
模型和活动错误保留服务端 code／where／why／fix，普通网络失败使用规范提示；面板渲染失败不在普通界面打印原始异常。

对话结果卡和文件版本页的撤销均先展示提交与影响文件，经确认后执行。执行中不能重复触发，取消不写入。
为准确显示文件范围，既有 `GET /git/commits/{commit}/diff` 响应补充 `paths`：服务端从指定提交读取受管文件，
客户端不解析文本差异猜文件名。没有新增路由，没有扩大后端撤销权限；对应接口、类型与真实Git回归一起更新。
确认浮层层级高于活动记录，避免确认框被父浮层遮住。
