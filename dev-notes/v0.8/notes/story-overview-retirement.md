# 故事总览模块撤除

日期：2026-10-26。版本保持 `0.8.0`。

## 产品决定

本次撤除整个故事总览模块，包括独立页面、导航、时间线与模块关联视图、专用接口和模型整理任务。
此前先下线“更新总览”，本次按作者要求扩大为整个模块撤除，不再保留只读总览页面或内部整理实现。

原模块的任务范围、执行过程与操作限制不清楚，模型解释直接进入总览，作者审阅与采纳边界需要重新设计。
后续是否重新提供相关能力另行决定。

## 当前行为

- 主导航移除“故事总览”；旧 `overview` 链接及对象深链接返回当前作品写作页。
- 删除总览页面、人物关系图、线索关联视图、原文依据面板、专用请求类型与样式。
- 删除全部 `/story-overview` 读取、更新与历史进度接口，不再注册专用路由。
- 删除总览来源模型、派生存储服务和逐目标整理执行器；统一任务服务仅保留对已撤除用途的拒绝，防止旧请求进入写作模式。
- 清理专用评测用途、案例、套件、浏览器夹具和过时测试；已有评测报告和活动日志保留为历史证据。
- 移除仅为总览引入的关系图和布局依赖。
- 写作、模块编辑、灵感与已有独立旧资料能力保持各自实现；旧资料链接不再转入总览。

正文、模块原文及历史派生数据均不删除，不自动迁移或恢复模型执行。
磁盘上的旧 `overview/` 数据不再由产品读取；历史会话与活动记录继续使用通用查询能力。
根目录 README 未修改。旧 O0–O6 文档和验证记录只代表撤除前的历史状态。
