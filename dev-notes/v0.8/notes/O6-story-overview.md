# O0–O6 故事总览实施与验证

日期：2026-10-25。运行版本保持 `0.8.0`。O0–O5 已接线，O6 本轮验证完成；未覆盖范围列于文末。

## 结果与设计取舍

主导航改为“故事总览”，默认显示时间线。导航按当前作品挂载的模块显示实际名称，
没有模块时仍能阅读章节。尚未整理的模块直接读原文；只有有效派生结果才提供人物、线索视图。
混合模块无需填写类型，人物卡、关系图、关系列表、线索进展和事件来源使用同一份确定引用。

一个明确的“更新总览”命令对应一个作品轮次。逐目标创建独立只读上下文，按模块、章节、关联顺序执行，
复用已有模型快照、忙状态、停止和重启恢复。每目标最多 16 个模型回合，实际提供原文累计不超过 24,000 码点。
读取工具只接受当前目标的偏移，不能选择其他路径；发布工具不能修改正文、模块、装配或全局库。

作者设定、未来计划与正文观察分别呈现，正文表达方式保留证词、回忆、推测等性质。
关系图的边及关系列表显示来源性质。来源改变后不把旧偏移直接用于新正文。
信息不足单独保存尝试，保留最后成功结果；失败、停止和已完成目标分开记录。

## 在线语义结果与修正

通过 [story-overview 套件](../../../eval/suites/story-overview.json)执行实际 `organize_overview` 用途，
不是发送普通聊天来模拟整理。执行器保存当前故事索引和总览派生结果用于复核。

- [首次复核](../../../eval/runs/context-20261025-211828-108744/rescored.md)：3 通过、1 失败。失败案例把夹有未来计划的明确人物和钥匙判为空发现。
- 修改了模块整理说明，明确“从作者设定提取对象”与“正文已知观察”是两项不同工作，并加强同一案例的判定条件。
- [修改后复核](../../../eval/runs/context-20261025-212130-905715/rescored.md)：4 通过。混合模块、同名与否定关系、证词与计划、合法空发现均有公开派生结果。
- 第二次运行有错误区间和非法人物关系端点被服务端拒绝；模型在该受控轮次内修正后才发布，没有运行器自动重试或接受坏证据。

上述在线记录在 recipe 2 的同句对象锚点补充前产生；此后未改变语义提示，锚点与分页通过确定性用例，
最终界面通过真实接口浏览器专项。在线证据的源代码指纹按各自运行清单保留，不冒充最终文件的同一快照。
原文附件与本机测试作品按既有规则不入库；报告、运行清单及复核结论单独保留。
