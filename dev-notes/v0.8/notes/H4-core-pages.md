# H4 写作、灵感与故事资料

日期：2026-10-25。版本保持 `0.8.0`。页面迁移已实施并完成确定性回归。

页面先给主要阅读和编辑空间，窄窗口进入详情后可返回原列表；字号变大时调整布局，不压缩字号。
写作页沿用 H2 的空间预算，目录、正文和对话分别可达。页面切换保持现有内容和任务归属，加入参考不发送。

灵感拆为列表、编辑和历史，保留搜索、标签、来源与使用位置。列表与历史均消费游标，历史默认收起，
预览读取精确修订；删除修订明确说明恢复后仍为删除状态。删除和恢复后立即重读历史。
输入可在保存期间继续编辑；带到对话只使用保存修订，未保存时就近提示，不自动保存。

故事资料拆为导航、浏览工具、整理操作、列表、详情和依据。浏览截止章与任务目标各自独立；
打开范围时固定作品、时点和资料快照，确认时提交所选章节及当时内容指纹，后台读取不会重置勾选。
无模型仍可查看范围，启动按钮禁用并提供连接入口。重新读取不调用模型。
覆盖状态与来源有效性分开显示；窄屏依据可返回并保留列表滚动。来源已改动时保留旧引文，不按旧区间高亮当前文件。

资料读取、任务受理及会话列表补充切作品代次核对，A→B→A 后的旧结果不能覆盖新状态。
任务请求签名包括内容指纹，指纹变化后使用新请求键；断线不伪装任务已结束。
