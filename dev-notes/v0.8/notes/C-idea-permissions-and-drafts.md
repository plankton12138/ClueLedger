# C：灵感本轮许可与未保存草稿修复

日期：2026-10-24。状态：已实施并通过定向回归。

## 问题与设计

灵感本是作者主动使用的资料。历史上允许搜索或保存，不代表每一轮都继续授权；本轮明确
禁止时也不能因为请求包含动作关键词而执行。此前工具扫描全部历史作者消息，导致这两类
请求都被接受。

灵感编辑器此前在页面每次挂载时清空状态。作者切到写作页再返回，会失去尚未保存的内容。
草稿应在当前页面会话内保留，切页不应隐含取消编辑。

## 实现

- `RunContext.current_author_text` 保存受理轮次原话，由服务层明确传入。历史作者消息继续
  用于既有范围引文核验；灵感工具只读取当前请求。直接构造工具时未提供当前请求，则只取
  事件序号最新的一条作者消息。
- 搜索、保存分别检查各自的允许短语和否定分句。同一操作出现明确禁止时拒绝，另一操作
  不因此获得权限。引号内的动作词不授权，笔记内容里的否定也不影响外部保存请求。
  拒绝不增加可见灵感，也不写入笔记。此处沿用确定性短语判断，不增加
  模型调用；复杂自然语言不保证都能识别为授权。
- 同一作品重新进入灵感页只刷新列表，保留选择、版本与草稿；切换作品时缓存各自编辑状态，
  返回后恢复。缓存只存在当前页面会话中，刷新整个页面或关闭应用后不保证恢复未保存内容。
- 异步结果核对作品会话代数，作品切走再切回也不会接受旧请求结果。保存期间禁用编辑，
  未保存时不能通过删除、恢复历史或带到对话隐含放弃当前输入；取消仍由作者显式操作。
- G 阶段的整份确定性／浏览器矩阵、全部在线语义场景和成本对照均保留为未完成；已运行的
  四个在线案例照常保留，完整发布状态仍为部分完成。
