## 核心约束

灵感主要给作者看，默认不进入 agent 目录、搜索或装配；明确选择或请求检索才在本轮可用。
故事资料采用七种预设类型、同类型多实例，全局保存模块版本；作品只绑定确定版本。
不做隐藏入口；卸下从后续默认读取范围排除。新作品不强制创建真相或线索文件。
索引分为库索引、作品装配索引、正文索引；章节索引与时间线共用本作品事件来源。
作者计划和正文观察分开保存。语义整理显式启动，作品修改沿用直接写入与范围校验。
索引不是阅读凭据，保存和发布仍复核来源版本及实际提供的原文区间。
