本轮更新：[故事总览](../story-overview-plan.md)已连接默认时间线、当前挂载模块、人物关系和线索进展；**O0–O5 已实施，O6 本轮验证已执行**，下方仍是当前运行职责。

当前运行实现为 **0.8**，包版本 `0.8.0`。本版在 0.7 的故事资料页之上增加三块能力：

- 应用级**模块库**：七种预设类型、同类型多实例、不可变版本与作品按版本绑定。
- **统一章节与事件索引**：章节视图与故事视图共用一份投影；线索、名词与时间线改为按章记录贡献。
- **有界检索与上下文收口**：L0 短目录、L1 有界查询、L2 区间读取，装配冻结、条目级排除记录、任务卡与整请求规模。
