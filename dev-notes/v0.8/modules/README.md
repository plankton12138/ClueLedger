# 0.8 模块导航

当前运行实现为 **0.8**，包版本 `0.8.0`。本版在 0.7 的故事资料页之上增加三块能力：

- 应用级**模块库**：七种预设类型、同类型多实例、不可变版本与作品按版本绑定。
- **统一章节与事件索引**：章节视图与故事视图共用一份投影；线索、名词与时间线改为按章记录贡献。
- **有界检索与上下文收口**：L0 短目录、L1 有界查询、L2 区间读取，装配冻结、条目级排除记录、任务卡与整请求规模。

| 职责 | 当前说明 |
|---|---|
| 七种模块类型、库存储、不可变版本、CAS 发布、变体、删除与恢复、库接口 | [全局模块库与作品装配](library-and-assembly.md) |
| 作品装配清单、精确版本绑定、装／卸／升级／排序、依赖诊断、派生新作品并选择替换版本、保存并用于本作品 | [全局模块库与作品装配](library-and-assembly.md) |
| 模块装／卸／发布的作者授权、agent 工具与结束本轮规则 | [全局模块库与作品装配](library-and-assembly.md) |
| 章节视图与故事视图、事件观察、表达方式、未知时间与偏序、旧记录只读兼容 | [统一章节与事件索引](story-index.md) |

| L0／L1／L2、检索排序与游标、装配预算、必需与可选分区、排除原因 | [检索与上下文](retrieval-and-context.md) |
| 任务卡、模块授权、必读未读、整请求规模、材料越权边界 | [检索与上下文](retrieval-and-context.md) |

## 当前未实现或未验证的部分

- **在线语义验收**：已运行 `eval/suites/v08-smoke.json` 的四个合成案例，尚未覆盖全部在线
  场景与真实长篇；结果与未复核项见运行说明。
- **资料导入的语义映射**：旧资料按原文件内容整体导入为模块条目，不拆分单条线索或逐条人物；
  需要结构化拆分时由作者在模块编辑器中整理。
- **验收矩阵逐项编号**：I01–I10、M01–M07、L01–L13、E01–E09、C01–C10、R01–R05 没有全部
  单独立项执行；未覆盖项见运行说明。
- **作品包导出导入**：已取消，不提供隐藏入口。
- **任务相关性的统一重排**：条目仍按固定分区与确定性排序进入上下文，没有跨分区候选池。
