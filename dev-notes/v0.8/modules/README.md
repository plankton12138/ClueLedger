# 0.8 模块导航

当前运行实现为 **0.8**，包版本 `0.8.0`。本版在 0.7 的故事资料页之上增加三块能力：

- 应用级**模块库**：七种预设类型、同类型多实例、不可变版本与作品按版本绑定。
- **统一章节与事件索引**：章节视图与故事视图共用一份投影；线索、名词与时间线改为按章记录贡献。
- **有界检索与上下文收口**：L0 短目录、L1 有界查询、L2 区间读取，装配冻结、条目级排除记录、任务卡与整请求规模。

## 当前未实现或未接线的部分

- **灵感界面**：条目、修订与删除恢复的后端与 HTTP 接口已实现，顶栏入口、参考 chips 与 agent 灵感工具尚未接入；写作轮次不会自动读取灵感。
- **资料导入与作品包**：资料导入没有实施；作品包导出导入已取消，服务端路由与前端入口均已移除。
- **多时间线计划叠加**：只有一份统一故事索引；同一事件的多条计划线尚未叠加显示。
- **显式单轮库参考**：未装模块只能通过作者授权的库搜索查看候选，尚未提供「本轮只读引用、不自动装入」的独立通道。
- **在线语义验收**：本次只跑确定性与浏览器用例，未用在线模型复核长文材料使用、证词辨别与泄露边界；结果见运行说明。
