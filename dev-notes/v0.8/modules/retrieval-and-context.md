# 检索与上下文

状态：**已实现（0.8 F1–F4）**。运行版本 `0.8.0`。本文写当前的实际接线方式；阶段过程见
[F1](../notes/F1-retrieval.md)、[F2](../notes/F2-assembly-freeze.md)、[F3](../notes/F3-retrieval-tools.md)、
[F4](../notes/F4-entry-selection.md)。

## 1. 三层检索

| 层 | 回答什么 | 入口 | 不做什么 |
|---|---|---|---|
| L0 短目录 | 本轮装了哪些模块版本、正文有哪些章 | 装配分区、`list_modules` | 不加载条目原文 |
| L1 有界查询 | 哪些条目与观察可能相关 | `query_records` | 命中不等于读过全文 |
| L2 区间读取 | 指定条目的原文与区间 | `read_record`、`read_file` | 不复制另一套读取凭据 |

检索的边界：只查本轮装配里的精确版本；未装模块不会因名字相似出现在候选里；不做向量检索、
不递归遍历；一次查询最多走装配里已有的**一跳关联**。

## 2. L0 短目录

- 系统装配里只列已装实例、精确版本与条目数，不读条目正文。
- `list_modules` 按页返回 `binding_id`、`module_id`、`revision_id`、类型、名称、条目数、
  `missing` 与 `next_cursor`；模块不可用时给出警告，不把缺失版本当成空模块。
- 正文目录沿用作品目录，章节过多时只给数量与查询入口。

## 3. L1 有界查询

`query_records` 的输入（都能收窄，不能扩大装配）：

| 参数 | 作用 |
|---|---|
| `query` | 关键词或别名 |
| `kinds` | 条目种类，如 `character`、`author_event` |
| `module_ids` | 只查这些已装实例；显式模块范围可带入一跳关联的已装绑定 |
| `entity_ids` | 人物或作者事件的条目 ID |
| `chapter_paths` | 只看这些正文观察 |
| `include_plans` | 是否返回计划类模块，默认 `true` |
| `cursor` / `limit` | 分页；默认 20，最多 50 |

每条结果带：

- `id`、`kind`、`title`、`excerpt`（最多 240 字符）；
- `source`：`author`（作者条目）、`observed`（正文观察）、`legacy_unverified`（旧记录兜底）；
- `freshness`：`valid`、`stale`、`source_missing`、`unavailable`、`none`；
- `matched_by`：`entity`、`relation`、`chapter`、`module`、`keyword`；
- 完整模块引用（库／模块／修订／条目）、章号或人物路径。

排序是确定性的：显式 ID／关联 → 章区间 → 模块 → 关键词 → 目录；同分按 ID。一次查询返回的
正文总量上限 6,000 字符；关键词落到正文时最多扫 200,000 字符与 300 个条目，超限明确写进
`scan.limited` 与警告，不静默漏项。

分页游标绑定查询条件指纹。换条件复用旧游标返回 `RETRIEVAL_CURSOR_STALE_CONFLICT`，要求从第一页
重新查询。

## 4. L2 区间读取

`read_record` 必须给出完整四段引用；未装版本、库不匹配或条目不存在都拒绝，并提示先用
`list_modules` 或 `query_records` 取得引用。读取返回原文、磁盘指纹与分页游标；长条目分页，
不把一条截成半句。

`read_file` 继续负责作品正文与设定集的区间读取。作者指定为必读参考的文件，必须在写作品前
读完；只查索引或摘要不算读过全文。

## 5. 装配冻结

- 写作轮次受理时冻结装配快照；本轮内不随库或作品装配变化。运行中装卸返回
  `ASSEMBLY_BUSY_CONFLICT`；库发布不受影响。
- 已装模块短目录按受理时的版本生成；下一轮才看到新装模块。
- 卸下的模块从后续默认目录、查询、详情与引用展开里排除；已写进正文的事实不因卸下消失。

## 6. 预算与排除

装配按用途决定分区；预算按完整渲染字符数计量（标题、截断提示与正文都占位）：

| 分区 | 预算 | 说明 |
|---|---|---|
| 任务要求 | 4,000 | 必装 |
| 当前作品 | 12,000 | 必装 |
| 已装模块 | 2,000 | 可裁 |
| 本轮材料 | 8,000 | 可裁 |
| 章节索引摘要 | 8,000 | 可裁；过期索引不注入 |
| 状态层 | 1,500 | 可裁 |
| 人物状态 | 700 | 可裁 |
| 故事时间 | 400 | 可裁 |
| 未回收线索 | 500 | 可裁 |
| 专名表 | 800 | 可裁 |
| 设定集 | 6,000 | 可裁 |
| 历史 | 3,000 | 可裁 |

- **必装分区超预算直接失败**，不截断后宣称完整。
- 可裁分区超预算时整块裁掉，并留下原因。
- 条目级排除记录 `Assembly.excluded` / `state_injected.parts[i].excluded` 保存 `id`、`reason`
  （`budget` 或 `limit`）、完整渲染字符数 `chars` 与继续查看的 `location`。界面与日志读同一份
  结果，不另拼一套选择记录。
- 作者指定为必读的材料不进入可选条目池，也不会因预算降级为可选；预算不足时要明确拆分或
  给出剩余范围。

这是**字符**预算，不是 token 上限。上游实际用量单独记录，两者不互相换算。

## 7. 整请求规模与任务卡

- `model_request_started.request_size` 记录应用侧估算：`method=json_char_count`、
  `estimated=true`，分列 `system_chars`、`message_chars`、`tool_chars`、`total_chars`。
- 上游 `usage` 缺失时 `model_request_finished.usage` 保持 `null`，不填零，也不把字符数当 token。
- 任务卡是事件流投影 `taskCardFacts(turn)`，不新增事实来源，显示：范围摘要与作者授权原话
  （带序号）、承接来源、版本、允许与禁止的操作、装配授权、发布授权、必读材料与未读剩余、
  执行状态、改动路径与检查状态。
- 重复原文按路径与版本去重；需要时重新读取，不沿用旧版本自述。

## 8. 权限边界

- **灵感不默认进入检索**：未选中的灵感不在 L0／L1／L2、`search_text`、`list_files`、
  `read_file` 的结果里。灵感的界面入口与 agent 工具尚未接入。
- 作者指定材料只产生阅读范围，不产生任何写授权；参考第二章不会允许改第二章。
- 模块搜索（`search_module_library`）只在作者明确要求、且范围登记 `library_search` 时可用；
  结果只是候选，不自动装入或升级。
- 资料文本里的「删除授权」等内容不升级为指令；越权写仍按范围拒绝。
- 用例见 `tests/workspace/test_material_privilege.py`。

## 9. 边界

- 不自动启动摘要或压缩任务；上下文超限时由作者或显式流程处理。
- 没有向量检索，也没有全库无界扫描；库候选只来自作者授权的搜索。
- 未提供「显式单轮引用未装模块」的独立通道。
- 长篇上下文规模与在线语义效果尚未验收，见[运行与验证](../release.md)。
