# P6 三入口工作区与共享详情

日期：2026-11-01。范围：M1 与 M8 的界面部分。

## 1. 完成内容

- 主导航改为「正文 / 构思 / 线索」，模块库留在全局工具区；`#/workspaces/{id}/ideas` 仍表示灵感。
- 路由 `?mode=story|clues` 与 `?node=`、`?clue=` 成为选中状态的来源：直接打开链接、刷新与前进后退都回到同一个对象。
- 右侧新增共享详情区（`WorkspaceDetail`）：构思节点详情（状态与原因、标题、构思内容、时间说明、计划章节、相对分钟、定位正文、稍后处理、讨论调整）与线索详情（用途、作者事实、读者可能的理解、正文出处、相关线索、添加 / 删除关系、带入对话）。
- 线索出处保留「定位原文」：账本证据走现有来源阅读并在返回时回到原来那一页，只有作者关联时直接打开对应章节。
- 构思页以 `StoryTimeline` 替换悬疑视图：按披露章节分组，点的位置与条的长度只由相对分钟决定，没有拖动处理器；状态点有可访问名称。
- 新增线索页 `ClueSurface`：左列全书线索，右侧一跳关系图与关系列表；无关系时只显示列表，剩余数量如实说明。
- 正文选段新增「标记线索」：用解析器源位置换算出码点区间，弹出名称与用途后一次提交身份、用途与精确关联。正文标记按用途区分下划线与虚线，失效原句给出说明而不是错误位置。
- 删除 `StoryMysteryView`、`StorySyncStrip`、`mysteryLayout`、`StoryClues` 与对应测试和孤立样式；左栏只剩目录，目录状态改由三状态投影决定。
- 窄屏下详情置于内容下方，宽度不足时线索页改为单列。

## 2. 取舍

- 关系图只画选中线索的一跳；完整关系以键盘可达的列表呈现，不用缩小字号塞下全图。
- 详情与对话仍是同一块右侧区域里的并列视图：打开对话不丢弃所选线索，关闭详情不清空未发送的草稿。
- 线索编号、颜色不是唯一识别手段：用途同时有文字。
