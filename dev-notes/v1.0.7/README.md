# v1.0.7 开发入口：构思与线索简化

制定日期：2026-11-01。目标版本：**v1.0.7**。状态：**已交付 v1.0.7；在线模型验收未执行**。

当前核对的代码基线为 `d1f8238`，主包与前端版本均为 `1.0.6`。本目录依据作者的功能讨论和随后生成的交互预览制定；预览中的演示数据、固定回复和内存内修改不代表正式产品已经具备相应能力。

本版希望作者只需处理三件事：安排构思、阅读正文、判断线索。一级入口收敛为「正文 / 构思 / 线索」，保留正文与构思的直接关联、不可拖动的故事时间轴、线索关系图，以及主动点击后才开启的核对讨论。

## 版本范围

- 作者侧线索类型为「真相线索 / 误导线索」，正文和线索页使用同一分类。
- 构思状态为「就绪 / 草稿 / 需核对」；原因在选中内容后展示。
- 时间轴按故事发生时间定位，按披露章节组织行；支持点击，禁止拖动修改。
- 正文选段可以直接登记线索，线索无需先挂到构思节点。
- 节点与正文可以双向定位；多节点、多章节和同章多次出现都需要成立。
- 差异提醒可以稍后处理；作者主动开启讨论后才调用模型。
- 技术上的版本冲突、引文失效和越出修改范围仍然阻止错误写入。
- 模块库保留功能和独立路由，入口移至全局工具区；灵感入口沿用现有能力。
