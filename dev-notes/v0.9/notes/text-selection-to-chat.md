# 正文与装载模块的选段加入对话

日期：2026-10-27。

## 目的与交互

作者讨论某句话时，需要明确给出讨论对象。正文和作品内已装载模块的阅读区支持选择文本，
浮出“添加到对话”。点击后打开当前对话并聚焦输入框，不自动发送。
选段以可展开、可移除的卡片显示在输入框上方，保留来源名称、原文和选中时的版本。
可以先添加选段，再输入要求；选段也会随草稿保存并在刷新后恢复。

正文来源记录作品相对路径和内容摘要值。模块来源记录模块库、模块、作品绑定及修订标识。
这些标识用于说明引用来源，不在日常卡片里展示，也不构成新的读取或修改授权。
阅读内容后续发生变化，不替换已有选段；重新选择才生成另一份快照。

## 实现边界

- 共用的 `SelectionToChat` 只接受起止位置均在同一阅读区内的选择；跨栏、工具栏和编辑表单不触发。
- 草稿引用保存在 `DraftContext.text_references`，新增 `draft_text_references` 界面状态提交字段。
  单独选段也构成草稿内容；没有文字和选段的旧文件参考仍沿用原有清理规则。
- 发送时把作者要求与选段来源、原文引用组成同一条用户消息。使用现有发送接口，
  原文因此进入正式历史、用量估算与后续压缩，不需要新增独立模型上下文字段。
- 引用属于当前作品、当前会话的草稿。普通聊天之外的显式资料任务、灵感展开不携带这些选段。
- 受理失败保留草稿；成功后仅清除与提交快照一致的引用，受理期间新增的选段保留。
- 最多十个选段，每段最多 20,000 字符。前后端均有边界校验；重复选择同一来源、版本和原文不重复登记。
- 窄屏先切换到对话，再聚焦输入框。Escape、外部点击、滚动或切换来源关闭浮动入口。

## 验证

- 会话状态测试：去重、会话隔离、保存、失败保留、发送原文及来源、受理期间新增、数量与长度限制。
- 后端接口测试：无文字选段草稿重启恢复、不创建会话、超限请求拒绝、兼容旧草稿。
- 浏览器 `text-selection.spec.ts`：正文和装载模块选段，真实接口保存与刷新恢复、查看与移除、
  窄屏自动打开对话和聚焦、键盘触发、跨阅读区选择不触发。两项通过。
- 截图在 `data/test-tmp/text-selection/references-1440.png`，属于本地验证产物。

本功能的验证不调用模型；发送内容通过真实状态组装代码和请求断言核对。
