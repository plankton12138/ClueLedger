| 阶段 | 交付 | 状态 |
|---|---|---|
| S0 | 基线、契约、样本与前后端清单 | 待开始 |
| S1 | 线索身份、旧记录迁移、按章贡献与覆盖 | 待开始 |
| S2 | 原文定位、阅读与章界、精确引用 | 待开始 |
| S3 | 共享详情、本章线索、集中列表与空状态 | 待开始 |

契约冻结后可准备界面，以真实服务接通为交付条件。
