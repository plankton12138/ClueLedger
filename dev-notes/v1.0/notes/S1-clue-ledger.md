# S1：稳定线索身份与按章原子发布

日期：2026-10-27。状态：身份与事务已实现；当前按作者要求只使用第 2 版账本。
旧数据兼容、别名、迁移和迁移备份已移除，见[当前格式约定](current-format-only.md)。

## 解决的问题

线索标题不再承担身份。已有线索更名或重建时复用 clue_id；两条同名新线索分别保存。
已有同名记录而未提供身份时，发布返回身份冲突；明确另建可用 new_identity=true。

本章贡献和整理覆盖在同一个事务提交。empty 只清除本章贡献，insufficient 保留旧贡献。
当前格式的身份、其他章、作者关系和检查历史不随单章重建删除。

## 实际模块

| 位置 | 当前职责 |
|---|---|
| workspace/clue_models.py | 当前格式模型、身份和引用完整性 |
| workspace/clue_store.py | 只读空快照、显式初始化、文件锁、版本、回执和原子替换 |
| workspace/clues.py | 已有调用入口、按身份合并、章界和来源有效性 |
| workspace/material_tasks.py | 受理身份快照、贡献与覆盖一次发布、读取范围核验 |
| workspace/service.py、agent.py | 真实任务、停止检查、任务内逐章接续 |
| workspace/story_materials.py | 线索覆盖只读账本，详情只按当前稳定 ID 读取 |

后端路径相对 src/hastings/；前后端接口和原文定位见[S2 记录](S2-source-locations.md)。

## 当前规则

缺失账本或已弃用的第 1 版返回空快照 empty，GET 不创建目录或写文件。
首次显式发布创建全新的 lineage、线索身份和第 2 版账本；旧线索、覆盖、别名和关联不导入。
当前格式损坏、字段缺失或未知更高格式报错，不按空覆盖。

同键同内容返回原回执，同键不同内容返回冲突。任务可以接续自己的按章事务，外部写入后必须重新核对版本。
写入采用跨进程锁、同目录临时文件、fsync 和原子替换；失败保留当前文件。
作品改名仍移动完整状态目录，普通当前格式状态备份及恢复仍保留。
