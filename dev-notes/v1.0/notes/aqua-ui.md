# 前端 Aqua 视觉与布局改造

日期：2026-10-28。作者确认采用经典 OS X 原型的布局、较大字号与按钮位置，并保留复古对话气泡。包版本保持 `0.9.0`。

后续范围覆盖：作者本轮取消故事资料板块，并要求简化线索与统一模型交互，见[整改方案](../../../product-design/v1.0/interaction-redesign.md)。下文保留为当时实施记录，其中故事资料导航、页面和恢复行为不能作为当前需求重新引入。

设计原则见[当前视觉与布局](../../../product-design/visual-language.md)，参考图见[经典 OS X Aqua 原型](../../../prototypes/osx-aqua-20261027/README.md)。

## 已实施

| 区域 | 行为与目的 |
|---|---|
| 顶栏 | 左侧作品选择，中间写作／故事资料／模块库，设置靠右；资料入口恢复原浏览位置 |
| 写作区 | 压缩外围边距，240px 目录、正文和默认 420px 辅助区连续分栏；保留拖动及字号预算驱动的收拢 |
| 正文 | 平整暖白底，桌面 21px、窄屏 19px；工具栏提供章节翻页与同一份字号偏好的增减，文件信息按需展开 |
| 对话 | 保留绿色作者气泡、银灰回复气泡的渐变、高光、边框与投影；阅读文字和输入框增大，发送／停止位于底部右侧 |
| 故事资料 | 分类、列表、证据详情连续排布，右侧证据可用空间扩大；现有来源定位与披露边界沿用 |
| 模块库 | 宽屏并列列表与预览，窄屏逐页查看；编辑靠近标题，保存／取消／添加在文档底部，列表及编辑草稿在布局切换时保留 |
| 灵感 | 收起入口按输入区上缘限制显示范围，避开引用和输入操作；展开面板仍使用整个可用窗口，并保留拖动和位置偏好 |

## 回归中修复的问题

- 输入区滚动容器裁切上下文浮层，浏览器点击被阅读区拦截：移除该容器的裁切，验证压缩与停止、浮层位置和键盘行为。
- 同屏列表与预览出现相同文本：既有测试改为在文档预览内核对正文。
- 模块版本刷新与编辑状态切换存在时序问题：自动刷新保留脏草稿的编辑状态；作者明确「重新读取」时进入阅读态，草稿仍可继续编辑。
- 灵感入口遮挡引用移除按钮：入口显示范围避开输入区，并监听输入区尺寸变化。
- Windows 测试子进程的中文输出与读取编码不一致：夹具显式使用 UTF-8。
- 两个测试夹具缺少当前模型配置的字段：补齐空容量信息和默认思考选项，保持类型契约一致。
- 最后一次类型检查发现同期新增的线索流程测试提前闭合：仅移除多余括号，保留原断言；修正后全量浏览器测试代码类型检查通过。
- 一次页面加载出现脚本与样式 404：为测试增加独立构建目录选项，避免共享 `frontend/dist` 被其他构建替换。正常构建路径保持原样。

## 复现

在 `frontend/` 使用独立端口、状态目录与静态目录运行相关测试，目录选用当前工作区内的测试路径：

```powershell
$env:HASTINGS_E2E_PORT = '8945'
$env:HASTINGS_E2E_DATA_DIR = '../data/test-tmp/aqua-ui-20261028'
$env:HASTINGS_E2E_STATIC_DIR = '../data/test-tmp/aqua-ui-20261028/frontend-final'
$env:HASTINGS_E2E_SCREENSHOT_DIR = '../dev-notes/v1.0/artifacts/aqua-ui'
npx playwright test --project=workspace aqua-layout.spec.ts --reporter=line
```

首次验证应使用新的静态目录；浏览器夹具与服务端使用同一份产物。默认启动仍构建并托管 `frontend/dist`。
