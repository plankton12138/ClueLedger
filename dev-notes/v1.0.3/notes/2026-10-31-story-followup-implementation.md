## 已实施的行为

| 问题 | 当前行为与取舍 |
|---|---|
| 普通对话仍生成模块 | 受理普通对话时判定明确构思创建意图，缺少结构上下文时补入当前方案。保留来源读取，结构成果限制继续关闭模块写入；纯空白结构任务不提供正文／模块范围登记工具。明确创建动作缺少上下文仍拒绝，避免掩盖无效接口请求 |
| 分批生成不断收到缺回收错误 | 字段和操作应用错误立即拒绝；尚未补齐的整图依赖列入 `pending_dependencies`，返回下一步建议。先生成节点和推进关系，再细化线索。最终提交仍执行全部一致性和授权检查 |
| 报错没有问题列表 | 结构工具将机器诊断附加到异常的可见文本，保留错误标志；测试穿过实际工具执行边界，不只检查异常对象的 details |
| 修正错对象、覆盖有效草稿 | 替换必须保持对象种类与 ID；先应用候选再原子保存，重复 ID 等错误不覆盖原草稿。`read_story(source="draft", target_id=...)` 精确定位，`node_patches` 按节点 ID 局部修改，减少翻页与索引换算 |
| 用完回合后无法继续 | 结构任务按实际模型请求计数，每次工具返回剩余回合；准备批次进入最后 3 回合时，在下一次模型请求前暂停，保留草稿并进入需处理状态。达到原上限且有草稿也转换为可继续状态；不扩大 24 回合上限 |
| 来源确认反复失败 | 首次授权冲突后停止继续调用，展示草稿与来源确认；普通阶段安排不应一律提升为必需约定。确认页面依据最终候选中的有效约定，避免展示已删除或已替换的历史操作 |
| 继续任务重新创建对象 | 恢复输入附带当前草稿修订、基础修订和操作数，要求读取、补齐和提交现有草稿。修复服务重启后冻结空白 `empty` 修订被错误拒绝的问题；继续仍检查任务代次与冻结来源 |
| 图形稀疏、汇合过窄 | 阶段在左侧 88 宽区域，摘要进入提示及阶段详情；列宽按可用宽度在 240—380 内计算，列间 20、行间 32。真实依赖形成显示行，同行顶部对齐；汇合唯一绘制且跨参与列。更多故事线保留横向滚动 |
| 默认空白与尺寸变化偏移 | 初次按 100% 左侧视口打开；窗口变化造成浏览器自动截断滚动范围时，不将截断回写为用户拖动。保留原滚动、缩放和反向定位能力 |

阶段指导目前由工具的候选检查、下一步建议、预算与恢复检查点共同实现，尚未实现调查方案中完整的规模估算器和持久化多阶段调度器。未将这些规划项标记为完成。
