# P3 读取与引用

日期：2026-10-30。状态：**已实施**。

- `GET /clues` 与 `GET /clues/{id}` 增加 `scope=story`；全书范围返回身份、计划、使用位置和正文观察，`node_id` 只接受当前构思中的节点。
- 章界范围保持原截止规则，不接受构思节点或方案参数；两种范围不能混用。
- 新增 `StoryClueCatalog`，标题只从账本身份读取；计划、使用和观察组合成一个视图，`view_revision` 覆盖结构修订、账本修订、计划和使用。
- 分页游标绑定视图修订；结构或账本变化后旧游标冲突，不拼接两个修订。
- `read_story` 返回阶段、故事线目标、节点变化与线索计划；服务端装配使用同一账本快照。
- 测试覆盖全书列表、节点过滤、详情使用位置、非法节点和章界隔离。
