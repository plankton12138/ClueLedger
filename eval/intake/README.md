# Intake 协议真模型走查用例集

> 用途：验证真 LLM 对 intake 协议的遵循度（三段式、≤5 问、想法有限给选项、不抢跑）及生命周期门的有效性。
> 用法：`uv run python -m hastings intake-smoke`（全新 slug 保证 intake 阶段），按用例文件逐条粘贴；除注明外每条用例换新 slug。
> 判定口径（所有用例统一三档）：**通过 / 部分合规（写明偏差）/ 协议违规（抢跑或拍板）**。

## C 组：经典小说基准用例（原文精细度压测）

以三篇经典悬疑小说全文为基准，按**原文的精细度**评判系统——「用大师精度压测系统上限」，区别于 A/B 组的协议合规性检查。

- **输入侧（防训练数据污染）**：委托书只给核心前提与偏好，按真实用户口吻写——不出现原书书名、人名、地名、标志性原句，也不预先写好人物关系、手法与线索清单；原文里的那些精度是**评判标准**，不是输入。模型若在输出中「认出」原著并复述原书设定，视为污染规避失败，按协议违规记录。
- **金标准**：每份用例自带从原书反推的金标准表（人物矩阵 / 诡计机制 / 线索双层 / 伏笔 / 时间线 / 结构文风），保留原书人名仅供评判者对照原文。评判口径同前——不要求复刻原书，要求**同精度**发展力：A（同粒度对应）/ B（结构在但粒度粗）/ C（缺失或错位），六~八大类取均值。

| 文件 | 基准源 | 压测维度 |
|---|---|---|
| [C1-speckled-band.md](C1-speckled-band.md) | 柯南·道尔短篇（斑点带子案） | 装置型诡计六环 + 17 条线索双层 + 动机开关 |
| [C2-orient-express.md](C2-orient-express.md) | 阿加莎长篇（东方快车谋杀案） | 13 人证词矩阵 + 8 件假证据双层 + 双解答 |
| [C3-and-then-there-were-none.md](C3-and-then-there-were-none.md) | 阿加莎长篇（无人生还） | 假死诡计 15 条机制 + 童谣逐句对位 + 三重不可能现场 |

## 失败处理

某用例不合规时：保留终端记录 → 归因（协议措辞不清 / 硬约束缺失）→ 协议问题改 prompts.py 并补断言，门问题改工具层并补拒绝路径测试 → 换新 slug 复跑。
