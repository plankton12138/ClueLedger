# C3：孤岛十杀（原文精细度基准，原著《无人生还》）

**基准源**：[eval/assets/无人生还.txt](../assets/无人生还.txt)（阿加莎长篇，约 8.6 万汉字；译名体系：士兵岛/瓦格雷夫）
**测法**：同 C1——新 slug → 轮次 1 粘「作者构想」→ 走完 intake 与 bible_drafting → 系统落盘 Bible 对照金标准。
**评判口径**：同 C1，A/B/C 三档。本案是**诡计结构**的压力极值：假死诡计 + 童谣逐句对位 + 三重不可能现场。

**防训练数据污染**：轮次 1 输入已去除原书全部人名、岛名、书名、童谣原文与「假死」这一核心机关名（模型大概率背过原文，连童谣片段都会触发背诵）；人物名单、死亡顺序、凶手身份一概不写进输入——它们是**评判标准**，不是输入。金标准保留原书人名，仅供评判者对照原文。特别地：委托书里用户明确说「这个结解不开」——模型若直接给出假死解答属于高光，但也必须验证其是否落实了金标准的机制精度，而非一句「其中一个假死」糊弄过去。

## 作者构想（轮次 1 输入，真实用户口吻）

```text
想写一个孤岛连环杀人案。十个人收到内容各不相同的邀请，先后来到一座和大陆彻底隔绝的小岛，主人始终没露面，岛上除了他们没有别人。饭厅墙上挂着一首童谣，整整十句，写十个小人怎么一个接一个死掉；餐桌正中摆着十个一模一样的小瓷人。第一晚吃饭的时候，留声机突然自己响了起来，把十个人各自干过的亏心事——全是法律管不着的那种——当众点了一遍名。

然后他们就真的照着童谣的歌词，一个接一个死了：噎死的、睡过去的、被砸的、被蜇的……每死一个，桌上的瓷人就少一个。暴风雨一来，连船都过不来了。

我的难点在这：凶手肯定就在这十个人里，不然人不可能一个一个被杀；可最后十个人全死光了，连凶手都没活下来——那凶手到底是谁杀的？这个结我想了好久解不开，越想越毛。结尾我想要官方彻底查不出真相的处理，再给读者留一层后背发凉的解释。童谣和瓷人这种仪式感的东西我很喜欢，想要它们不光是装饰，而是跟死亡真的扣在一起。
```

## 金标准：假死诡计机制（15 条，环环相扣）

1. **剧本公开**：童谣挂满每间卧室与餐厅，死亡按词逐句执行——预告即挑衅，也是凶手自我约束的仪式；
2. **计数装置**：十枚瓷人与死亡同步递减（罗杰斯先后发现 9→8→…），官方无法解释的现场核心；
3. **择罪标准**：留声机指控即凶手自白素材——他杀的全是法律够不着的人（法官自认「亲手处决过人」）；
4. **死亡顺序按罪孽轻重与痛苦时长设计**：最重的维拉排最后、独享最长的恐惧——凶手自任「处刑人」的正义叙事；
5. **早期死亡用身份掩护的无痕毒杀**：管家上酒递药天然接触——氰化物/镇静剂验不出下手时机；
6. **假死三件套**：红窗帘（浴室失踪）当血袍 + 灰毛线假发 + 额上红泥当弹孔记号；烛光房间只允许医生近身验尸；
7. **同谋唯一解**：岛上只有医生能合法宣告死亡；法官第一夜借「联合演戏恐吓真凶」的名义说服他配合——同谋是被骗的共犯；
8. **假死位次选第 6**：死亡已成惯例、众人自顾不暇，无人再验旧尸；掀开假发见额上红痕仍判定真死；
9. **假死后借「活人指挥」推动中段**：医生相信法官还活着并受其指挥，沦为凶手的白手套；
10. **借刀落海**：骗医生上崖「赴约」，落海尸骨无存——第 7 句「青鱼」字面兑现，幸存者据此坚信医生还活着；
11. **熊形钟**：布洛尔被假信号诱到独行路上，被从楼上推下的大理石熊形钟砸死（壁炉架装饰即前置伏笔）；
12. **夺枪调包**：趁乱进隆巴德房间偷走左轮子弹——「有枪」的自信恰是诱饵；
13. **诱导自杀**：房内水草惊吓唤起溺亡记忆令维拉崩溃，先夺枪击毙隆巴德，再在精神崩塌中自缢——最后一刀是死者自己动的；
14. **自杀装置**：眼镜系橡皮筋套在门把手、手枪挂于皮筋——扣扳机后枪弹回落地，「处刑完成后归位」，死因合法且保住「人人皆死」的结局；
15. **双结尾**：官方尾声逐人排查仍有缺口 + 瓶中信手稿自白补上动机与手法——谜底只对读者公开。

## 金标准：结构与文风

童谣十句=十幕结构，每幕死亡+瓷人递减的仪式节奏；无侦探主角的群像轮换内视角（「侦探」缺席，尾声由警方接手）；凶手心理全书只漏两处（宴席上取下假牙露出嗜血相 + 尾声手稿自白）——公平性契约：读者与角色同步困惑，谜底靠道具对位反推；氛围要素：暴风雨封岛、海崖、与世隔绝的老宅、童谣循环吟唱；双结尾（官方调查章 + 瓶中信）收束。

## 判定清单（对系统产出，同精度口径）

- [ ] **人物**：≥10 张人物卡，每卡含罪行 + 死亡对位 + 独立怀疑点三要素；「幸存者视角」（维拉型）与「明面侦探」（布洛尔型）两类误导角色不缺 → A/B/C
- [ ] **凶手机制**：假死三件套（伪装道具可就地取得 / 唯一验尸人 / 死亡时间不可鉴定）齐备；「借人性杀人」机关（同谋被骗 / 夺枪调包 / 诱导自杀）至少两处成立 → A/B/C
- [ ] **不可能现场**：三重不可能（消失的第 11 人 / 医生死于海上而死亡继续 / 全员死光凶手不在）各有解、且官方视角无解 → A/B/C
- [ ] **童谣与计数**：死亡顺序逐句对位童谣（十句不缺行）；计数装置自洽且含「瓷人消失」的恐慌节拍 → A/B/C
- [ ] **线索**：金标准 15 条按功能分类（邀请伪装 / 公开剧本 / 计数装置 / 身份伪装 / 道具出处 / 物证链 / 心理死因），系统 ≥10 条有对应物且每条双层 → A/B/C
- [ ] **伏笔**：9 组回收对照中 ≥6 组成对（埋点+回收点都有章位）→ A/B/C
- [ ] **时间线**：案外第 0 位 + 岛内 10 位顺序正确，含「官方计第 6 位实为假死」的错位标注 → A/B/C
