# C 组 v2 · CP2 成对盲评评分单

> 用途：对同一题目、同一模型下 harness 臂与 bare 臂的成稿（`<case>-s<k>.article.md`）做成对盲评，产出 **harness 增益** 的核心证据。CP1（Bible 设定精度）仍按各用例文件内的金标准表单臂评，本模板只管 CP2。

## 盲评协议

1. **匿名**：评判者拿到的是 `A` / `B` 两篇全文，不知道哪篇出自哪条臂；组织者保留映射表（`sample → arm`），评完再揭盲。
2. **抹痕**：揭盲前组织者须抹掉可识别来源的痕迹——统一去掉 markdown 工具性标记（如有）、章节标题格式统一为「第 X 章」。
3. **换位**：每对评两遍（A/B 左右互换）。两遍结论不一致记 `tie`，用于消位置偏好。
4. **多采样**：正式评测每臂每题 ≥3 次采样（`--sample 3`），逐对评完后按维度汇总胜率。
5. **双 judge**：人类 judge + 异族 LLM judge 各评一遍，LLM judge 输出须符合下方 JSON schema；两 judge 维度一致率（κ）写入报告，不一致维度回炉改 rubric 而非争论。
6. **防污染红线**：任一篇出现原书人名（如「罗伊洛特」「福尔摩斯」）或标志性原句，该篇按协议违规单独记录，不进入胜率统计（两臂都违规则该题作废）。

## 评分维度（每维度三选一：win_a / win_b / tie）

| # | 维度 | 判定要点 |
|---|---|---|
| D1 | 线索公平性 | 关键线索（含凶器/通道/动机文书）是否在揭示前全部展示给读者；读者理论上能否推出真相 |
| D2 | 伏笔回收 | 埋点与回收是否成对出现；有无「揭示时才首次出现」的作弊信息 |
| D3 | 误导设计 | 是否存在有效的红鲱鱼（表面指向 vs 真实含义双层）；误导是来自信息设计还是靠隐瞒 |
| D4 | 结构完整度 | 谜面 → 调查 → 高潮 → 复盘的完整闭环；揭示与高潮的位置关系 |
| D5 | 文风执行度 | 氛围要素（如哥特/暴风雨/老宅）是否落实在文本而非设定；对话驱动 vs 概述灌水 |

## 证据引用（硬性要求）

每个维度的判定必须引用**两篇中的具体证据**方可生效——线索编号、段落引文或章节位置，例如：

> D1 win_a：A 第 3 章「奶碟与鞭子先后出现两次」vs B 揭示章才首次提到凶器来源——B 作弊。

无证据引用的判定按 `tie` 处理。

## 汇总口径

- **维度胜率** = 该维度 harness 胜对数 / 有效对数（tie 与双违规对剔除）；报告各维度胜率及 95% 区间（样本少时直接报原始 W-L-T）。
- **总增益** = 五维度胜率均值；「harness 有没有用」的判据：总增益显著 > 50%（人类 judge 为准，LLM judge 为校验）。
- 环境头（模型版本 / 温度 / 日期 / 采样数 / judge 配置）必须写入报告，保证可复现。
